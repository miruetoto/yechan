핵심 논리: 절대높이 → 중심화 높이 변환

1. 절대높이 체이닝 (귀납법)

스텝 j−1: Xj−1에 +b 적립 → 절대높이 = y(Xj−1) + b
Flow 규칙: 낮은 쪽으로 이동 → y(Xj) ≤ y(Xj−1) + b
귀납: y(Xj−1) ≤ y(X₀) + (j−1)b 이므로 → y(Xj) ≤ y(X₀) + jb

2. 중심화 높이로 변환

스텝 j 시점에서 평균 ȳ = ȳ₀ + jb/n (j번의 +b 적립으로 평균이 jb/n 상승)
따라서: h(Xj) = y(Xj) − ȳ ≤ [y(X₀) + jb] − [ȳ₀ + jb/n]
= h(X₀) + jb(1 − 1/n) = h(X₀) + jb·(n−1)/n

hXj ≤ hXfall + jb · (n−1)/n  ≤  hXfall + jb

⚠ 만약 flow 중에 +b가 안 쌓이는 모델이라면 천장이 올라가지 않으므로 h ≤ hfall + b로 충분.
HST는 매 스텝 +b가 쌓이므로 천장이 매번 +b씩 상승하여 jb가 누적된다.

정리: flow는 절대높이 기준으로 "내리막"이지만, 매 스텝 현재 노드에 +b가 쌓여 "내리막의 출발점"이 매번 b씩 높아진다. j스텝 후 절대높이 상한은 y(X₀) + jb. 평균 보정 jb/n을 빼면 중심화 높이 상한은 h(X₀) + jb(n−1)/n ≤ h(X₀) + jb.
