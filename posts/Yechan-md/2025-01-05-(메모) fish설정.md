`-` fish, omf 설치 

```bash
sudo apt update
sudo apt install fish
curl -L https://get.oh-my.fish | fish
```

`-` tmux 기본을 fish로 하기

```bash
nano ~/.tmux.conf
```

```bash
set-option -g default-shell /usr/bin/fish
set-option -g default-command /usr/bin/fish
```

`-` conda와 fish 연동

```bash
conda init fish
```
