# 0. 동기

앞 포스트 [예제2의 diffusion distance 정의 오류](260425_*.html) 를 정리하면서, 우리가 "diffusion" 이라고 부른 것이 실제로 표준 정의가 아니었고, 더 근본적으로 — HST 자체를 *정확히* 어떤 기존 거리 위에 위치시킬지가 모호하다는 걸 재확인. 이 포스트는 그래프의 두 노드 사이 거리를 재는 **주요 고전 기법**을 한자리에 정리하고, HST 가 그 지형에서 어디에 놓이는지 짚는 index.

# 1. 왜 "그래프 위 거리" 인가

그래프 $\mathcal G = (\mathcal V, \mathcal E, \mathbf W)$ 의 노드 두 개 $i, j$ 에 대해 $d(i, j) \geq 0$ 을 주는 함수가 필요한 이유:

- **임베딩**: $d$ 를 Euclidean $\mathbb R^k$ 에 이식 (MDS, spectral embedding) → 시각화·downstream ML
- **클러스터링**: $d$-based partitioning (spectral clustering 등)
- **신호처리**: $d$ 로 regularization kernel 정의 (smoothing, denoising)
- **이상 탐지 / link prediction**: 노드 쌍 유사도의 정량화
- **geometry analysis**: 그래프가 어떤 *잠재 metric space* 를 근사하는가 (manifold hypothesis)

좋은 그래프 거리는 대개 다음을 만족: **(i) 엣지 가중치 존중**, **(ii) 전역 구조 반영**, **(iii) 노이즈에 둔감**, **(iv) 계산 가능**, **(v) 해석 가능**. 한 가지가 모두를 만족 못하므로 여러 family 가 공존.

---

# 2. 거리의 큰 분류

- **경로 기반 (path-based)**: 한 최단경로에만 의존 — shortest path
- **Walk 기반 (walk-based)**: 모든 경로의 확률적 평균 — diffusion, heat kernel, PPR
- **대수 기반 (algebraic / spectral)**: Laplacian 스펙트럼으로 표현 — resistance, biharmonic
- **확률 기반 (probabilistic / stopping-time)**: 마르코프 체인의 통계 — hitting/commute time
- **비선형·신호-aware**: HST 고유 — 신호와 그래프의 상호작용으로 정의

다섯 family 는 상당 부분 겹침 (특히 walk-based ⊂ spectral).

# 3. Family A — 경로 기반

## 3.1 Shortest path (geodesic) distance

$$d_{\mathrm{sp}}(i, j) \;=\; \min_{\text{path }i \to j} \; \sum_{e \in \text{path}} w_e^{-1}$$

(가중치 $w$ 가 similarity 면 $1/w$ 를 거리로 쓰는 것이 관례, distance 로 주어지면 그대로 합.)

- **장점**: 명료, triangle inequality 자동 성립, Dijkstra $O((|V| + |E|) \log |V|)$.
- **단점**: **한 경로에 과의존**. 한 엣지 제거/노이즈에 취약. 두 노드 사이 "얼마나 많이 연결됐나"는 못 봄. 그래서 bottleneck 그래프에서 cluster 두 개 간 거리가 모두 같은 값으로 뭉개짐.
- **응용**: 교통망, 검색, Manifold Learning 의 Isomap (Tenenbaum 2000).

## 3.2 $k$-shortest paths / widest path

Shortest 하나가 아니라 상위 $k$ 개의 path 평균/최솟값 사용 — noise 완화. 잘 안 씀.

# 4. Family B — Walk 기반 (diffusion)

## 4.1 Random walk 전이행렬

$P = D^{-1} W$ (row-stochastic), $\pi$ = stationary distribution (symmetric $W$ 이면 $\pi_i = d_i / \text{vol}(G)$).

## 4.2 Diffusion distance (Coifman-Lafon 2006)

$$d_t^2(i, j) \;=\; \sum_k \frac{\bigl(P^t_{ik} - P^t_{jk}\bigr)^2}{\pi_k}$$

- $t$ = diffusion scale. $t$ 작으면 local, 클수록 global.
- Multi-scale — $t$ 를 바꿔가며 그래프 구조의 다양한 층위 관찰.
- **Spectral form** (symmetric $P$ 의 경우, or normalized Laplacian $\mathcal L = I - P$ 의 eigenpair $(\lambda_k, \phi_k)$):
  $$d_t^2(i, j) \;=\; \sum_{k \geq 1} (1 - \lambda_k)^{2t} \bigl(\phi_k(i) - \phi_k(j)\bigr)^2$$
- **Diffusion map embedding**: $\Psi_t(i) = \bigl((1-\lambda_1)^t \phi_1(i), (1-\lambda_2)^t \phi_2(i), \ldots\bigr)$. 유클리드 거리 = diffusion distance.

참고: [예제2의 diffusion distance 정의 오류](260425_*.html) 에서 짚은 대로, 구현 시 $\pi$-가중 / row-stochastic 여부가 중요.

## 4.3 Heat kernel distance

$$H_t = e^{-t L}, \qquad d_t^2(i, j) = \sum_k \frac{\bigl(H_t(i, k) - H_t(j, k)\bigr)^2}{\pi_k}$$

연속시간 버전. Laplacian 의 exponential.

- **관계**: $P^t \approx (I - \mathcal L)^t \approx e^{-t\mathcal L}$ (small spectral). 본질적으로 같은 family — Poisson-average 관점.
- Belkin-Niyogi 2003, Coifman-Lafon 2006 에서 통일.
- **Heat Kernel Signature** (Sun-Ovsjanikov-Guibas 2009): geometry processing 표준.

## 4.4 Personalized PageRank (PPR) distance

$$\mathbf p_i \;=\; \alpha \mathbf e_i + (1 - \alpha) P^\top \mathbf p_i$$

각 노드 $i$ 에서의 local 분포 $\mathbf p_i$ 를 구하고 $d(i, j) = \|\mathbf p_i - \mathbf p_j\|_2$.

- Restart-probability $\alpha$ 가 지역성 조절.
- $\alpha \to 0$: diffusion 의 stationary 근사, $\alpha \to 1$: 지역 이웃 (one-hop).
- 대규모 그래프 (웹, 소셜) 에서 실용.
- Spielman-Teng (2013) 의 local clustering 이론과 밀접.

# 5. Family C — Algebraic / spectral

## 5.1 Laplacian 스펙트럼

Combinatorial Laplacian $L = D - W$ (symmetric, PSD). 고유 분해:
$$L = \sum_k \lambda_k \psi_k \psi_k^\top, \quad 0 = \lambda_0 \leq \lambda_1 \leq \cdots$$

여러 거리가 **스펙트럼 필터**로 통합됨:

$$d_f^2(i, j) \;=\; \sum_{k \geq 1} f(\lambda_k) \bigl(\psi_k(i) - \psi_k(j)\bigr)^2$$

| 이름 | $f(\lambda)$ |
|:---|:---|
| Heat kernel | $e^{-t\lambda}$ |
| Resistance | $1/\lambda$ |
| Biharmonic | $1/\lambda^2$ |
| Diffusion (이산) | $(1-\lambda)^{2t}$ |
| PPR | $\alpha^2 / (1 - (1-\alpha)(1-\lambda))^2$ |
| Spectral embedding ($k$차원) | $\mathbf 1_{\{\lambda \leq \lambda_k\}}$ |

## 5.2 Effective resistance / resistance distance

그래프를 전기회로로 보고 (엣지 가중치 = conductance), 노드 $i, j$ 에 $\pm 1$ A 주입 시 발생하는 전위차:

$$R_{\mathrm{eff}}(i, j) \;=\; L^\dagger_{ii} + L^\dagger_{jj} - 2 L^\dagger_{ij} \;=\; \sum_{k \geq 1} \frac{(\psi_k(i) - \psi_k(j))^2}{\lambda_k}$$

- **Metric** (Klein-Randić 1993) — triangle inequality 성립.
- **Euclidean embedding 가능** — $\sqrt{R}$ 는 유클리드 거리.
- $L^\dagger$ 는 Moore-Penrose pseudoinverse.
- **한계**: von Luxburg-Radl-Hein (2014) — 대규모 그래프에서 $R_{\mathrm{eff}}(i,j) \approx 1/d_i + 1/d_j$ 로 **degrees 만 반영하는 ultrametric 으로 수렴** → 구조 정보 유실. $k$-NN 그래프 등에서 주의.

## 5.3 Commute time

$$C_{ij} \;=\; \mathbb E_i[\tau_j] + \mathbb E_j[\tau_i] \;=\; \text{vol}(\mathcal G) \cdot R_{\mathrm{eff}}(i, j)$$

(Chandra-Raghavan-Ruzzo-Smolensky-Tiwari 1989.) Resistance 와 상수배 — 대수/전기/Markov 가 같은 대상을 보는 예시.

## 5.4 Biharmonic distance (Lipman-Rustamov-Funkhouser 2010)

$$d_{\mathrm{bih}}^2(i, j) \;=\; \sum_{k \geq 1} \frac{(\psi_k(i) - \psi_k(j))^2}{\lambda_k^2}$$

- 저주파 비중이 더 큼 → global structure 우선.
- 3D mesh geometry processing 의 de facto.

## 5.5 Spectral / Laplacian eigenmap embedding

Belkin-Niyogi 2003. 하위 $k$ 개 고유벡터 $(\psi_1, \ldots, \psi_k)$ 로 임베딩, 유클리드 거리. 위 spectral family 에서 필터 $f$ = indicator 인 경우.

# 6. Family D — Probabilistic / stopping-time

## 6.1 Hitting time

$$H_{ij} \;=\; \mathbb E_i[\tau_j], \quad \tau_j = \inf\{t \geq 0 : X_t = j\}$$

- **비대칭** (directed 그래프는 특히): metric 아님.
- Fundamental matrix $Z = (I - P + \mathbf 1 \pi^\top)^{-1}$ 로 closed-form.

## 6.2 Kemeny's constant

$$\kappa \;=\; \sum_j \pi_j H_{ij} \;\; \text{(startvertex $i$ 에 무관한 상수)}$$

Mixing 시간의 지표. 그래프 건강도 measure.

## 6.3 Hitting time 대칭화

$C_{ij} = H_{ij} + H_{ji}$ → commute time (§5.3 와 동일).

$|H_{ij} - H_{ji}|$ → directed 그래프에서 방향성 지표.

---

# 7. Family E — 고차 / 신호-aware

## 7.1 Wasserstein / OT 기반

- **Earth Mover's Distance on graphs**: 두 분포 간 최소 transport cost. 두 노드라기보다 두 distribution 간 거리.
- **Gromov-Wasserstein** (Mémoli 2011): 두 metric space 간 거리, 그래프-to-그래프.
- **Fused GW**: 그래프 feature + structure 동시 비교.

(Node-level 에는 직접 적용 X, 하지만 임베딩 모양 비교 / 그래프 비교에 쓰임. [편차분석](260424_a5d784.html) 에서 GW 를 node-level 에 쓰려다가 degenerate 된 것 참조.)

## 7.2 Heat Kernel Signature / Wave Kernel Signature

Heat kernel $H_t(i, i)$ 의 $t$-trace 를 feature vector 로 취급. 두 노드 feature 의 거리. Geometry processing 기반.

## 7.3 Learned embeddings (DeepWalk, node2vec, GNN)

데이터 기반으로 학습된 임베딩 후 유클리드 거리. Perozzi 2014 (DeepWalk), Grover-Leskovec 2016 (node2vec), Hamilton 2017 등. Skip-gram 목적함수 로 random walk 통계를 embedding 으로 내재화.

## 7.4 Heavysnow Transform (HST)

$$\mathrm{SD}^2_{ij}(t) \;=\; \sum_{\ell=1}^t \bigl(h_i(\ell) - h_j(\ell)\bigr)^2, \qquad h(\cdot, \ell) = \text{snow height at step } \ell$$

$h$ 는 Algorithm 1 (flow + block + reset) 로 생성. 극한:
$$\overline{\mathrm{SD}}^2_{ij}(t) = \mathrm{SD}^2_{ij}(t)/t \;\xrightarrow{a.s.}\; c_{ij} = \mathbb E_\pi[(\delta_i - \delta_j)^2] \quad \text{(drift 조건 하)}$$

참고: [$\overline{\mathrm{SD}}^2$ 수렴 증명](260424_cdbaf0.html).

# 8. HST 의 위치 — 고전과의 대응

지금까지 정리한 family 중 HST 는 어디에 속하나?

## 8.1 "Block 없는 $\mathbf f = 0$ HST" = commute time 류

- 블록 메커니즘 제거 → walker 는 단순 random walk.
- $\mathbf y = 0$ → 초기 snow 균일.
- $h_i(\ell)$ = 노드 $i$ 의 누적 방문 횟수.
- $h_i(\ell)/\ell \to \pi_i$, fluctuation $(h_i - \ell\pi_i)$ 은 martingale.
- $\overline{\mathrm{SD}}^2$ 은 **발산** — linear trend 가 $t^2 (\pi_i - \pi_j)^2$ 로 polynomial 지배.
- Centered 양의 asymptotic variance 는 **effective resistance / commute time** 에 비례 (Lovász 1993 §3, Chandra et al. 1989).

**결론**: block 없는 HST 는 본질적으로 resistance / commute-time 계열. 새로움 없음.

## 8.2 "Block 있는 $\mathbf f = 0$ HST" — drift 메커니즘 발동

- Block 이 height range 를 stationary 로 만들어 $\overline{\mathrm{SD}}^2$ 수렴 가능케 함.
- $\mathbf y = 0$ 이지만 여전히 graph-only 지표.
- 극한 $c_{ij} = \mathbb E_\pi[(\delta_i - \delta_j)^2]$ 에서 $\delta$ 는 height increment 의 stationary 분포.
- $\delta$ 는 walker 의 방향·block 통계에 의존 — **classical 과 정확히 일치하는 대응 없음** (열린 문제).

한계: $c_{ij}$ 가 $R_{\mathrm{eff}}$ 와 같은지? 일반적으로 **다름**. 특히 directed graph 에서 HST 는 방향 정보를 간직, 그러나 $R_{\mathrm{eff}}$ 는 symmetrize.

## 8.3 "Block 있는 $\mathbf f \neq 0$ HST" = signal-aware (고유)

- 초기 signal $\mathbf y$ 가 height 에 박혀 block 확률을 바꿈.
- 결과: 극한 metric $c_{ij}$ 가 $\mathbf y$ 의 구조를 **nonlinearly** 반영.
- 이것이 HST 의 *진짜* 기여 — 위 어떤 family 도 signal-aware 가 아님 (§7.3 learned embedding 은 supervised/training 기반, HST 는 unsupervised / intrinsic).

# 9. 통합 요약표

"방향성 (directed)" 열은 세 층위로 나누어 읽어야 함:
- **계산 가능?** — directed $W$ 에서 식이 well-defined 인가.
- **output 비대칭?** — $d(i,j) \neq d(j,i)$ 인가.
- **방향성 반영?** — directed vs symmetrize 결과가 실질적으로 다른가.

**범례**.
- **metric (undirected)**: symmetric $W$ 에서 거리 공리 (non-neg, symm, identity, triangle) 성립 여부.
- **directed 에서 행동**: 세 층위로 — (a) 계산 가능성, (b) output 비대칭 가능성, (c) 실제로 방향 정보가 output 에 드러나는지.

| Family | 이름 | 정의 핵심 | metric (und.)? | 파라미터 | 신호-aware | directed 에서 행동 |
|:---|:---|:---|:---:|:---|:---:|:---|
| Path | Shortest path | $\min \sum w^{-1}$ | ✓ | - | ✗ | **metric 깨짐** (symmetry 없음, 경로 부재 시 ∞) — strongly connected 필요; quasi-metric 으로 남음 |
| Walk | Diffusion | $P^t$ 행 거리 | ✓ | $t$ | ✗ | $P$ 는 directed 수용, output symmetric — 방향성 **평균화돼 사라짐** (ex: directed cycle ≈ undirected cycle); $\pi$ 존재 조건 필요 |
| Walk | Heat kernel | $e^{-tL}$ 행 거리 | ✓ | $t$ | ✗ | $L$ 비대칭 ⇒ spectral 복잡 (complex eigvals), 실무적으론 symmetrize |
| Walk | PPR | restart walk 분포 거리 | ✓ | $\alpha$ | ✗ | 계산은 ✓, output symmetric — walker 방향성 일부 반영하나 output 에 평탄화 |
| Algebraic | Resistance ($R_{\mathrm{eff}}$) | $L^\dagger$ diagonal+off | ✓ | - | ✗ | **요구: symmetric $W$** (전기회로 해석이 undirected 기반) |
| Algebraic | Biharmonic | $1/\lambda^2$ weight | ✓ | - | ✗ | **요구: symmetric $L$** |
| Algebraic | Spectral embedding | 하위 $k$ 고유벡터 | ✓ | $k$ | ✗ | **요구: symmetric $L$** (asymmetric eigendecomp 가능하지만 해석 약함) |
| Prob | Hitting time | $\mathbb E_i[\tau_j]$ | ✗ (비대칭) | - | ✗ | directed 에서도 자연, **비대칭 그대로 유지** — 유일하게 방향성을 output 까지 보존 |
| Prob | Commute time | $H_{ij} + H_{ji}$ | ✓ | - | ✗ | symmetrize 로 directed 도 계산, **output symmetric** (방향성 평균) |
| OT | Gromov-Wasserstein | node pair 에 비직접 | - | - | 부분적 | 계산 가능하지만 metric-space 자체 비교라 node-level 관점과 다름 |
| Learned | DeepWalk / GNN | walk/skip-gram | ≈ | 많음 | ✓ (label 있으면) | 모델 설계에 따라 (rowwise vs bidirectional) |
| Nonlinear | **HST (block + signal)** | snow height L2 | ≈ | $b, T_{\max}$ | **✓ intrinsic** | walker 가 directed 수용, output symmetric 이지만 block dynamics 가 **$W$ vs $W^\top$** 에서 다른 극한 $c_{ij}$ 생성 → 방향성이 기하학적으로 간직됨 |

"≈" — 삼각부등식 엄밀증명 없거나 특정 조건 하에서만 성립.

## 9.1 Directed 에서 거리 공리 정리

| 공리 | SP | Diffusion | PPR | Resist | Hit | Commute | HST |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| $d \geq 0$ | ✓ | ✓ | ✓ | ✓ (sym) | ✓ | ✓ | ✓ |
| $d(i,i) = 0$ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **symmetric** | **✗** | ✓ | ✓ | ✓ | **✗** | ✓ | ✓ |
| triangle ineq. | ✓ (quasi) | ✓ | ✓ | ✓ | ✗ | ✓ | ≈ |
| 전체 정의 (모든 쌍에 유한) | **✗** (reach 필요) | ergodic 필요 | ✓ | sym 요구 | reach 필요 | strong conn 필요 | ergodic 필요 |

(**굵게**: 치명적 결함.)

## 9.2 방향성 정보가 실제로 남는가

**Output 자체가 비대칭**인 거리:
- Shortest path (directed SP, metric 아님)
- Hitting time (metric 아님, 비대칭 그대로)

**Output 은 symmetric 이지만 방향성이 정량적으로 스며드는** 거리:
- HST — block dynamics 가 $W$ vs $W^\top$ 를 구별. 직접 검증 가능.

**Output 이 symmetric 이고 실질적으로 방향성이 사라지는** 거리:
- Diffusion, heat kernel, PPR, commute time, resistance — 수치적으론 directed $W$ 로 계산해도 최종 distance pattern 이 symmetrized 그래프 결과와 가까움 (특히 ergodic + 빠른 mixing 경우).

→ **"신호 섞인 directed graph 분석"** 이라면 HST 가 유의미한 차별화 포인트. **"신호 없는 directed 분석"** 이라면 hitting time 이 가장 직접적.

# 10. 언제 어느 것을 쓸까

| 상황 | 1차 후보 |
|:---|:---|
| 빠른 baseline | shortest path |
| Multi-scale 그래프 구조 | diffusion / heat kernel ($t$ 스윕) |
| 전역 robust metric, 유클리드 임베딩 | resistance / commute time |
| 대규모 그래프 지역 구조 | PPR |
| Geometry processing (mesh) | heat / biharmonic |
| Directed 그래프 | diffusion / PPR / hitting |
| 두 metric space 간 거리 | Gromov-Wasserstein |
| 신호 $\mathbf y$ 와 그래프 구조의 **결합** 이 핵심 | **HST** |
| 학습된 작업-특화 거리 | GNN / node2vec |

HST 를 선택해야 할 상황의 핵심 키워드: **"신호 $\mathbf y$ 가 그래프 구조를 해석하는 맥락으로 들어가야 한다"**. 단순히 그래프만 분석하면 위 classical 중 하나로 충분.

# 12. 결론

그래프 위 거리는 **5개 family (path / walk / algebraic / probabilistic / signal-aware)** 로 정리된다. Spectral family 가 walk/algebraic 을 통일적으로 본다는 게 이론적 백본. HST 는 block + signal 의 조합으로 이 지형 밖에 있는 **nonlinear signal-aware metric** 을 만든다는 점에서 구분됨.

"$f = 0$ + block 없음" 의 특수 케이스는 **commute time / effective resistance 와 동일 계보** 로 환원. 그래서 HST 가 정말 기여하는 부분은 block 메커니즘과 signal interaction 이 함께 작동하는 regime 에 있음. 이걸 놓치면 "새로운 diffusion" 이라고 착각할 뻔 — 이번에 diffusion distance 정의 오류를 발견하면서 실제로 놓칠 뻔했다.
