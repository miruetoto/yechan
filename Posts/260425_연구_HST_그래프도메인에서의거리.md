# 1. 도입

그래프 $\mathcal G = (\mathcal V, \mathcal E, \mathbf W)$ 위에서 노드 쌍 $i, j$ 사이의 "거리" $d(i, j)$ 를 어떻게 정의할 것인가? 단일 정답은 없다. 거리를 재는 방식에 따라 **같은 그래프**에서도 서로 다른 기하를 보게 되고, downstream task (임베딩, 클러스터링, 이상 탐지) 의 질이 달라진다.

좋은 그래프 거리의 바람직한 성질:

| 성질 | 설명 |
|:---|:---|
| (i) 엣지 가중치 존중 | 가중치가 큰 엣지는 "가까움"을 의미 |
| (ii) 전역 구조 반영 | 한 경로에만 의존하지 않고 전체 연결 패턴을 봄 |
| (iii) 노이즈 둔감 | 엣지 하나의 추가/삭제에 robust |
| (iv) 계산 가능 | $O(n^3)$ 이하로 모든 쌍 계산 가능 |
| (v) 해석 가능 | 물리적/확률적 의미가 명확 |

한 가지가 전부를 만족하지 못하므로 여러 family 가 공존한다. 이 포스트는 **주요 그래프 거리 6종**의 정의와 성질을 정리하고, **Thm A·B 검증에 사용된 8개 그래프** 위에서 실제 MDS 임베딩을 비교하여 각 거리가 어떤 구조를 포착하는지 실증한다.

# 2. 여러 거리 소개

## A. 정의

### 2.1 Shortest path distance (SP)

$$d_{\mathrm{sp}}(i, j) \;=\; \min_{\text{path }i \to j} \sum_{e \in \text{path}} w_e^{-1}$$

가중치 $w$ 가 similarity 이면 $1/w$ 를 거리로 사용. Dijkstra $O((|V|+|E|)\log|V|)$.

- **장점**: 명료, triangle inequality 자동 성립.
- **단점**: 한 경로에 과의존. 노이즈에 취약. bottleneck 그래프에서 클러스터 간 거리가 동일값으로 뭉개짐.

### 2.2 Diffusion distance (Coifman–Lafon 2006)

전이행렬 $P = D^{-1}W$ (row-stochastic), stationary $\pi$ 에 대해:

$$d_t^2(i, j) \;=\; \sum_k \frac{\bigl(P^t_{ik} - P^t_{jk}\bigr)^2}{\pi_k}$$

- **파라미터** $t$: 작으면 local, 크면 global.
- **Spectral form**: $d_t^2(i,j) = \sum_{k \geq 1} (1-\lambda_k)^{2t} (\phi_k(i)-\phi_k(j))^2$.
- **한계**: $t \to \infty$ 에서 $d_t \to 0$ (degenerate). scale 선택이 중요.

### 2.3 Effective resistance (Resistance distance)

그래프를 전기회로로 해석 (엣지 가중치 = conductance):

$$R_{\mathrm{eff}}(i, j) \;=\; L^\dagger_{ii} + L^\dagger_{jj} - 2L^\dagger_{ij} \;=\; \sum_{k \geq 1} \frac{(\psi_k(i)-\psi_k(j))^2}{\lambda_k}$$

- **Metric** (triangle inequality 성립), Euclidean embedding 가능.
- **Commute time 과의 관계**: $C_{ij} = \mathbb E_i[\tau_j] + \mathbb E_j[\tau_i] = \mathrm{vol}(\mathcal G) \cdot R_{\mathrm{eff}}(i,j)$.
  → 두 거리는 같은 MDS 임베딩을 만들므로 아래 시뮬레이션에서는 resistance 만 사용.
- **한계**: von Luxburg et al. (2014) — 대규모 그래프에서 $R_{\mathrm{eff}}(i,j) \approx 1/d_i + 1/d_j$ (degree 만 반영하는 ultrametric 으로 수렴).
- **요구**: symmetric $W$.

### 2.4 Biharmonic distance (Lipman–Rustamov–Funkhouser 2010)

$$d_{\mathrm{bih}}^2(i,j) \;=\; \sum_{k \geq 1} \frac{(\psi_k(i)-\psi_k(j))^2}{\lambda_k^2}$$

- Resistance 대비 저주파 비중이 더 큼 → global structure 우선.
- 3D mesh geometry processing 의 de facto.
- **요구**: symmetric $L$.

### 2.5 Hitting time

$$H_{ij} \;=\; \mathbb E_i[\tau_j], \quad \tau_j = \inf\{t \geq 0 : X_t = j\}$$

- **비대칭** ($H_{ij} \neq H_{ji}$) — metric 아님.
- Closed-form: $Z = (I - P + \mathbf 1 \pi^\top)^{-1}$ 에서 $H_{ij} = (Z_{jj} - Z_{ij})/\pi_j$.
- **Directed graph** 에서도 자연스럽게 정의되며, **비대칭 그대로 유지** — 유일하게 방향성을 output 까지 보존하는 거리.
- MDS 임베딩 시에는 $(H + H^\top)/2$ 로 대칭화.

### 2.6 Heavysnow Transform distance (HST, $f=0$)

$$\overline{\mathrm{SD}}^2_{ij}(\tau) = \frac{1}{\tau} \sum_{\ell=1}^\tau (h_i(\ell) - h_j(\ell))^2$$

$h$ 는 Algorithm 1 (flow + block + reset) 로 생성된 snow height. **$f=0$** (신호 없음) 이면 순수하게 그래프 구조만 반영.

- Block 없는 HST ($f=0$) = commute time / resistance 계열로 환원.
- **Block 있는 HST ($f=0$)** = drift 메커니즘이 발동, classical 과 정확히 일치하는 대응 없음.
- 파라미터: $b$ (block 임계), $\tau$ (시뮬레이션 길이).

## B. 계열 분류

다섯 family 로 정리된다:

| Family | 거리 | 핵심 기제 |
|:---|:---|:---|
| **Path-based** | Shortest path | 최단 경로 합 |
| **Walk-based** | Diffusion, Heat kernel, PPR | 확률적 걷기의 전이확률 비교 |
| **Algebraic / Spectral** | Resistance, Biharmonic, Spectral embedding | Laplacian 스펙트럼 필터 |
| **Probabilistic** | Hitting time, Commute time | 마르코프 체인 정지 시간 |
| **Nonlinear** | HST | Block dynamics + snow accumulation |

Walk-based 와 Algebraic 은 **spectral filter** 로 통합된다:

$$d_f^2(i,j) = \sum_{k \geq 1} f(\lambda_k) (\psi_k(i) - \psi_k(j))^2$$

| 이름 | $f(\lambda)$ |
|:---|:---|
| Heat kernel | $e^{-t\lambda}$ |
| Diffusion (이산) | $(1-\lambda)^{2t}$ |
| Resistance | $1/\lambda$ |
| Biharmonic | $1/\lambda^2$ |
| PPR | $\alpha^2 / (1-(1-\alpha)(1-\lambda))^2$ |

HST 는 이 spectral 표현에 들어맞지 않는 **nonlinear** 거리다. Block 메커니즘이 height 의존적이므로 선형 연산자로 환원되지 않는다.

# 3. 시뮬레이션 연구

## 테스트 그래프

Thm A (balanced: $\rho_i \approx 1/n$, $\overline{\mathrm{SD}}^2/\tau \to c$) 와 Thm B (drift: $\rho_i \neq \rho_j$, $\overline{\mathrm{SD}}^2/\tau^3$) 검증에 사용된 8개 그래프를 그대로 사용한다. 모든 예제에서 **$f=0$** (그래프 구조만 관찰).

| # | 그래프 | $n$ | 특징 | Theorem |
|:---|:---|:---:|:---|:---|
| 1 | Star $S_{13}$ | 13 | hub(deg 12) + 12 leaves(deg 1) | B (drift) |
| 2 | Wheel $W_{11}$ | 11 | hub(deg 10) + 10 rim(deg 3), outer cycle | A (balanced) |
| 3 | Helm | 21 | hub + ring(10) + pendant(10) | A+B (hybrid) |
| 4 | Double Helm | 31 | hub + inner ring + pendant + outer ring | A+B (hybrid) |

## A. Shortest Path

![Ex1: Star](../2026-OHS-HST/results/figures/260516_거리비교_시뮬레이션.py/ex1_star.png)

**SP 의 관찰:**

- **Star**: hub→leaf = 1, leaf→leaf = 2. 임베딩이 "허브 중심 + 균등 leaf 원"을 정확히 보여줌. 모든 leaf 가 등거리이므로 원주에 균등 배치.
- **Cycle 류 (5, 7, 8)**: 원형 구조를 정확히 복원. 가장 직관적.
- **Directed cycle (6)**: **치명적 실패**. Directed SP 에서 $\mathrm{SP}(i, i+1)=1$, $\mathrm{SP}(i, i-1)=n-1$. 대칭화 $(\mathrm{SP}+\mathrm{SP}^\top)/2$ 하면 모든 쌍의 거리가 $\approx n/2$ 로 뭉개짐 → MDS 가 **임의 산포** (scatter) 를 출력. 방향 그래프에서 SP 대칭화는 의미 없다.
- **Helm / Double Helm**: bottleneck — hub→leaf 거리가 모든 leaf 에 대해 동일 (=2 또는 =3). 그래프의 다층 구조가 뭉개짐.

## B. Diffusion Distance ($t=10$)

![Ex5: Parity Cycle](../2026-OHS-HST/results/figures/260516_거리비교_시뮬레이션.py/ex5_parity.png)

**Diffusion 의 관찰:**

- **Star**: hub 가 leaf 군집에서 **극단적으로 분리**. $t=10$ 이면 leaf 들의 $P^t$ 행은 서로 거의 동일하나 hub 행은 다름 → leaf 군집이 한 점으로 응축.
- **Parity Cycle**: 원이 아니라 **나선(spiral) 형태**로 왜곡. $t=10$ 이 60-node cycle 에 비해 짧아 local 패턴만 반영하기 때문. $t$ 를 키우면 원에 가까워지지만 → 0 degenerate.
- **Directed cycle**: SP 와 마찬가지로 **산란**. Shift matrix 의 $P^t$ 는 역시 shift 이므로 모든 행이 순환 치환 → diffusion distance 는 결국 stationary 근사에서 모든 쌍 동일.
- **Gaussian kernel cycle (7)**: 가중치 연속 변화를 반영하여 타원형에 가까운 원. SP 보다 smooth.
- **핵심 한계**: **$t$ 선택이 결정적**. $t$ 작으면 local, 크면 degenerate. 정보량이 파라미터에 크게 의존.

## C. Resistance Distance

![Ex7: Outlier Cylinder](../2026-OHS-HST/results/figures/260516_거리비교_시뮬레이션.py/ex7_ocyl.png)

**Resistance 의 관찰:**

- **Star**: hub 중심, leaf 원형 — SP 와 동일한 구조 ($R_{\mathrm{eff}}$ 도 hub-leaf=1, leaf-leaf=2).
- **Cycle 류**: **깨끗한 원형 복원**. 양쪽 경로를 모두 고려하므로 SP 보다 robust. Outlier Cylinder (7) 에서 상/하반구 분리가 약간 보임 — Gaussian 가중치의 미세 차이 반영.
- **Directed cycle**: $W$ 를 symmetrize 후 계산 → $(W+W^\top)/2$ 가 uniform cycle → **완벽한 원형 복원**. 방향 정보는 완전 유실이지만, 구조 자체는 정확히 잡음.
- **Helm**: hub 중심에 ring (파랑) 이 가까이, pendant (초록) 가 바깥으로. **degree 차이를 반영**한 층위 분리가 SP 보다 선명.
- **한계**: von Luxburg et al. (2014) 의 ultrametric 수렴. 대규모에서 $R \approx 1/d_i + 1/d_j$.

## D. Biharmonic Distance

**Biharmonic 의 관찰:**

- Resistance 와 같은 spectral family ($1/\lambda^2$ vs $1/\lambda$) 이나 저주파 비중이 더 큼.
- **Cycle 류**: Resistance 와 거의 동일한 원형 복원. 소규모에서는 두 거리의 차이 미미.
- **Helm**: Resistance 보다 **층위 간 분리가 약간 더 뚜렷**. $1/\lambda^2$ 가중이 global mode 를 강조하기 때문.
- **Outlier Cylinder**: 상/하반구 분리가 Resistance 보다 더 눈에 띔 — 저주파 성분이 cluster 경계를 강조.
- **Directed cycle**: symmetric $L$ 필요 → symmetrize. Resistance 와 동일하게 원형 복원.

## E. Hitting Time

![Ex6: Directed Cycle](../2026-OHS-HST/results/figures/260516_거리비교_시뮬레이션.py/ex6_dcycle.png)

**Hitting time 의 관찰:**

- **Star**: hub→leaf hitting time 과 leaf→hub hitting time 이 크게 다름. 대칭화 후에도 hub 가 leaf 와 상당히 분리된 임베딩.
- **Directed cycle**: SP, Diffusion 이 산란되는 데 비해, hitting time 은 **원형에 가까운 구조를 유지**하면서도 약간의 비대칭 왜곡이 남음. $H(i \to i+1)=1$, $H(i \to i-1)=n-1$ 의 비대칭이 대칭화 $(H+H^\top)/2$ 후에도 기하학적 흔적으로 남기 때문.
- **Cycle 류 (undirected)**: degree 균등 → geodesic 에 비례 → 원형 복원.
- **Helm**: hub 와 leaf 의 hitting time 비대칭이 층위 분리에 기여.
- **한계**: metric 아님 (triangle inequality 불성립). 비대칭이 장점이자 단점 — MDS 에 넣으려면 대칭화 필수.

## F. HST ($f=0$)

![Ex3: Helm](../2026-OHS-HST/results/figures/260516_거리비교_시뮬레이션.py/ex3_helm.png)

**HST (block, $f=0$) 의 관찰:**

- **Star**: hub (빨강) 가 leaf 군집에서 **극단적으로 분리**. Degree 차이 → drift regime (Thm B) → SD²/τ³ 스케일링. Diffusion 도 hub 를 분리하지만, HST 는 block dynamics 의 비선형성으로 **다른 형태의 분리**를 만듦.
- **Helm**: 세 층위가 뚜렷하게 분리. 특히 pendant leaf (초록) 가 매우 작은 영역에 **압축** — drift 효과로 degree 낮은 노드들이 뭉침. Ring (파랑) 은 중간, hub 는 별도. 이 "drift 로 인한 층위 압축"은 다른 거리에서 볼 수 없는 HST 만의 패턴.
- **Cycle 류 (balanced)**: SD²/τ → c 수렴 (Thm A). 원형 복원. Resistance / biharmonic 과 유사하지만 Monte Carlo noise 로 약간 불규칙.
- **Directed cycle**: 선형/호(arc) 형태의 독특한 임베딩. Walker 가 directed 엣지를 따르면서 block dynamics 가 방향 정보를 일부 간직. SP (산란) 이나 Resistance (완전 원형) 과 다른 중간적 구조.
- **핵심**: $f=0$ 에서도 block mechanism 이 degree heterogeneity 를 **비선형적으로 증폭** → classical spectral 거리와 질적으로 다른 기하를 만듦. 특히 drift/balance 이중 regime (Helm, Double Helm) 에서 "다층 구조의 자동 분리"는 HST 만의 특성.

# 4. 마무리

## 거리별 특성 요약

| 거리 | 포착하는 구조 | 강점 | 약점 |
|:---|:---|:---|:---|
| **SP** | 최단 경로 | 명료, 빠름 | bottleneck, 1-경로 과의존 |
| **Diffusion** | multi-scale 전이확률 | $t$ 로 scale 조절, directed 수용 | $t \to \infty$ degenerate, $t$ 선택 민감 |
| **Resistance** | 전역 연결성 (all paths) | metric, Euclidean embedding | degree-only ultrametric 수렴, symmetric 필요 |
| **Biharmonic** | 저주파 global structure | smooth, mesh 최적 | symmetric 필요, resistance 와 유사 |
| **Hitting time** | 방향성 + 접근 난이도 | **유일한 비대칭 출력**, directed 자연 | metric 아님, degree 스케일 의존 |
| **HST ($f=0$)** | block dynamics + degree 구조 | 비선형, drift/balance 동시 포착 | Monte Carlo (느림), $\tau$ 수렴 필요 |

## 어떤 그래프 구조에서 어떤 거리가 의미있나

| 그래프 특성 | 추천 거리 | 이유 |
|:---|:---|:---|
| **정규 그래프** (cycle, grid) | SP 또는 diffusion | degree 균등 → 대부분 거리가 비슷. SP 가 가장 간단 |
| **degree heterogeneity 큰** (star, hub-spoke) | Resistance 또는 HST | SP 는 bottleneck, diffusion 은 scale 민감. HST 는 drift regime 으로 degree 차이를 정량화 |
| **다층 계층** (helm, tree) | HST | Thm A+B 동시 작동으로 층위 간 (drift) + 층위 내 (balance) 분리 |
| **Directed graph** | Hitting time (비대칭) 또는 Diffusion | Resistance/biharmonic 은 undirected 전용. Hitting time 이 방향성 보존에 가장 강력 |
| **가중치 연속 변화** (Gaussian kernel) | Diffusion 또는 Biharmonic | spectral 계열이 weight 변화를 smooth 하게 반영 |
| **대규모 sparse** | PPR 또는 SP | $O(n^3)$ 인 spectral 방법은 비실용적 |
| **신호 $\mathbf y$ 와 결합** | **HST ($f \neq 0$)** | 유일한 intrinsic signal-aware metric |

## 핵심 교훈

1. **정규 그래프에서는 대부분의 거리가 비슷한 임베딩을 만든다.** Parity Cycle (5), Outlier Ring (8) 에서 SP, resistance, biharmonic, hitting, HST 모두 원형을 복원. 예외: Diffusion ($t=10$) 은 나선 왜곡.

2. **Degree heterogeneity 가 거리 간 차이를 만든다.** Star 에서 SP 는 "hub 중심 + 균등 leaf 원"이지만, Diffusion 은 "hub 극단 분리 + leaf 응축", HST 는 "drift 로 hub 더 멀리". Helm 에서 HST 만이 pendant leaf 를 작은 군집으로 압축하는 비선형 패턴을 보임.

3. **Directed graph 에서 거리별 실패 모드가 극적으로 다르다.** Directed Cycle 에서:
   - **SP, Diffusion → 산란** (대칭화 시 모든 쌍 거리 동일 → MDS 무의미)
   - **Resistance, Biharmonic → 완벽한 원형** (symmetrize 로 방향 완전 제거, 구조는 보존)
   - **Hitting time → 원형 + 약간의 비대칭 흔적** (방향성 일부 보존)
   - **HST → 호(arc) 형태** (block dynamics 가 방향 정보를 독특하게 인코딩)

4. **HST ($f=0$) 의 고유 기여**: block mechanism 의 비선형성이 classical spectral 거리와 질적으로 다른 기하를 만든다. 특히 **(a)** degree heterogeneity 가 큰 그래프에서 drift/balance 이중 regime 으로 다층 구조를 자동 분리, **(b)** directed graph 에서 SP/diffusion 과 다른 (산란이 아닌) 구조적 임베딩을 산출.

5. **$f=0$ 은 출발점이다.** 이 포스트에서는 그래프 구조만 봤지만, HST 의 진짜 기여는 $f \neq 0$ — 신호와 그래프의 결합. $f=0$ 에서 보인 구조 위에 신호가 얹히면 어떤 기하가 만들어지는지는 별도 포스트에서 다룬다.
