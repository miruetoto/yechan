# 1. 도입

그래프 $\mathcal G = (\mathcal V, \mathcal E, \mathbf W)$ 위에서 노드 쌍 $i, j$ 사이의 "거리"를 어떻게 정의할 것인가? 단일 정답은 없다. 거리를 재는 방식에 따라 같은 그래프에서도 서로 다른 기하를 보게 되고, downstream task(임베딩, 클러스터링, 이상 탐지)의 질이 달라진다.

좋은 그래프 거리의 바람직한 성질:

| 성질 | 설명 |
|:---|:---|
| (i) 엣지 가중치 존중 | 가중치가 큰 엣지는 "가까움"을 의미 |
| (ii) 전역 구조 반영 | 한 경로에만 의존하지 않고 전체 연결 패턴을 봄 |
| (iii) 노이즈 둔감 | 엣지 하나의 추가/삭제에 robust |
| (iv) 계산 가능 | $O(n^3)$ 이하로 모든 쌍 계산 가능 |
| (v) 해석 가능 | 물리적/확률적 의미가 명확 |

한 가지가 전부를 만족하지 못하므로 여러 family 가 공존한다.

이 포스트는 그래프 도메인 위의 **주요 거리 5종**을 다음 순서로 리뷰한다:

1. **도입**
2. **여러가지 거리** — 정의와 성질 (수학적 정의, spectral 표현, 물리적 해석, 한계)
3. **시뮬레이션 연구**
   - 3.1 테스트 그래프 (24개)
   - 3.2 분석 도구 (3×3 패널 9종)
   - 3.3 시뮬레이션 결과 (거리별)
4. **마무리** — 종합 / 요약 / 핵심 교훈

# 2. 여러가지 거리

## 2.1 Shortest Path distance (SP)

$$d_{\mathrm{sp}}(i, j) = \min_{\text{path }i \to j} \sum_{e \in \text{path}} w_e^{-1}$$

| 항목 | 내용 |
|:---|:---|
| 물리적 해석 | "가장 빠른 한 경로"의 비용 |
| Spectral 표현 | 없음 (Laplacian으로 환원 불가) |
| metric? | ✓ (undirected), quasi-metric (directed) |
| 파라미터 | 없음 |
| 계산 | Dijkstra $O((|V|+|E|)\log|V|)$ |
| 장점 | 명료, 빠름, triangle inequality |
| **한계** | 한 경로에 과의존, 노이즈 취약, bottleneck 그래프에서 정보 유실 |
| directed | $d(i,j) \neq d(j,i)$. 대칭화 시 directed cycle에서 **모든 쌍 거리 $\approx n/2$** → MDS 산란 |

---

## 2.2 Diffusion distance (Coifman–Lafon 2006)

$$d_t^2(i, j) = \sum_k \frac{(P^t_{ik} - P^t_{jk})^2}{\pi_k}$$

$P = D^{-1}W$ (row-stochastic), $\pi$ = stationary distribution.

| 항목 | 내용 |
|:---|:---|
| 물리적 해석 | "두 출발점의 $t$-step random walk 분포 차이" |
| Spectral 표현 | $f(\lambda) = (1-\lambda)^{2t}$ |
| metric? | ✓ |
| 파라미터 | $t$ (diffusion time: local↔global) |
| 계산 | $O(n^3)$ |
| 장점 | Multi-scale, directed 수용 |
| **한계** | (1) $t \to \infty$에서 $d_t \to 0$ (degenerate). (2) $t$ 선택 민감. (3) Directed cycle에서 **rotational symmetry trap** → 모든 쌍 거리 상수 |

---

## 2.3 Effective Resistance (Resistance distance)

$$R_{\mathrm{eff}}(i, j) = L^\dagger_{ii} + L^\dagger_{jj} - 2L^\dagger_{ij} = \sum_{k \geq 1} \frac{(\psi_k(i)-\psi_k(j))^2}{\lambda_k}$$

| 항목 | 내용 |
|:---|:---|
| 물리적 해석 | "전기회로에서 $i, j$ 사이 등가 저항" |
| Spectral 표현 | $f(\lambda) = 1/\lambda$ |
| metric? | ✓ (Euclidean embedding 가능) |
| 파라미터 | 없음 |
| 계산 | $O(n^3)$ (pseudoinverse) |
| 장점 | All-path 반영, Euclidean 보장, 파라미터 free |
| **한계** | (1) **Symmetric $W$ 요구**. (2) 대규모에서 $R \approx 1/d_i + 1/d_j$ (degree-only ultrametric 수렴, von Luxburg et al. 2014) |
| Commute time | $C_{ij} = \mathrm{vol}(\mathcal G) \cdot R_{\mathrm{eff}}(i,j)$ → MDS 동일. 이 포스트에서는 resistance만 사용 |

---

## 2.4 Biharmonic distance (Lipman–Rustamov–Funkhouser 2010)

$$d_{\mathrm{bih}}^2(i,j) = \sum_{k \geq 1} \frac{(\psi_k(i)-\psi_k(j))^2}{\lambda_k^2}$$

| 항목 | 내용 |
|:---|:---|
| 물리적 해석 | Resistance의 "squared penalty" — 저주파 global structure 강조 |
| Spectral 표현 | $f(\lambda) = 1/\lambda^2$ |
| metric? | ✓ |
| 파라미터 | 없음 |
| 장점 | 저주파 강조로 cluster boundary 선명, 3D mesh de facto |
| **한계** | Symmetric $L$ 요구. 소규모에서 resistance와 거의 동일 |

---

## 2.5 Hitting time

$$H_{ij} = \mathbb E_i[\tau_j], \quad \tau_j = \inf\{t \geq 0 : X_t = j\}$$

Closed-form: $Z = (I - P + \mathbf 1 \pi^\top)^{-1}$, $H_{ij} = (Z_{jj} - Z_{ij})/\pi_j$.

| 항목 | 내용 |
|:---|:---|
| 물리적 해석 | "$i$에서 $j$까지 random walk 기대 도달 시간" |
| metric? | **✗** (비대칭: $H_{ij} \neq H_{ji}$, triangle inequality 불성립) |
| 파라미터 | 없음 |
| **핵심 강점** | **유일하게 방향성을 output에 보존** |
| **한계** | Metric 아님 → MDS에 대칭화 필수. Degree 스케일 의존: $H_{ij} \propto 1/\pi_j$ |
| Star 예시 | $H(\text{leaf} \to \text{hub}) = 1$, $H(\text{hub} \to \text{leaf}_k) = 12$ |

---

## 2.6 계열 분류 — Spectral filter 통합

Walk-based + Algebraic 거리는 **spectral filter**로 통일:

$$d_f^2(i,j) = \sum_{k \geq 1} f(\lambda_k) (\psi_k(i) - \psi_k(j))^2$$

| 이름 | $f(\lambda)$ | 파라미터 | 저주파 강조 |
|:---|:---|:---|:---|
| Diffusion | $(1-\lambda)^{2t}$ | $t$ | $t$ 의존 |
| Heat kernel | $e^{-t\lambda}$ | $t$ | $t$↑ → 강 |
| PPR | $\alpha^2 / (1-(1-\alpha)(1-\lambda))^2$ | $\alpha$ | $\alpha$↓ → 강 |
| Resistance | $1/\lambda$ | — | 중간 |
| Biharmonic | $1/\lambda^2$ | — | 강 |

**Hitting time은 이 표에 없다.** 비대칭 output이므로 spectral filter(대칭)로 표현 불가.

| Family | 거리 | 핵심 기제 |
|:---|:---|:---|
| **Path** | SP | 최단 경로 |
| **Walk** | Diffusion, Heat, PPR | 전이확률 비교 |
| **Algebraic** | Resistance, Biharmonic | $L$ 스펙트럼 필터 |
| **Probabilistic** | Hitting, Commute | 마르코프 정지 시간 |

## 3.2 분석 도구

각 그래프 예제에 대해 **3×3 = 9가지 시각화**를 한 패널에 모은다. 세 행은 각각 "그래프 자체 / 거리 임베딩 / 거리행렬 특성"을 본다.

### 3.2.A 그래프 자체 (1행)

#### 3.2.1 Original graph

$(\mathcal V, \mathcal E)$ 의 직관적 시각화. 노드는 무지개색(ring/path 류), hub-spoke 류에서는 hub(빨강) + spoke(파랑/초록/보라) 구분. **Directed 엣지**는 빨간 화살표(→), **bidirectional 엣지**는 회색 선(↔).

**용도**: 그래프의 위상(topology) 자체를 확인. 어떤 노드가 hub인가, ring/path인가, 방향성이 어디 있는가.

#### 3.2.2 $W$ heatmap — 가중 행렬

$W \in \mathbb R^{n \times n}$ 을 그대로 히트맵으로 시각화. $W_{ij}$ = 엣지 $i \to j$의 **similarity** (큰 값 = 가까움).

- Cycle/path: super/sub-diagonal에 얇은 띠
- Hub-spoke: 첫 행/열에 집중
- Gaussian: 대각선 주변으로 연속적 그라데이션
- Directed: 비대칭 ($W \neq W^\top$)

**용도**: 그래프의 **국소(local) 구조** 확인. Sparse / dense, 방향성 유무, 가중치 분포.

#### 3.2.3 $D$ heatmap — 거리 행렬

특정 metric (SP, Diff, Res, …)으로 계산된 $D \in \mathbb R^{n \times n}$. $D_{ij}$ = 노드 $i, j$ 사이 **distance** (큰 값 = 멈).

- W와 **역관계**: similarity → distance
- W는 sparse, D는 dense (모든 쌍에 대해 정의)
- 도달 불가 쌍은 $\infty$ (시각화에서 NaN 처리)

**용도**: 거리 metric의 **전역 효과** 확인. Block structure, 비대칭, degenerate(상수) 여부.

**$W$ vs $D$ 핵심 차이:**

|  | $W$ | $D$ |
|:--|:--|:--|
| 의미 | similarity (입력) | distance (출력) |
| 국소성 | local (sparse) | global (dense) |
| 방향성 | 그대로 보존 | metric에 따라 사라지거나 보존 |

---

### 3.2.B 거리행렬 특성 (3행)

#### 3.2.4 Laplacian spectrum

##### Laplacian $L$이란

그래프 $\mathcal G = (\mathcal V, \mathcal E, \mathbf W)$ ($n$개 노드, 가중치 행렬 $W$)에 대해 **차수 행렬** $D$를 다음과 같이 정의한다:

$$D = \mathrm{diag}(d_1, d_2, \ldots, d_n), \qquad d_i = \sum_{j} W_{ij}$$

즉 $D$는 대각 성분이 각 노드의 차수인 대각행렬.

**조합 Laplacian** (combinatorial Laplacian):

$$L = D - W$$

성분으로 쓰면:

$$L_{ij} = \begin{cases} d_i & i = j \\ -W_{ij} & i \neq j,\ (i,j) \in \mathcal E \\ 0 & \text{otherwise} \end{cases}$$

**대안 형태 (정규화 버전)**:

- **Symmetric normalized**: $L_{\mathrm{sym}} = D^{-1/2} L D^{-1/2} = I - D^{-1/2} W D^{-1/2}$
- **Random-walk normalized**: $L_{\mathrm{rw}} = D^{-1} L = I - D^{-1} W = I - P$

본 포스트에서는 별도 언급 없으면 **조합 Laplacian** $L = D - W$를 사용. (Directed graph는 $L_s = (L + L^\top)/2$로 대칭화.)

##### $L$의 핵심 성질

$W$가 대칭이면 $L$도 **대칭** + **positive semi-definite (PSD)**. 따라서 고유값이 모두 $\geq 0$이고 실수 고유벡터 직교 기저 존재:

$$L = \sum_{k=0}^{n-1} \lambda_k\, \psi_k \psi_k^\top, \qquad 0 = \lambda_0 \leq \lambda_1 \leq \cdots \leq \lambda_{n-1}$$

##### 왜 $\lambda_0 = 0$인가

상수 벡터 $\mathbf 1 = (1, 1, \ldots, 1)^\top$에 대해

$$L \mathbf 1 = (D - W) \mathbf 1$$

각 항을 전개:

$$(D \mathbf 1)_i = d_i, \qquad (W \mathbf 1)_i = \sum_j W_{ij} = d_i$$

따라서

$$L \mathbf 1 = D\mathbf 1 - W\mathbf 1 = \mathbf 0$$

즉 $\mathbf 1$이 고유값 $0$의 고유벡터. **상수 함수는 항상 graph Fourier basis의 첫 번째 mode** — DC 성분에 해당.

##### 고유벡터의 직관 — Graph Fourier Basis

$\psi_k$는 그래프 위의 **smooth function** ($\lambda_k$ 작음) 또는 **빠르게 진동하는 function** ($\lambda_k$ 큼)을 나타낸다.

- $\psi_0$: 모든 노드 동일 값 (DC, 가장 smooth)
- $\psi_1$ (Fiedler vector): 그래프를 두 덩어리로 나누는 가장 자연스러운 분할
- $\psi_k$ (큰 $k$): 인접 노드 간 값이 부호 반전하는 oscillation

**Rayleigh quotient** 관점:

$$\lambda_k = \min_{\substack{\psi \perp \psi_0, \ldots, \psi_{k-1} \\ \|\psi\|=1}} \psi^\top L \psi$$

여기서

$$\psi^\top L \psi = \sum_{(i,j) \in \mathcal E} W_{ij} (\psi_i - \psi_j)^2$$

즉 $\lambda_k$는 **인접 노드 간 값 차이의 가중 제곱합을 최소화하는 $k$번째 mode의 "거칠기"**. 작은 $\lambda_k$ → smooth, 큰 $\lambda_k$ → rough.

##### Spectrum 플롯의 핵심 정보

$L$의 고유값 $0 = \lambda_0 \leq \lambda_1 \leq \cdots \leq \lambda_{n-1}$을 정렬하여 플롯하면:

- **$\lambda_1$ — algebraic connectivity (Fiedler value, Fiedler 1973)**:
  - $\lambda_1 = 0$ ⟺ 그래프가 **disconnected** (2개 이상의 연결 성분)
  - $\lambda_1 > 0$ ⟺ 연결 그래프, 값이 클수록 "잘 연결됨"
  - Cheeger 부등식: $\lambda_1$이 그래프 expansion (병목 정도)에 lower bound

- **$\lambda_k - \lambda_{k-1}$ 큰 gap**:
  - $k$번째 자리에 spectral gap이 있으면 그래프가 대략 **$k$개 클러스터**로 분리 가능
  - Spectral clustering의 원리: $\psi_1, \ldots, \psi_{k-1}$의 embedding 후 $k$-means

- **선형(코사인) 증가** $\lambda_k \approx 2(1 - \cos(2\pi k/n))$:
  - Cycle $C_n$: DCT 패턴
  - Path $P_n$: 유사한 코사인 패턴
  - 1D continuous Laplacian의 이산 근사

- **계단형 (large gaps at multiple positions)**:
  - 다층/계층 구조 (Helm, D-Helm, hub-spoke, cylinder)
  - 각 step의 위치가 클러스터 수에 대응

- **하한 / 상한**:
  - $\lambda_1 \leq n \cdot \min_i d_i / (n-1)$ (Fiedler)
  - $\lambda_{n-1} \leq 2 \max_i d_i$

##### 거리와의 연결 — 왜 spectral 거리 거동을 이걸로 예측할 수 있나

본 포스트의 §2.3 Resistance / §2.4 Biharmonic 거리는 spectral filter 형태로 직접 쓸 수 있다:

$$d_f^2(i, j) = \sum_{k \geq 1} f(\lambda_k) (\psi_k(i) - \psi_k(j))^2$$

- Resistance: $f(\lambda) = 1/\lambda$ → 작은 $\lambda_k$ (smooth mode)가 크게 기여
- Biharmonic: $f(\lambda) = 1/\lambda^2$ → 더더욱 저주파 강조
- Diffusion: $f(\lambda) = (1-\lambda)^{2t}$ → $t$ 작으면 모든 mode, $t$ 크면 가장 작은 비자명 $\lambda_1$ mode만 살아남음

따라서 **$\lambda_1$이 작은 그래프**는 resistance가 큰 값 (잘 연결되지 않아서 멀리 보임), **계단형 spectrum**은 거리행렬에 명확한 block 구조를 만든다.

**Hitting time**은 spectral filter로 표현되지 않지만 (비대칭), $V$-norm 수렴 속도가 spectral gap $\lambda_1$로 결정되므로 간접적으로 spectrum에 종속.

**용도 요약**: 거리 metric 계산 **이전**에 그래프의 본질적 특성 (연결성, 클러스터 수, 차원성)을 파악. Resistance / Biharmonic / Diffusion 같은 spectral 계열 거리의 거동을 예측.

#### 3.2.5 Ring profile — 참조 노드에서의 거리 곡선

$D[0, j]$를 $j = 0, \ldots, n-1$에 대해 플롯하고 min-max normalize. 곡선의 **형태**를 보면 metric 특성 즉시 드러남:

- Inverted-V: geodesic 비례 (SP, Resistance, Biharmonic, Hitting on cycles)
- 톱니 / 나선: local oscillation (Diffusion 작은 $t$)
- 단조 증가 후 급락: directed SP/Hit on cycle
- 수평선: degenerate (Diffusion 큰 $t$, directed cycle)

**용도**: Ring 구조 그래프(cycle, path)에서 metric별 형태 비교에 특히 강력. 다른 구조에서도 "node 0에서 본 거리 분포"로 활용.

#### 3.2.6 Symmetry scatter — $D[i,j]$ vs $D[j,i]$

각 쌍 $(i, j)$에 대해 $(D_{ij}, D_{ji})$ 산점. 대각선 $y=x$ 위에 있으면 대칭, 벗어나면 비대칭.

함께 표시:
$$\rho_{\mathrm{asym}}(D) = \frac{\|D - D^\top\|_F}{\|D + D^\top\|_F} \in [0, 1]$$

$0$ = 완전 대칭, $\to 1$ = 강한 비대칭.

**용도**: Directed graph에서 각 metric이 방향 정보를 output에 얼마나 보존하는지 **정량화 + 시각화** 동시.

### 3.2.C 임베딩 (2행)

3가지 서로 다른 원리로 같은 그래프를 $\mathbb R^2$에 내장.

#### 3.2.7 Spectral embedding (Laplacian eigenmaps)

그래프 Laplacian $L = D_{\deg} - W$ (또는 $L_s = (L+L^\top)/2$)의 첫 2개 비자명 eigenvector $\psi_1, \psi_2$로 좌표 (Belkin-Niyogi 2003).

$$x_i = (\psi_1(i), \psi_2(i))$$

**원리적 차이**:
- MDS / Sammon: **거리 기반** ($D$ 사용)
- Spectral: **스펙트럼 기반** ($W$ → $L$ → 고유벡터)

**용도**: 거리 metric을 우회한 graph-intrinsic 임베딩. **MDS와 같은 그래프에서 다른 결과**를 줄 때가 많다 (예: directed cycle에서 MDS 산란 vs Spectral 완벽 원).

#### 3.2.8 Sammon dual MDS — 비대칭 분리 임베딩

각 노드를 **source $p_i$** (원)와 **sink $q_i$** (삼각형) 두 점으로 분리하여 $\mathbb R^2$에 임베딩. 비대칭 행렬을 위해 설계:

$$\min_{p, q} \sum_{i,j: \text{finite}} (D_{ij} - \|p_i - q_j\|_2)^2$$

(Sammon 1969 의 dual variant; 표준 Sammon은 대칭, dual은 비대칭 거리에 확장.)

**용도**: $D[i,j]$와 $D[j,i]$가 다른 경우 source/sink 좌표 분리가 비대칭의 기하학적 해석을 줌. 대칭이면 $p_i \approx q_i$로 두 점이 겹침.

#### 3.2.9 cMDS 2D — 거리 보존 임베딩

Classical MDS: $D$에 double centering 적용 후 top-2 eigenvalue로 좌표. 비대칭 $D$는 $(D+D^\top)/2$로 대칭화 후 적용.

$$\min_X \sum_{i<j} (D_{ij} - \|x_i - x_j\|_2)^2$$

**용도**: "거리 metric이 만들어낸 기하"를 직관적 시각화. 원형 복원 / 산란 / 군집 분리 등.

**한계**: 대칭 행렬만 처리 → 비대칭 정보 유실.

### 3.3.2 Diffusion Distance

### MDS 임베딩 — 24개 그래프 ($t=10$)

![Diff MDS](attachments/260516_1cdb82_32.png)

- **1-3 Star bidir**: hub가 leaf 군집에서 **극단적으로 분리**. $P^{10}$ 행이 모든 leaf에서 거의 동일 → leaf 응축.
- **2-1 / 2-2 Wheel directed**: $P^t$ 비대칭이지만 output은 대칭 → directed 정보 일부만 남음.
- **3-3 / 4-3 Helm / D-Helm bidir**: hub 극단 분리 + ring/pendant 응축.
- **6-2 Bidir Ring**: **나선(spiral) 왜곡** — $t=10$이 $n=60$에 비해 짧아 local 패턴만 반영.
- **6-1 Dir Ring**: **degenerate** — Shift matrix의 $P^t$도 shift → 모든 쌍 거리 상수.

### $t$-sweep — 대표 그래프

![Diff t-sweep](attachments/260516_1cdb82_33.png)

$t \in \{1, 2, 4, 8, 16, 32, 64\}$ × {1-3 Star, 6-1 Dir Ring, 6-2 Bidir Ring, 7-1 Cyl Inter-dir}:

- **Star (1행)**: $t=1$ local → $t=4$ hub 분리 → $t=16$ 극단 → $t=64$ **collapse**.
- **Dir Ring (2행)**: **모든 $t$에서 degenerate** — rotational symmetry trap.
- **Bidir Ring (3행)**: $t=1$ 이웃만 → $t=4\sim 8$ 나선 → $t=16$ 원에 수렴 → $t=64$ collapse 시작.
- **Cyl Inter-dir (4행)**: $t$ 작을 때 ring 별 분리 보이다가 $t$ 커지면 점차 한 군집으로.

→ **최적 $t$ 구간이 좁다.** 그래프 크기/구조에 따라 달라지며, directed에서는 아예 실패.

**Diffusion 요약**: Multi-scale의 강점이 있으나 (1) $t$ 선택이 결정적, (2) $t \to \infty$ degenerate, (3) directed에서 rotational symmetry trap.

### 3.3.3 Resistance Distance

### MDS 임베딩 — 24개 그래프

![Res MDS](attachments/260516_1cdb82_34.png)

Resistance는 정의상 symmetric ($L_s = (L+L^\top)/2$). 따라서:

- **모든 directed 그래프** (1-1, 1-2, 2-1, 2-2, 3-1, 3-2, 4-1, 4-2, 5-1, 6-1, 7-1): 자동으로 symmetrize → undirected 등가물의 MDS와 거의 동일.
- **6-1 Dir Ring**: $(W+W^\top)/2$ = bidirectional cycle → **완벽한 원형** (SP/Diffusion 산란/degenerate와 대비).
- **Star/Wheel/Helm/D-Helm**: hub 중심, ring/leaf 외곽 분리 — Degree 차이 반영하여 SP보다 선명.
- **7-2 Cyl Inter-bidir**: 5 ring 별 응집 구조 깔끔하게 시각화.
- **5-3, 6-3 Gaussian**: 가중치 연속 변화를 smooth하게 반영.

**Resistance 요약**: 파라미터 free, Euclidean, all-path 반영. 단 (1) symmetric 요구 → 방향 정보 완전 유실, (2) 대규모에서 degree-only ultrametric 수렴.

### 3.3.4 Biharmonic Distance

### MDS 임베딩 — 24개 그래프

![Bih MDS](attachments/260516_1cdb82_35.png)

Resistance와 같은 spectral family ($1/\lambda$ vs $1/\lambda^2$). 차이는:

- **소규모** (Star, Wheel): Resistance와 거의 동일 — 두 거리의 차이 미미.
- **다층 구조** (Helm, D-Helm): 층위 간 분리가 Resistance보다 약간 더 뚜렷 — 저주파 강조.

- **7-2 Cyl Inter-bidir**: 5 ring 응집이 Resistance보다 더 선명 — cluster boundary 강조.

**Biharmonic 요약**: Resistance의 저주파 강화 버전. 소규모에서 차이 미미. 3D mesh의 de facto이나 graph 분석에서는 Resistance로 충분.

# 4. 마무리

## 거리별 특성 요약

| 거리 | 포착 구조 | 강점 | 약점 | 최적 사용처 |
|:---|:---|:---|:---|:---|
| **SP** | 최단 경로 | 명료, 빠름, 파라미터 free | bottleneck, directed 산란 | 정규 그래프 baseline |
| **Diffusion** | multi-scale 전이확률 | $t$로 scale 조절 | $t \to \infty$ degenerate, directed trap | undirected multi-scale |
| **Resistance** | 전역 연결성 | metric, Euclidean, 파라미터 free | degree-only 수렴, symmetric 요구 | undirected 전역 metric |
| **Biharmonic** | 저주파 global | cluster boundary 강조 | resistance와 유사 | 3D mesh |
| **Hitting** | 방향성 + 접근 난이도 | **유일 비대칭 output** | metric 아님 | directed 분석 |

## 어떤 그래프 구조에서 어떤 거리가 의미있나

| 그래프 특성 | 추천 거리 | 이유 |
|:---|:---|:---|
| **정규 그래프** (cycle, grid) | SP 또는 Diffusion | degree 균등 → 대부분 거리가 비슷. SP가 가장 간단 |
| **degree heterogeneity 큰** (star, hub-spoke) | Resistance | SP는 bottleneck, Diffusion은 scale 민감 |
| **다층 계층** (helm, tree) | Resistance 또는 Biharmonic | 층위 간 degree 차이를 반영한 분리 |
| **Directed graph** | Hitting time | 유일하게 방향성을 output에 보존 |
| **가중치 연속 변화** (Gaussian kernel) | Diffusion 또는 Biharmonic | spectral 계열이 weight 변화를 smooth하게 반영 |
| **대규모 sparse** | PPR 또는 SP | $O(n^3)$인 spectral 방법은 비실용적 |

## 핵심 교훈

1. **정규 그래프에서는 대부분의 거리가 동일한 임베딩을 준다.** 차이는 파라미터 민감도(diffusion의 $t$)에서만 발생.

2. **Degree heterogeneity가 거리 간 차이를 만든다.** Star에서 SP는 2-level block, Diffusion은 leaf 응축 — 같은 그래프를 다르게 본다.

3. **Directed graph에서 거리별 실패 모드가 극적으로 다르다.**
   - SP, Diffusion → 산란/degenerate
   - Resistance, Biharmonic → 완벽한 원 (방향 제거)
   - Hitting time → 원 + 비대칭 흔적 (방향 보존)

4. **Diffusion $t$-sweep**: "too small → sweet spot → degenerate"의 좁은 구간. 그래프 크기/구조에 따라 최적 $t$이 달라지며, directed에서는 모든 $t$에서 실패.

5. **$\rho_{\mathrm{asym}}$ 분석**: Directed에서 비대칭 output은 SP와 Hitting time 뿐. Walk-based는 rotational symmetry trap, algebraic은 $L_s$ symmetrization이 원인.

# Appendix. 거리 이론 — 3대 교재 발췌

회사 `ref/` 폴더의 세 책을 정독하면서 본 포스트의 거리들과 직접 연결되는 이론 결과를 발췌·정리한다.

## A. Brémaud (2020), *Markov Chains*

### A.1 그래프 위 random walk의 정상 분포 (§8.1.2)

연결된 무방향 그래프 $\mathcal G = (\mathcal V, \mathcal E)$, 차수 $d_i$. 엣지를 양방향 directed로 분할하여 transition $p_{ij} = 1/d_i$ 부여.

**정상 분포 (Theorem):**
$$\pi(i) = \frac{d_i}{2|\mathcal E|}$$

증명은 detailed balance $\pi(i) p_{ij} = \pi(j) p_{ji}$ ($\Leftrightarrow$ $1/d_i \cdot d_i = 1/d_j \cdot d_j$)로 즉시.

**HST와의 연결**: 이 결과가 HST의 default fall 분포 $\mu_0 = \pi = d_i/2|\mathcal E|$ (degree-proportional)의 출처. Algorithm 1의 reset 단계에서 사용.

### A.2 Effective Resistance (§8.3.1, Def. 8.3.1)

그래프를 전기회로로 해석: 엣지 $\{i,j\}$에 conductance $c_{ij} = w_{ij}$, 노드 $a$에 1V·노드 $b$에 0V 인가. 전위 $\Phi$가 만족:
$$\Phi(i) = \mathbb P_i(T_a < T_b)$$
(즉 $\Phi$ = "$i$에서 출발해 $b$ 보다 먼저 $a$ 도달 확률"). 정의:

$$R_{\mathrm{eff}}(a \leftrightarrow b) := \frac{\Phi(a)}{I_a}, \qquad I_a = \text{a에서 나가는 전류}$$

**Bremaud Exercise 8.4.14**: 노드 $a$의 commute time과 effective resistance 관계:
$$G_b(a) := \mathbb E_a\!\left[\sum_{n=0}^{\infty} \mathbf 1_{\{X_n = a\}} \mathbf 1_{\{n < T_b\}}\right] = C_a \cdot R_{\mathrm{eff}}(a \leftrightarrow b)$$

**HST와의 연결**: §2.3 Resistance distance의 전기회로 해석이 여기서 옴. §4.4 결과 "directed cycle에서 Resistance는 symmetrize 후 완벽한 원형 복원"의 이론적 배경.

### A.3 Mutual Time-Distance Matrix (§6.3.2, Theorem 6.3.6)

Bremaud은 hitting time 행렬을 **"mutual time-distance matrix"** $M = (m_{ij})$, $m_{ij} = \mathbb E_i[T_j]$ 로 명명. Fundamental matrix $Z = (I - P + \mathbf 1 \pi^\top)^{-1}$에 대해:

$$\boxed{\;m_{ij} = \mathbb E_i[T_j] = \frac{z_{jj} - z_{ij}}{\pi(j)}\;}$$

(Theorem 6.3.6)

**HST와의 연결**: 본 포스트 §2.5의 hitting time closed-form이 이 정리에서 직접 가져옴. Bremaud조차 hitting time을 "distance"라고 부르는 것이 §4.6 분석의 정당성을 강화.

### A.4 SLEM과 Mixing Time (§9.1.2, §9.3)

Reversible Markov chain $P$의 두 번째로 큰 고유값 modulus를 **SLEM** $\lambda_*$ 라 부른다 (second largest eigenvalue modulus). Perron–Frobenius:

$$\|P^n(x, \cdot) - \pi\|_{\mathrm{TV}} \leq C \cdot \lambda_*^n$$

**Mixing time**:
$$t_{\mathrm{mix}}(\varepsilon) := \min\{n : \max_x \|P^n(x, \cdot) - \pi\|_{\mathrm{TV}} \leq \varepsilon\}$$

이건 **total variation distance** 위에서의 거리 — 분포 간 거리이지 노드 간 거리는 아니지만 본 포스트의 diffusion distance와 직결 ($d_t^2(i,j)$가 $P^t$의 $\pi$-weighted L2이므로 mixing 후 0으로 수렴).

**HST와의 연결**: §2.2 Diffusion의 한계 "$t \to \infty$에서 $d_t \to 0$ degenerate"가 정확히 mixing 현상의 표현.

## B. Meyn–Tweedie (2009), *Markov Chains and Stochastic Stability*

### B.1 세 가지 등가 조건 (Preface, Theorem 16.0.2)

$\varphi$-irreducible aperiodic chain에 대해 **세 조건이 모두 등가**이며, 모두 **기하급수적 수렴**을 함의:

(A) **Geometric return time tail**: 어떤 small set $C$, $r > 1$에 대해 $\sup_{x \in C} \mathbb E_x[r^{\tau_C}] < \infty$

(B) **Geometric convergence**: 어떤 $M < \infty$, $\rho_C < 1$에 대해
$$\sup_{x \in C} |P^n(x, C) - P^\infty(C)| \leq M \rho_C^n$$

(C) **Geometric drift (Foster-Lyapunov)**: 어떤 함수 $V \geq 1$, $\beta > 0$에 대해
$$\int P(x, dy) V(y) \leq (1 - \beta) V(x) + \mathbf 1_C(x)$$

이 모두는 다음을 함의:
$$\sup_{|f| \leq V} \left| \int P^n(x, dy) f(y) - \int \pi(dy) f(y) \right| \leq R \cdot V(x) \cdot \rho^n$$

**HST와의 연결**: HST의 Snow Distance 수렴 증명 (회사 페이퍼팀 작업)에서 Foster-Lyapunov drift가 사용됨. 본 결과는 그 이론적 출처. **drift V가 곧 "거리에 가까움"을 측정**하므로 거리 이론과 직결.

### B.2 V-Uniform Ergodicity (§16.1, Theorem 16.1.5)

Chain $\Phi$가 **V-uniformly ergodic**이면 (즉 $\|P^n - \pi\|_V \to 0$), $V$-norm 거리에서 기하급수적 수렴:

$$\|P^n(x, \cdot) - \pi\|_V \leq R \cdot \rho^n \cdot V(x)$$

여기서 $V$-norm distance:
$$\|\mu - \nu\|_V := \sup_{|f| \leq V} \left| \int f \, d\mu - \int f \, d\nu \right|$$

**HST와의 연결**: 본 포스트 §3.4 cMDS, §3.6 Sym scatter 등이 다루는 거리는 **노드 간 거리** $d(i, j)$인 반면, V-norm은 **분포 간 거리**. 둘은 다른 층위이지만 — HST의 SD distance가 시간 평균으로 정의되므로 V-uniform ergodicity가 수렴 rate 결정.

### B.3 Doeblin's Condition (§16.2, Theorem 16.2.3)

$\psi$-irreducible aperiodic chain $\Phi$에 대해:

$$\Phi \text{ uniformly ergodic} \;\Longleftrightarrow\; \text{Doeblin 조건 성립}$$

**Doeblin 조건**: 어떤 확률측도 $\phi$, $m \geq 1$, $\varepsilon < 1$, $\delta > 0$에 대해
$$\phi(A) > \varepsilon \;\Longrightarrow\; P^m(x, A) \geq \delta \quad \forall x \in \mathsf X$$

**Theorem 16.2.4 (minorization → mixing rate)**: 만약 $P^m(x, A) \geq \nu_m(A)$ (전 공간이 small set)이면:
$$\|P^n(x, \cdot) - \pi\| \leq \rho^{n/m}, \qquad \rho = 1 - \nu_m(\mathsf X)$$

**HST와의 연결**: 페이퍼팀 ABC증명의 `proof_sd2_random_b.tex`에서 사용한 **Doeblin minorization 증명**이 정확히 이 결과의 응용. HST walker가 reset → fall로 인해 minorization 조건을 만족, 따라서 uniform ergodic.

### B.4 Drift Criterion (§16.3.1, Theorem 16.3.1)

Test function $V$가 (16.25)
$$\int P(x, dy) V(y) \leq \begin{cases} V(x) - 1 & x \in C^c \\ b & x \in C \end{cases}$$

만족하고 두 조건 (16.26), (16.27) 추가로 만족하면 $\Phi$는 $V^*$-uniformly ergodic ($V^* = e^{\delta V}$ for some $\delta < \beta$).

**핵심 아이디어**: $V$가 "어떤 set $C$로부터의 거리에 비례하는 함수"이면, 매 step마다 $V$ 평균이 줄어드는 것이 chain의 **stability + 기하급수 수렴**을 보장. 이게 "drift criterion = 거리 함수"의 등식.

**HST와의 연결**: $V = \Phi$ (Lyapunov function, snow height의 centered second moment) 의 drift 조건이 HST 증명의 핵심. **거리(snow distance)의 시간 평균 수렴**이 V-drift로 환원됨.

## C. Djurić & Richard (eds., 2018), *Cooperative and Graph Signal Processing*

### C.1 Partially Absorbing Random Walks (Ch 14, Theorem 14.2)

HST와 가장 직접적으로 닮은 모델. 노드 $i$에서 walker가 absorb될 확률 $p_{ii} = \alpha_i / (\alpha_i + d_i)$, 이웃으로 이동할 확률 $w_{ij}/(\alpha_i + d_i)$.

Absorption probability 행렬 $A = (L + \Lambda)^{-1} \Lambda$ ($\Lambda = \mathrm{diag}(\alpha_i)$).

**Theorem 14.2**: $\Lambda = \alpha I$이면 $\lim_{\alpha \to 0^+} (L + \alpha I)^{-1} \alpha = \frac{1}{n} \mathbf{11}^\top$ (균일 분포).

### C.2 Laplacian Regularized Kernel ↔ ParWalk ↔ PPR

| 방법 | Kernel | 흡수 capacity |
|:---|:---|:---|
| **Laplacian-reg** $(L + \alpha I)^{-1}$ | $\Lambda = I$ | $p_{ii} = \alpha/(\alpha + d_i)$ — degree 큰 노드일수록 작음 |
| **PPR** $(\alpha \mathbf e_i^\top + (1-\alpha) \mathbf p_i^\top P)$ | $\Lambda = D$ | $p_{ii} = \beta$ (constant) — degree 무관 |

GSP Ch 14 핵심 관찰: PPR는 degree로 편향되지만, $\Lambda = I$인 ParWalk는 degree 편향을 **상쇄** → cluster 구조가 분리되어 보임.

**HST와의 연결**:
- HST의 **block 메커니즘**이 GSP의 partial absorption과 유사한 역할
- HST의 fall 분포 $\mu_0 = $ degree-prop = PPR과 유사
- 단, HST는 **block이 height 의존적** (non-linear) → 어떤 ParWalk 식으로도 표현 불가
- 본 포스트 §4.4 결과 "Resistance는 degree-only 수렴"이 GSP에서도 동일하게 지적되는 한계

**거리 이론은 두 층위에서 작동:**

1. **노드 간 거리** $d(i, j)$ (본 포스트 §2-§4 주제): SP, Diffusion, Resistance, Biharmonic, Hitting
2. **분포 간 거리** $\|\mu - \nu\|$ (이 Appendix B 주제): Total Variation, V-norm, Wasserstein

두 층위는 별개로 보이지만 — Diffusion distance는 분포 간 거리($\|P^t_i - P^t_j\|_\pi$)를 노드 거리로 사용. Hitting time도 분포(첫 도달 시간 분포)의 평균. **그래프 위 거리는 모두 마르코프 체인의 분포 간 거리에서 파생**.

이게 HST에서 SD$(i,j) = \sum_\ell |h_i(\ell) - h_j(\ell)|^2$이 distance가 되는 이유 — height process가 마르코프 체인이고, drift를 통해 stationary 분포로 수렴하기 때문.
