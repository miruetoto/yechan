\(O_p\), \(o_p\)

- 전제조건 - \(X_1, X_2, \dots\) : 독립·동일분포(i.i.d.) 확률변수
- \(\mathbb{E}[X_i] = \mu, \ \mathrm{Var}(X_i) = \sigma^2 < \infty\) - 표본평균: \(\overline{X}n = \frac1n\sum{i=1}^n X_i\) - 표본합: \(S_n = \sum_{i=1}^n X_i\) - 중심극한정리(CLT)와 약한대수의법칙(WLLN) 사용 가능
