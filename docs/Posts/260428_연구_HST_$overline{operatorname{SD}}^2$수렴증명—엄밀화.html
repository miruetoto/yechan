0. 메모

260426_연구_HST_\(\overline{\operatorname{SD}}^2\)수렴증명—내가푼다 에서 narrative 로 푼 증명을 재구성. 증명 없이 넘어간 단계 모두 Lemma 로 명시하고 각 lemma의 증명을 채운다.

표기는 260407_연구_HST_눈이많이쌓이면그래프구조만반영 과 동일 — Round-skeleton, \(t_r\) = block-flag 시각, \(\tilde X_j := X_{t_r+j}\) (\(j = 1, \ldots, m_r\)).

1. 메인 정리

Theorem (\(\overline{\operatorname{SD}}^2\) 수렴). 연결 가중 그래프 \(\mathcal{G}\)와 파라미터 \((b, T_{max})\)가 주어질 때, 다음 drift 조건이 성립한다고 하자:

\[\Delta_{\mathrm{drift}} := (T_{max}{+}1)\alpha - \frac{2p_0}{n-1} < 0 \tag{DC}\]

여기서

  • \(\alpha := \|\boldsymbol{\mu}_0 - \mathbf{u}\|_1\) (차수 비균등도, \(\mathbf{u}\)는 균등분포),
  • \(\mu_{min} := \min_i \mu_0(v_i)\),
  • \(P_{RW,\min} := \min_{(u,w)\in\mathcal{E}}\,\deg(w)/\sum_{k\in\mathcal{N}_u}\deg(v_k)\),
  • \(p_0 := \mu_{min}\cdot P_{RW,\min}\) (1라운드 big-drop 확률 하한).

DC 가 만족되면 상수 행렬 \(C = [c_{ij}]_{n\times n}\), \(c_{ij} = c_{ij}(\mathcal{G}, b, T_{max}, \mathbf{y}\bmod b) \geq 0\) 이 존재하여, 임의의 초기 신호 \(\mathbf{y}\) 에 대해

\[\overline{\mathbf{SD}}^2(t) \;\xrightarrow{t\to\infty}\; C \quad \text{a.s.}\]

한계값 \(c_{ij}\) 는 초기 신호 \(\mathbf{y}\) 의 거시적 절대 스케일에는 독립이고, \(b\) 단위 미세 위상차 \(\mathbf{y}\bmod b\) 에만 종속.

2. 증명의 골격

본 정리 증명은 두 단계로 분해된다.

Step A (Height Recurrence). 높이차 마르코프 체인 \(\{S(t)\}\) 가 양의 재귀(positive recurrent) 임을 보임. 즉 어떤 결정적 상수 \(C > 0\) 이 존재하여 \(\{M(t) \leq C\}\) 영역으로 a.s. 무한히 자주 복귀.

Step B (Ergodic theorem). Step A + 비가약성(irreducibility) + 모멘트 조건 \(\mathbb{E}_\pi[(\delta_i-\delta_j)^2] < \infty\) 가 주어지면, 양의 Harris 재귀 마르코프 체인의 LLN (M&T Thm 17.1.7) 으로 시간평균 \(\overline{\operatorname{SD}}^2_{ij}(t) \to c_{ij}\) a.s.

본 글은 Step A 의 엄밀화에 집중. Step B 는 대원리만 §10에서 짧게 정리.

Step A 의 핵심은 다음 명제.

Proposition (Height Recurrence). DC 가 성립하면, \((\mathcal{G}, b, T_{max})\) 에만 의존하는 결정적 상수 \(C > 0\) 이 존재하여 높이차 과정 \(\{S(t)\}\) 가 유한 집합 \(\mathcal{B}_\Phi := \{S : \Phi(\boldsymbol{\delta}) \leq C_1\}\) 으로 a.s. 양의 재귀이다 (즉 \(\mathbb{E}[\tau_{\mathcal{B}_\Phi}] < \infty\)). 특히 \(M(t)\) 는 \(\{M \leq C\}\) 로 무한 자주 복귀.

전략: Foster–Lyapunov 정리 (§9) 를 round-skeleton \(\{S(t_r)\}\) 위에서 적용. Lyapunov 함수는 높이 분산 \(\Phi(t) := \sum_i \hbar(i,t)^2\). 핵심 산출물은 round drift 부등식:

\[\mathbb{E}[\Phi(t_{r+1}) - \Phi(t_r) \mid S(t_r)] \;\leq\; b\,M(t_r)\,\Delta_{\mathrm{drift}} + C_3 \tag{$\star\star$}\]

이를 도출하기 위해 §3–§7 의 Lemma 들이 차례로 동원된다.

3. Lemma 1 — 1-step \(\Phi\) drift (post-+b)

Lemma 1. Lyapunov 함수 \(\Phi(t) := \sum_{i=1}^n \hbar(i,t)^2\), \(\hbar(i,t) := h(v_i,t) - \bar h(t)\) 라 하자. 시각 \(t+1\) 에 노드 \(\ell = X_{t+1}\) 이 +b 를 받으면

\[\Phi(t+1) - \Phi(t) \;=\; 2b\,\hbar(\ell, t+1) - \frac{(n-1)b^2}{n} \tag{$\dagger$}\]

Proof. \(X_{t+1} = \ell\) 이면 노드별 변화는

\[\hbar(\ell, t+1) = \hbar(\ell, t) + b\frac{n-1}{n}, \qquad \hbar(i, t+1) = \hbar(i, t) - \frac{b}{n} \;\;(i \neq \ell).\]

이를 역방향 으로 풀어 +b 직전 값을 +b 직후 값으로 표현:

\[\hbar(\ell, t) = \hbar(\ell, t+1) - b\frac{n-1}{n}, \qquad \hbar(i, t) = \hbar(i, t+1) + \frac{b}{n} \;\;(i \neq \ell). \tag{$*$}\]

차분 \(\Phi(t+1) - \Phi(t) = \sum_i [\hbar(i, t+1)^2 - \hbar(i, t)^2]\) 의 각 항에 (\(*\)) 를 대입:

  • \(i = \ell\): \(\hbar(\ell, t+1)^2 - \big(\hbar(\ell, t+1) - \tfrac{b(n-1)}{n}\big)^2 = 2\hbar(\ell, t+1)\cdot\tfrac{b(n-1)}{n} - \tfrac{b^2(n-1)^2}{n^2}\).
  • \(i \neq \ell\): \(\hbar(i, t+1)^2 - \big(\hbar(i, t+1) + \tfrac{b}{n}\big)^2 = -2\hbar(i, t+1)\cdot\tfrac{b}{n} - \tfrac{b^2}{n^2}\).

\(\sum_i \hbar(i, t+1) = 0\) 이므로 \(\sum_{i\neq\ell}\hbar(i, t+1) = -\hbar(\ell, t+1)\). 따라서 \(i \neq \ell\) 항을 합산하면

\[\sum_{i\neq\ell}[\,\cdot\,] = -\frac{2b}{n}\sum_{i\neq\ell}\hbar(i, t+1) - (n-1)\frac{b^2}{n^2} = \frac{2b}{n}\hbar(\ell, t+1) - \frac{(n-1)b^2}{n^2}.\]

전체 합:

\[\begin{aligned} \Phi(t+1) - \Phi(t) &= \frac{2b(n-1)}{n}\hbar(\ell, t+1) - \frac{b^2(n-1)^2}{n^2} + \frac{2b}{n}\hbar(\ell, t+1) - \frac{(n-1)b^2}{n^2} \\ &= 2b\,\hbar(\ell, t+1)\cdot\Big[\frac{n-1}{n} + \frac{1}{n}\Big] - \frac{b^2(n-1)[(n-1)+1]}{n^2} \\ &= 2b\,\hbar(\ell, t+1) - \frac{(n-1)b^2}{n}. \quad\square \end{aligned}\]

Corollary (1-step 기댓값 형태):

\[\mathbb{E}[\Phi(t+1) - \Phi(t) \mid S(t)] = 2b\,\mathbb{E}[\hbar(X_{t+1}, t+1) \mid S(t)] - \frac{(n-1)b^2}{n} \tag{$\dagger'$}\]

4. Lemma 2 — Round drift telescoping

라운드 \(r\) 의 +b 적립은 시각 \(t_r+1, \ldots, t_{r+1}\) 에서 일어난다. 라운드 길이 \(m_r := t_{r+1} - t_r \in [1, T_{max}+1]\). 라운드 내 +b 위치를 \(\tilde X_j := X_{t_r+j}\), \(j = 1, \ldots, m_r\) 로 둠.

Lemma 2. Round-skeleton 1-step drift (= 한 라운드 동안의 \(\Phi\) 변화) 는

\[\Phi(t_{r+1}) - \Phi(t_r) = 2b\sum_{j=1}^{m_r}\hbar(\tilde X_j, t_r+j) - m_r\,\frac{(n-1)b^2}{n}\]

Proof. Lemma 1 의 (\(\dagger\)) 을 \(t = t_r, t_r+1, \ldots, t_{r+1}-1\) 에 대해 적용 후 합산 (telescoping):

\[\Phi(t_{r+1}) - \Phi(t_r) = \sum_{t=t_r}^{t_{r+1}-1}[\Phi(t+1) - \Phi(t)] = \sum_{t=t_r}^{t_{r+1}-1}\left[2b\,\hbar(X_{t+1}, t+1) - \frac{(n-1)b^2}{n}\right]\]

변수치환 \(j := t - t_r + 1 \in \{1, \ldots, m_r\}\), \(X_{t+1} = X_{t_r+j} = \tilde X_j\):

\[= 2b\sum_{j=1}^{m_r}\hbar(\tilde X_j, t_r+j) - m_r\,\frac{(n-1)b^2}{n}. \quad\square\]

기댓값을 씌우면

\[\mathbb{E}[\Phi(t_{r+1}) - \Phi(t_r) \mid S(t_r)] = 2b\,\mathbb{E}\bigg[\sum_{j=1}^{m_r}\hbar(\tilde X_j, t_r+j)\,\Big|\,S(t_r)\bigg] - m_r\frac{(n-1)b^2}{n} \tag{$\dagger\dagger$}\]

5. Lemma 3 — \(\mu_0\)-bias baseline

Lemma 3. \(\tilde X_1 = X_{t_r+1} \sim \boldsymbol{\mu}_0\) 가 \(S(t_r)\) 와 독립인 fresh draw 라는 사실로부터:

\[\mathbb{E}[\hbar(\tilde X_1, t_r+1) \mid S(t_r)] \;\leq\; \frac{\alpha}{2}\,M(t_r) + \frac{b(n-1)}{n}\]

여기서 \(\alpha = \|\boldsymbol{\mu}_0 - \mathbf{u}\|_1\), \(\mathbf{u}\) 는 균등분포.

Proof. \(\tilde X_1\) 은 \(\boldsymbol{\mu}_0\) fresh draw 이고, \(\tilde X_1 = i\) 인 조건에서 \(v_i\) 가 +b 를 받으므로 \(\hbar(i, t_r+1) = \hbar(i, t_r) + b(n-1)/n\) (Lemma 1 의 첫 식). 전체 기댓값은

\[\mathbb{E}[\hbar(\tilde X_1, t_r+1) \mid S(t_r)] = \sum_{i=1}^n \mu_0(i)\,\Big[\hbar(i, t_r) + \frac{b(n-1)}{n}\Big] = \sum_i \mu_0(i)\,\hbar(i, t_r) + \frac{b(n-1)}{n}.\]

Jordan 분해 (\(\mu_0\) 에서 균등 빼기). \(\sum_i \hbar(i, t_r) = 0\) 이므로

\[\sum_i \mu_0(i)\,\hbar(i, t_r) = \sum_i \big(\mu_0(i) - \tfrac{1}{n}\big)\,\hbar(i, t_r).\]

차이 \(\mu_0(i) - 1/n\) 의 양의 부분과 음의 부분은 각각 합이 \(\alpha/2\) 씩 (\(\sum_i (\mu_0(i) - 1/n) = 0\) + \(L^1\) 노름 정의). 따라서

\[\sum_i (\mu_0(i) - \tfrac{1}{n})\,\hbar(i, t_r) \leq \frac{\alpha}{2}\big(\max_i \hbar(i, t_r) - \min_i \hbar(i, t_r)\big) = \frac{\alpha}{2}\,M(t_r).\]

(상한 달성: 양의 초과분 \(\alpha/2\) 가 max 노드에, 음의 부족분 \(\alpha/2\) 가 min 노드에 몰린 worst-case.)

종합:

\[\mathbb{E}[\hbar(\tilde X_1, t_r+1) \mid S(t_r)] \leq \frac{\alpha}{2} M(t_r) + \frac{b(n-1)}{n}. \quad\square\]

6. Lemma 4 — Flow chain inequality (no big drop)

Lemma 4. 라운드 \(r\) 안에서 (\(j = 2, \ldots, m_r\)):

\[\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1) \;\leq\; (j-1)b\cdot\frac{n-1}{n} \;<\; (j-1)b\]

따라서 합산하면

\[\sum_{j=2}^{m_r}\big(\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1)\big) \;\leq\; b\cdot\frac{n-1}{n}\cdot\frac{(m_r-1)m_r}{2} \;\leq\; C_{round} \tag{B.3}\]

여기서 \(C_{round} := \frac{T_{max}(T_{max}+1)}{2}\,b\).

Proof. Flow 정의에 의해 \(X_{t+1}\) 은 \(X_t\) 의 다운스트림 이웃이며, 그 절대 높이 관계는

\[h(v_{X_{t+1}}, t) \leq h(v_{X_t}, t).\]

다음 스텝 +b 적립 후 \(h(v_{X_{t+1}}, t+1) = h(v_{X_{t+1}}, t) + b \leq h(v_{X_t}, t) + b\). 즉

\[h(v_{\tilde X_j}, t_r+j) \;\leq\; h(v_{\tilde X_{j-1}}, t_r+j-1) + b, \qquad j \geq 2.\]

체이닝:

\[h(v_{\tilde X_j}, t_r+j) \;\leq\; h(v_{\tilde X_1}, t_r+1) + (j-1)b.\]

평균값 차이는 \(\bar h(t_r+j) - \bar h(t_r+1) = (j-1)b/n\). 따라서

\[\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1) = [h(\tilde X_j, t_r+j) - h(\tilde X_1, t_r+1)] - \frac{(j-1)b}{n} \leq (j-1)b - \frac{(j-1)b}{n} = (j-1)b\cdot\frac{n-1}{n}.\]

합산: \(\sum_{j=2}^{m_r}(j-1) = \frac{(m_r-1)m_r}{2}\), \(m_r \leq T_{max}+1\). \(\square\)

7. Lemma 5 — Big drop event

라운드 \(r\) 시작 시점 \(t_r\) 에서 경사 간선 \((v_{i^\star}, v_{j^\star})\) 을 다음과 같이 구성:

  • \(v^+ := \arg\max_i \hbar(i, t_r)\), \(v^- := \arg\min_i \hbar(i, t_r)\)
  • 연결성으로 \(v^+ \to v^-\) 경로 \(w_0 = v^+, w_1, \ldots, w_m = v^-\) (\(m \leq n-1\)) 존재
  • 비둘기집: 어떤 \(\ell\) 에서 \(\hbar(w_\ell, t_r) - \hbar(w_{\ell+1}, t_r) \geq M(t_r)/(n-1)\)
  • 이 간선 \((v_{i^\star}, v_{j^\star}) := (w_\ell, w_{\ell+1})\) 을 경사 간선이라 함

Big drop 사건 \(E_r\): \(\tilde X_1 = i^\star\) (fresh draw 가 \(i^\star\) 에 떨어짐) AND \(\tilde X_2 = j^\star\) (다음 flow 스텝에서 \(j^\star\) 로 이동).

Lemma 5(a) — Big drop 확률 하한.

\[\Pr(E_r \mid S(t_r)) \;\geq\; \mu_{min}\cdot P_{RW,\min} \;=:\; p_0 \;>\; 0\]

Proof. 두 사건이 독립적인 두 random source (\(\mu_0\) draw, flow target draw) 에서 결정되므로 곱확률.

  • \(\Pr(\tilde X_1 = i^\star \mid S(t_r)) = \mu_0(i^\star) \geq \mu_{min}\).
  • \(\Pr(\tilde X_2 = j^\star \mid \tilde X_1 = i^\star, S(t_r))\): \(j^\star\) 가 \(i^\star\) 의 다운스트림 이웃이고 (\(\hbar(j^\star) \leq \hbar(i^\star)\) 보장 — 경사 간선 정의), flow probability \(P_{RW}(i^\star, j^\star) \geq P_{RW,\min}\).

곱하면 \(\geq \mu_{min}\cdot P_{RW,\min} = p_0\). \(\square\)

Lemma 5(b) — Big drop 발생 시 합 bound. \(E_r\) 에서

\[\sum_{j=2}^{m_r}\big(\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1)\big) \;\leq\; -(m_r-1)\,\frac{M(t_r)}{n-1} + C_{round} \tag{$\spadesuit$}\]

Proof. \(E_r\) 발생 시 \(\tilde X_2 = j^\star\), \(\tilde X_1 = i^\star\) 이고 \(\hbar(j^\star, t_r) \leq \hbar(i^\star, t_r) - M(t_r)/(n-1)\) (경사 간선 정의).

스텝 \(j = 2\): \(\tilde X_2 = j^\star\) 가 +b 받음. Lemma 1 의 첫 식 + 평균 보정으로

\[\hbar(\tilde X_2, t_r+2) = \hbar(j^\star, t_r) + b\frac{n-2}{n} \leq \hbar(i^\star, t_r) - \frac{M(t_r)}{n-1} + b.\]

스텝 \(j \geq 3\): Lemma 4 와 동일한 체이닝 (\(\tilde X_2\) 기준)

\[\hbar(\tilde X_j, t_r+j) \leq \hbar(\tilde X_2, t_r+2) + (j-2)b \leq \hbar(i^\star, t_r) - \frac{M(t_r)}{n-1} + (j-1)b.\]

한편 \(\hbar(\tilde X_1, t_r+1) = \hbar(i^\star, t_r+1) = \hbar(i^\star, t_r) + b(n-1)/n\). 따라서

\[\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1) \leq -\frac{M(t_r)}{n-1} + (j-1)b - b\frac{n-1}{n} \leq -\frac{M(t_r)}{n-1} + (j-1)b.\]

\(j=2\) 부터 \(m_r\) 까지 합하면 \(\sum_{j=2}^{m_r}(j-1) = (m_r-1)m_r/2 \leq C_{round}/b\), 따라서

\[\sum_{j=2}^{m_r}\big(\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1)\big) \leq -(m_r-1)\frac{M(t_r)}{n-1} + C_{round}. \quad\square\]

특히 \(m_r \geq 2\) 이므로 (big drop 은 flow 한 번 이상 필요)

\[\sum_{j=2}^{m_r}(\hbar - \hbar_1) \leq -\frac{M(t_r)}{n-1} + C_{round}.\]

8. Lemma 6 — Combined expected sum

Lemma 6.

\[\mathbb{E}\bigg[\sum_{j=2}^{m_r}\big(\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1)\big)\,\Big|\,S(t_r)\bigg] \;\leq\; -\frac{p_0\,M(t_r)}{n-1} + C_{round}\]

Proof. \(E_r\) 와 \(E_r^c\) 로 케이스 분해:

  • \(E_r\) 발생 시 (Lemma 5(b)): \(\sum \leq -\frac{M(t_r)}{n-1} + C_{round}\)
  • \(E_r^c\) (Lemma 4): \(\sum \leq C_{round}\)

기댓값:

\[\begin{aligned} \mathbb{E}[\sum \mid S(t_r)] &= \Pr(E_r)\cdot\mathbb{E}[\sum \mid E_r, S(t_r)] + \Pr(E_r^c)\cdot\mathbb{E}[\sum \mid E_r^c, S(t_r)] \\ &\leq \Pr(E_r)\cdot\Big(-\frac{M(t_r)}{n-1} + C_{round}\Big) + \Pr(E_r^c)\cdot C_{round} \\ &= -\Pr(E_r)\cdot\frac{M(t_r)}{n-1} + C_{round}. \end{aligned}\]

Lemma 5(a) 의 \(\Pr(E_r) \geq p_0\) 적용 (음의 항이라 부등호 방향 주의: \(-\Pr(E_r)\cdot M/(n-1) \leq -p_0\cdot M/(n-1)\)):

\[\mathbb{E}[\sum \mid S(t_r)] \leq -\frac{p_0 M(t_r)}{n-1} + C_{round}. \quad\square\]

주의: Lemma 4/5(b) 는 점별(pointwise) 부등식 (random path 단위). 음의 항 \(-M/(n-1)\) 은 \(E_r\) 발생 시에만 등장. 기댓값에서 비로소 \(-p_0 M/(n-1)\) 형태의 음의 drift 가 등장하는 것 — 이게 Foster-Lyapunov 의 “expected drift” 개념과 정확히 부합.

9. Round drift 부등식 (\(\star\star\)) 유도

Lemma 2,3,6 결합.

Lemma 2 (\(\dagger\dagger\)) 에서 합을 분해:

\[\sum_{j=1}^{m_r}\hbar(\tilde X_j, t_r+j) = m_r\,\hbar(\tilde X_1, t_r+1) + \sum_{j=2}^{m_r}\big(\hbar(\tilde X_j, t_r+j) - \hbar(\tilde X_1, t_r+1)\big)\]

(원래 \(j=1\) 항도 \(1\cdot\hbar(\tilde X_1, t_r+1) + 0\) 이라 자명히 들어맞음.)

기댓값 양변에 \(2b\) 곱한 형태로 (\(\dagger\dagger\)) 우변 첫 항 분해:

\[\begin{aligned} & \mathbb{E}[\Phi(t_{r+1}) - \Phi(t_r) \mid S(t_r)] \\ & \quad = \underbrace{2b\,m_r\,\mathbb{E}[\hbar(\tilde X_1, t_r+1) \mid S(t_r)]}_{\text{(I)}} + \underbrace{2b\,\mathbb{E}\bigg[\sum_{j=2}^{m_r}(\hbar(\tilde X_j) - \hbar(\tilde X_1)) \,\Big|\, S(t_r)\bigg]}_{\text{(II)}} - m_r\frac{(n-1)b^2}{n} \end{aligned}\]

(I) 처리 (Lemma 3): \(\mathbb{E}[\hbar(\tilde X_1, t_r+1) \mid S(t_r)] \leq \frac{\alpha}{2}M(t_r) + \frac{b(n-1)}{n}\). 곱하기 \(2b\,m_r\):

\[\text{(I)} \leq b\,m_r\,\alpha\,M(t_r) + m_r\cdot\frac{2b^2(n-1)}{n}\]

(II) 처리 (Lemma 6): \(\mathbb{E}[\sum_{j=2}^{m_r}(\hbar - \hbar_1) \mid S(t_r)] \leq -\frac{p_0 M(t_r)}{n-1} + C_{round}\). 곱하기 \(2b\):

\[\text{(II)} \leq -\frac{2b\,p_0\,M(t_r)}{n-1} + 2b\,C_{round}\]

결합: (I) + (II) + \(- m_r(n-1)b^2/n\):

\[\begin{aligned} \mathbb{E}[\Phi(t_{r+1}) - \Phi(t_r) \mid S(t_r)] &\leq b\,m_r\,\alpha\,M(t_r) - \frac{2b\,p_0\,M(t_r)}{n-1} + 2b\,C_{round} + m_r\frac{2b^2(n-1)}{n} - m_r\frac{(n-1)b^2}{n} \\ &= b\,M(t_r)\Big[m_r\,\alpha - \frac{2p_0}{n-1}\Big] + 2b\,C_{round} + m_r\frac{(n-1)b^2}{n} \end{aligned}\]

\(m_r \leq T_{max}+1\) 으로 bound 하면 (\(\alpha \geq 0\), 양의 항):

\[\boxed{\mathbb{E}[\Phi(t_{r+1}) - \Phi(t_r) \mid S(t_r)] \;\leq\; b\,M(t_r)\,\Delta_{\mathrm{drift}} + C_3} \tag{$\star\star$}\]

여기서

\[\Delta_{\mathrm{drift}} := (T_{max}+1)\alpha - \frac{2p_0}{n-1}, \qquad C_3 := 2b\,C_{round} + (T_{max}+1)\frac{(n-1)b^2}{n}.\]

\(C_3\) 는 \(M(t_r)\) 에 무관하고 \((\mathcal{G}, b, T_{max})\) 에만 의존하는 결정적 상수.

10. Foster–Lyapunov 적용 → Proposition

Theorem (Foster–Lyapunov criterion; M&T, 1993, Thm 11.3.4). 가산 상태공간 위의 비가약 마르코프 체인 \(\{Y_n\}\) 에 대해, 함수 \(V: \mathcal{X} \to [0,\infty)\) 와 유한 집합 \(\mathcal{B} \subset \mathcal{X}\) 가 존재하여

\[\mathbb{E}[V(Y_{n+1}) - V(Y_n) \mid Y_n = y] \leq -1 + \beta\,\mathbf{1}_{\mathcal{B}}(y), \qquad \beta < \infty\]

를 만족하면, 체인은 양의 재귀이며 \(\mathcal{B}\) 도달 기대시간 \(\mathbb{E}[\tau_{\mathcal{B}}] \leq V(Y_0) + \beta < \infty\).

Proposition 의 증명. Round-skeleton \(\{S(t_r)\}\) 에 위 정리 적용. Lyapunov 함수 \(V := \Phi\).

Step 1 — refuge 정의. 경계 \(M^\star, C_1\) 을 다음과 같이 잡는다:

\[M^\star := \frac{C_3 + 1}{b\,|\Delta_{\mathrm{drift}}|}, \qquad C_1 := n(M^\star)^2.\]

\(\mathcal{B}_\Phi := \{S : \Phi(\boldsymbol{\delta}) \leq C_1\}\) 로 둠.

Step 2 — refuge 유한성. \(\Phi(\boldsymbol{\delta})\) 는 \(\boldsymbol{\delta}\) 에 대한 coercive (proper) 함수 — 즉 \(\Phi \leq C_1\) 사블레벨이 \(\mathbb{R}^{n-1}\) 에서 유계. 격자 \(\boldsymbol{\delta}(0) + b\mathbb{Z}^{n-1}\) 와의 교집합은 유한. \(X \in \{1,\ldots,n\}\), \(Z \in \{0,\ldots,T_{max}\}\) 도 유한. 따라서 \(\mathcal{B}_\Phi\) 유한.

Step 3 — refuge 밖에서 음의 drift. \(\Phi(\boldsymbol{\delta}) \leq nM^2\) (Lemma 7 아래) 이므로 \(\Phi > C_1 = n(M^\star)^2 \Longrightarrow M > M^\star\). 그러면 (\(\star\star\)) 의 우변

\[bM(t_r)\Delta_{\mathrm{drift}} + C_3 \leq -bM^\star\,|\Delta_{\mathrm{drift}}| + C_3 = -(C_3 + 1) + C_3 = -1\]

(둘째 등호: \(M^\star\) 정의에서 \(b\,M^\star\,|\Delta_{\mathrm{drift}}| = C_3 + 1\).) 즉 \(S \notin \mathcal{B}_\Phi\) 에서 drift \(\leq -1\).

Step 4 — refuge 안에서 유한 변화량. \(S \in \mathcal{B}_\Phi\) 이면 \(\Phi(t_r) \leq C_1\), 한 라운드 \(\Phi\) 변화량은 (\(\star\star\)) 우변 \(\leq b\,M(t_r)\,\Delta_{\mathrm{drift}} + C_3 \leq C_3\) (drift 가 양수일 때 worst-case). 즉 \(\beta := C_3 + 1 < \infty\).

Step 5 — Foster–Lyapunov 적용. \(\{S(t_r)\}\) 가 round-skeleton 위에서 비가약 (Section 3 of 블로그 본문, Lemma 2 — 본 글에선 인용으로 처리).

조건 \(\mathbb{E}[\Phi(S(t_{r+1})) - \Phi(S(t_r)) \mid S(t_r)] \leq -1 + \beta\,\mathbf{1}_{\mathcal{B}_\Phi}\) 충족 → skeleton chain 양의 재귀, \(\mathbb{E}[\tau_{\mathcal{B}_\Phi}^{\text{sk}}] < \infty\).

Step 6 — 원 체인 양의 재귀 전이. 라운드 길이 \(m_r \leq T_{max}+1\) 결정적 상한. 따라서 원 체인의 \(\tau_{\mathcal{B}_\Phi} \leq (T_{max}+1)\cdot\tau_{\mathcal{B}_\Phi}^{\text{sk}}\), 기댓값도 유한. 즉 \(\{S(t)\}\) 양의 재귀.

Step 7 — \(M(t) \leq C\) 표현. \(\Phi \leq C_1 \Longrightarrow M \leq \sqrt{2C_1}\) (Lemma 7). \(C := \sqrt{2C_1}\) 로 잡으면 \(\{S \in \mathcal{B}_\Phi\} \subset \{M \leq C\}\), 후자도 a.s. 무한 자주 방문. \(\square\)

11. Lemma 7 (보조) — \(\Phi\) 와 \(M\) 의 관계

Lemma 7. 임의 시각 \(t\)에 대해

\[\frac{M(t)^2}{2} \;\leq\; \Phi(t) \;\leq\; n\,M(t)^2\]

Proof. \(M(t) = \max_i \hbar(i,t) - \min_i \hbar(i,t)\), 두 극단점 \(\hbar_+, \hbar_-\) 라 하면:

상한: 모든 \(i\)에서 \(|\hbar(i,t)| \leq M(t)\) (because \(\hbar_- \leq \hbar(i,t) \leq \hbar_+\) and the range is \(M\), but actually we need a bit more care). 정확히는 \(\sum_i\hbar = 0\) 에서 \(|\hbar(i,t)| \leq M(t)\) 가 일반 성립 (\(\hbar_+ \geq 0 \geq \hbar_-\), 즉 \(|\hbar_+| + |\hbar_-| = M\), 각각 \(\leq M\)). 따라서 \(\Phi = \sum_i \hbar^2 \leq n\cdot M^2\).

하한: \(\hbar_+^2 + \hbar_-^2 \geq (\hbar_+ - \hbar_-)^2/2 = M^2/2\) (왜냐 \(a^2+b^2 \geq (a-b)^2/2\), AM-QM 또는 직접). 다른 항들은 비음. 따라서 \(\Phi \geq M^2/2\). \(\square\)

12. Step B 개요 — 정리 (\(\overline{\operatorname{SD}}^2 \to C\) a.s.) 완성

Proposition 으로부터 다음이 따라옴.

Step B.1 — 비가약성. \(\{S(t)\}\) 가 격자 \(\boldsymbol{\delta}(0) + b\mathbb{Z}^{n-1}\) 위에서 비가약 (\(\mu_0\) 의 support 가 \(V\) 전체이고 연결성으로 모든 \(\delta\)-격자점에 양의 확률로 도달). 본 글에선 인용.

Step B.2 — 양의 Harris 재귀. Proposition + 비가약성 + 가산 상태공간 → 양의 Harris 재귀 (M&T Prop 10.1.1; 가산공간에서 \(\varphi\)-비가약성 = Harris 비가약성).

Step B.3 — 모멘트 조건 확보. LLN 적용에 \(f(S) = (\delta_i - \delta_j)^2 \in L_1(\pi)\) 가 필요. 즉 \(\mathbb{E}_\pi[M^2] < \infty\). (\(\star\star\)) 의 drift 는 \(M\) 에 선형이라 \(\mathbb{E}_\pi[M] < \infty\) 만 보장 (M&T Thm 14.0.1 \(f\)-regularity). 한 차수 더 강화하려면 \(V := \Phi^2\) 로 Lyapunov 함수 강화하여

\[\mathbb{E}[V(t_{r+1}) - V(t_r) \mid S(t_r)] \leq -\tfrac{c}{4}M(t_r)^3 + C\cdot\mathbf{1}_{\mathcal{B}'}\]

를 도출 → \(\mathbb{E}_\pi[M^3] < \infty\) → Jensen 으로 \(\mathbb{E}_\pi[M^2] < \infty\). 자세한 도출은 블로그 본문 Step 4 참조.

Step B.4 — LLN. 양의 Harris 재귀 + 비가약성으로 유일 정상분포 \(\pi\) 존재. 양의 Harris 체인의 강대수 법칙 (M&T Thm 17.1.7) 에서 \(f \in L_1(\pi)\) 에 대해

\[\frac{1}{t}\sum_{s=0}^t f(S(s)) \xrightarrow{t\to\infty} \mathbb{E}_\pi[f] \quad\text{a.s.}\]

\(f(S) = (\delta_i - \delta_j)^2\) 적용:

\[\overline{\operatorname{SD}}^2_{ij}(t) = \frac{1}{t}\sum_{s=0}^t (\delta_i(s) - \delta_j(s))^2 \xrightarrow{t\to\infty} \mathbb{E}_\pi[(\delta_i - \delta_j)^2] =: c_{ij} \quad\text{a.s.}\]

\(\mathbf{y}\)-종속성. 전이커널은 \((\mathcal{G}, b, T_{max})\) 만 의존 (Step 1). 유효 상태공간이 \(\boldsymbol{\delta}(0) + b\mathbb{Z}^{n-1}\) 격자에 제한되므로 \(\boldsymbol{\delta}(0) \bmod b = \mathbf{y} \bmod b\) 에 의존. 즉 \(c_{ij} = c_{ij}(\mathcal{G}, b, T_{max}, \mathbf{y}\bmod b)\). \(\blacksquare\)
