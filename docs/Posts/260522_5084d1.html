대표 강의글 250818_공부_Big-O,Little-o,Theta,Tilde,Big-Op,little-op 의 정의·표 정본을 코딩 예제로 보충하는 노트. 두 sequence \(a_n, b_n\) 의 ratio \(a_n / b_n\) 이 (i) 유계인가 — \(O\), (ii) 0 으로 가는가 — \(o\), (iii) 양쪽 양의 상수 사이에 갇히는가 — \(\Theta\), (iv) 1 로 가는가 — \(\sim\) — 어느 양상인지 그림으로 직접 본다. 공통 헤더부터.

import numpy as np
import matplotlib.pyplot as plt
plt.style.use("seaborn-v0_8-whitegrid")
plt.rcParams.update({
    "text.usetex": True,
    "text.latex.preamble": r"\usepackage{amsmath,amssymb}",
    "font.family": "serif",
    "font.size": 10,
    "axes.titlesize": 11,
    "axes.labelsize": 10,
})
rng = np.random.default_rng(20260522)
n = np.arange(1, 201)
n[:5], n[-5:]
(array([1, 2, 3, 4, 5]), array([196, 197, 198, 199, 200]))

- 예제 1 — Big-\(O\) (upper bound). \(a_n = 3n^2 + 5n + 7\), \(b_n = n^2\). ratio \(a_n/b_n = 3 + 5/n + 7/n^2 \to 3\). 상한이 유계로 정해지면 \(a_n = O(b_n)\).

a1 = 3 * n**2 + 5 * n + 7
b1 = n**2
a1[:5]
array([ 15,  29,  49,  75, 107])
b1[:5]
array([ 1,  4,  9, 16, 25])
ratio1 = a1 / b1
ratio1[0], ratio1[-1]   # (15.0, 3.0252...)
(np.float64(15.0), np.float64(3.025175))

ratio 가 \(n=1\) 에서 15 였다가 \(n=200\) 에서 3.03 으로 안정화. 어떤 상수로 유계라는 게 \(O\) 의 핵심.

fig, ax = plt.subplots(figsize=(7.5, 4.5))
ax.plot(n, ratio1, lw=2.0, color="C0", label=r"$a_n / b_n$")
ax.axhline(3.0, lw=1.4, ls="--", color="crimson", label=r"limit $= 3$")
ax.set_title(r"$a_n = 3n^2 + 5n + 7$,\quad $b_n = n^2$,\quad $a_n/b_n \to 3$")
ax.set_xlabel(r"$n$"); ax.set_ylabel(r"$a_n / b_n$"); ax.legend(loc="upper right")

# 경계 표현 — 정확한 T 와 경계에서 살짝 빗나간 F
txt = "\n".join([
    r"$a_n = \Theta(n^2)$\quad \textbf{T}",
    r"$a_n \sim 3\,n^2$\quad \textbf{T}",
    r"$a_n \sim n^2$\quad \textbf{F}\;\;(wrong constant)",
    r"$a_n = o(n^2)$\quad \textbf{F}\;\;(ratio $\to 3 \neq 0$)",
])
ax.text(0.42, 0.92, txt, transform=ax.transAxes, va="top", ha="left",
        fontsize=10, family="serif",
        bbox=dict(boxstyle="round,pad=0.5", fc="white", ec="0.6", alpha=0.95))
plt.show()

이 한 장의 그래프 (ratio = \(3 + 5/n + 7/n^2\), 15 → 3 단조 감소) 가 보여주는 상황에서 어떤 오더 표현이 맞고 틀린지 한 표로 정리하면 다음과 같다.

# 표현 T/F 이유
1 \(a_n = O(n^2)\) T ratio 가 어떤 상수 (≤ 15) 로 유계
2 \(a_n = o(n^2)\) F ratio \(\to 3 \neq 0\)
3 \(a_n = \Theta(n^2)\) T ratio 가 \([3, 15]\) 양쪽 양의 상수 사이에 갇힘
4 \(a_n \sim n^2\) F ratio \(\to 3\) (1 아님)
5 \(a_n \sim 3 n^2\) T \(a_n / (3 n^2) \to 1\) — 점근 비율까지 정확
6 \(a_n = O(n^3)\) T \(a_n / n^3 = 3/n + \cdots \to 0\) (유계) — 상한이 더 헐겁기만
7 \(a_n = o(n^3)\) T \(a_n / n^3 \to 0\)
8 \(a_n = \Theta(n^3)\) F lower bound 부재 — ratio 가 0 으로 갔는데 양의 상수로 못 막음
9 \(a_n \sim n^3\) F ratio \(\to 0 \neq 1\)
10 \(a_n = O(n)\) F \(a_n / n = 3n + 5 + 7/n \to \infty\) — 유계 아님
11 \(a_n = o(n)\) F 위 동일
12 \(a_n = \Theta(n)\) F 위 동일
13 \(a_n = 3 n^2 + O(n)\) T 잔여항 \(5n + 7\) 이 \(O(n)\)
14 \(a_n = 3 n^2 + o(n^2)\) T 잔여항 \((5n+7)/n^2 \to 0\)

ratio 가 어느 점근값 으로 수렴하는가 (여기서는 3) 와 그 점근값이 0 / 양의 상수 / 1 중 어느 것 인지가 모든 판정의 기준. ratio \(\to\) 양의 상수 \(c\) 이면 \(O, \Theta\) T / \(o, \sim\) F (단 \(\sim c b_n\) 는 T), ratio \(\to 0\) 이면 \(O, o\) T / \(\Theta, \sim\) F, ratio \(\to \infty\) 이면 모두 F. 같은 sequence \(a_n\) 에 대해서도 비교 기준 \(b_n\) 을 어떤 차수로 잡느냐에 따라 네 오더의 T/F 가 모두 달라진다 — \(b_n = n^2\) (정확한 차수) 일 때만 \(\Theta\) 가 살아남고, \(b_n = 3 n^2\) 까지 잡아야 \(\sim\) 도 살아남는다.

- 예제 2 — little-\(o\) (vanishing ratio). \(a_n = n^2\), \(b_n = n^3\). ratio \(a_n/b_n = 1/n \to 0\) — 분모가 진짜로 빨리 자란다. 대조로 ratio 가 0 으로 안 가는 (= \(O\) 는 맞지만 \(o\) 는 아닌) sequence 도 같이.

a2 = n**2; b2 = n**3
ratio2 = a2 / b2
ratio2[0], ratio2[-1]   # (1.0, 0.005)
(np.float64(1.0), np.float64(0.005))
# 대조: ratio 가 0 으로 안 감 — bounded constant 0.5
a2b = n**2; b2b = 2 * n**2
ratio2b = a2b / b2b
ratio2b[0]              # 0.5 for all n
np.float64(0.5)
fig, ax = plt.subplots(figsize=(7.5, 4.5))
ax.plot(n, ratio2,  lw=2.0, color="C0", label=r"$n^2/n^3 \to 0$  ($o$, also $O$)")
ax.plot(n, ratio2b, lw=2.0, ls="--", color="C1", label=r"$n^2/(2n^2) = 0.5$  ($O$ only, not $o$)")
ax.axhline(0.0, lw=1.0, color="gray")
ax.set_title(r"vanishing vs bounded constant ratio")
ax.set_xlabel(r"$n$"); ax.set_ylabel(r"ratio"); ax.legend(loc="upper right")

txt = "\n".join([
    r"\textbf{blue solid}: $a_n=n^2$, $b_n=n^3$",
    r"\quad $a_n = o(n^3)$\quad \textbf{T}",
    r"\quad $a_n = \Theta(n^3)$\quad \textbf{F}",
    r"",
    r"\textbf{orange dashed}: $a_n=n^2$, $b_n=2n^2$",
    r"\quad $a_n = \Theta(2n^2)$\quad \textbf{T}",
    r"\quad $a_n = o(2n^2)$\quad \textbf{F}",
])
ax.text(0.40, 0.80, txt, transform=ax.transAxes, va="top", ha="left",
        fontsize=10, family="serif",
        bbox=dict(boxstyle="round,pad=0.5", fc="white", ec="0.6", alpha=0.95))
plt.show()

두 곡선 모두 유계 (= \(O\) 의 조건은 충족). 차이는 0 으로 가는가 — 그게 little-\(o\) 의 핵심.

- 예제 3 — \(\Theta\) (양쪽 bound). \(a_n = 4n^2 + \sin(n)\cdot n\), \(b_n = n^2\). ratio = \(4 + \sin(n)/n\). \(\sin\) 진동으로 살짝 흔들리지만 양쪽 양의 상수 사이에 갇힌다.

a3 = 4 * n**2 + np.sin(n) * n
b3 = n**2
ratio3 = a3 / b3
ratio3.min(), ratio3.max()   # (3.8..., 4.84...)
(np.float64(3.8082151450673725), np.float64(4.841470984807897))

ratio 가 모든 \(n\) 에서 \([3.8, 4.9]\) 사이에 갇힌다. 어떤 상수 \(c, C > 0\) 가 존재해 \(c \cdot b_n \leq a_n \leq C \cdot b_n\) → \(a_n = \Theta(b_n)\).

fig, ax = plt.subplots(figsize=(7.5, 4.5))
ax.plot(n, ratio3, lw=2.0, color="C0", label=r"$(4n^2 + \sin(n)\,n)\,/\,n^2$")
ax.axhline(4.0, lw=1.4, ls="--", color="crimson", label=r"limit $= 4$")
ax.set_title(r"ratio bounded between positive constants ($\to 4$)")
ax.set_xlabel(r"$n$"); ax.set_ylabel(r"$a_n / b_n$"); ax.legend(loc="upper right")

txt = "\n".join([
    r"$a_n = \Theta(n^2)$\quad \textbf{T}",
    r"$a_n \sim 4\,n^2$\quad \textbf{T}",
    r"$a_n \sim n^2$\quad \textbf{F}\;\;(ratio $\to 4 \neq 1$)",
    r"$a_n = o(n^2)$\quad \textbf{F}",
])
ax.text(0.40, 0.55, txt, transform=ax.transAxes, va="top", ha="left",
        fontsize=10, family="serif",
        bbox=dict(boxstyle="round,pad=0.5", fc="white", ec="0.6", alpha=0.95))
plt.show()

- 예제 4 — \(\sim\) (asymptotic equality, ratio \(\to 1\)). \(a_n = n^2 + n\), \(b_n = n^2\). ratio = \(1 + 1/n \to 1\). 가장 강한 진술 — 같은 차수 가 아니라 1 이라는 상수까지 정확. 대조로 다른 상수로 가는 경우 (= \(\Theta\) 는 맞지만 \(\sim\) 은 아닌) 도.

a4 = n**2 + n; b4 = n**2
ratio4 = a4 / b4
ratio4[0], ratio4[-1]   # (2.0, 1.005)
(np.float64(2.0), np.float64(1.005))
# 대조: ratio = 2 (≠ 1) — Θ 맞지만 ∼ 는 아님
a4b = 2 * n**2
ratio4b = a4b / b4
ratio4b[0]              # 2.0 for all n
np.float64(2.0)
fig, ax = plt.subplots(figsize=(7.5, 4.5))
ax.plot(n, ratio4,  lw=2.0, color="C0", label=r"$(n^2+n)/n^2 \to 1$  ($\sim$)")
ax.plot(n, ratio4b, lw=2.0, ls="--", color="C1", label=r"$2n^2 / n^2 = 2$  ($\Theta$ only, not $\sim$)")
ax.axhline(1.0, lw=1.2, ls=":", color="crimson", label=r"limit $= 1$")
ax.set_title(r"ratio $\to 1$ (tilde) vs ratio bounded but $\neq 1$ (Theta only)")
ax.set_xlabel(r"$n$"); ax.set_ylabel(r"ratio"); ax.legend(loc="center right")

txt = "\n".join([
    r"\textbf{blue solid}: $a_n=n^2+n$, $b_n=n^2$",
    r"\quad $a_n \sim n^2$\quad \textbf{T}",
    r"",
    r"\textbf{orange dashed}: $a_n=2n^2$, $b_n=n^2$",
    r"\quad $a_n \sim n^2$\quad \textbf{F}\;\;(ratio $\to 2 \neq 1$)",
    r"\quad $a_n = \Theta(n^2)$\quad \textbf{T}",
])
ax.text(0.40, 0.92, txt, transform=ax.transAxes, va="top", ha="left",
        fontsize=10, family="serif",
        bbox=dict(boxstyle="round,pad=0.5", fc="white", ec="0.6", alpha=0.95))
plt.show()

본 글의 출발이었던 fair walk 의 제곱 \(E[X_n^2] = n\) 도 정확히 이 양식: \(E[X_n^2] \sim n\) (또는 등식 \(= n\)) 이 가장 정확하고, \(\Theta(n)\) 도 맞고, \(O(n)\) 도 맞고, \(o(n)\) 만 틀린다.

- 예제 5 — \(O_p\) vs \(o_p\) (probabilistic). \(X_1, \dots, X_n \overset{\text{iid}}{\sim} N(\mu, \sigma^2)\), \(\mu = 2\), \(\sigma = 1\). 표본평균 \(\bar X_n\) 에 대해 두 가지 진술:

  • WLLN: \(\bar X_n - \mu = o_p(1)\). \(\bar X_n - \mu \xrightarrow{p} 0\).
  • CLT: \(\sqrt n\,(\bar X_n - \mu) = O_p(1)\). \(\sqrt n\,(\bar X_n - \mu) \xrightarrow{d} N(0, \sigma^2)\) — tight.
mu, sigma = 2.0, 1.0
n_max, NREP = 5000, 200
X = rng.normal(mu, sigma, size=(NREP, n_max))
cs = np.cumsum(X, axis=1)
js = np.arange(1, n_max + 1)
Xbar = cs / js[None, :]
Xbar_dev  = Xbar - mu                          # X̄_n - μ
sqrtn_dev = np.sqrt(js)[None, :] * Xbar_dev    # √n · (X̄_n - μ)
Xbar_dev.shape
(200, 5000)
# o_p(1): |X̄ - μ| 의 평균이 n 커지면서 0 으로
np.mean(np.abs(Xbar_dev[:, 10])), np.mean(np.abs(Xbar_dev[:, -1]))
(np.float64(0.2396022025228026), np.float64(0.010986329963954157))
# O_p(1): √n · |X̄ - μ| 의 평균이 n 무관 거의 일정 (≈ σ·√(2/π) ≈ 0.798)
np.mean(np.abs(sqrtn_dev[:, 10])), np.mean(np.abs(sqrtn_dev[:, -1]))
(np.float64(0.794670604710882), np.float64(0.7768508417864943))
fig, axes = plt.subplots(1, 2, figsize=(8, 4))
g = np.arange(1, n_max + 1)
for rep in range(40):
    axes[0].plot(g, Xbar_dev[rep],  lw=0.5, alpha=0.4, color="steelblue")
    axes[1].plot(g, sqrtn_dev[rep], lw=0.5, alpha=0.4, color="darkorange")
axes[0].plot(g, np.mean(np.abs(Xbar_dev), axis=0),  lw=2.0, color="black", label=r"$\mathbb{E}|\cdot|$")
axes[1].plot(g, np.mean(np.abs(sqrtn_dev), axis=0), lw=2.0, color="black", label=r"$\mathbb{E}|\cdot|$")
axes[0].axhline(0, lw=1.0, color="crimson"); axes[1].axhline(0, lw=1.0, color="crimson")
axes[0].set_title(r"$\bar X_n - \mu \to 0$ in prob")
axes[1].set_title(r"$\sqrt n\,(\bar X_n - \mu)$ tight")
for ax in axes:
    ax.set_xlabel(r"$n$"); ax.legend(loc="upper right")
axes[0].set_ylabel(r"$\bar X_n - \mu$")
axes[1].set_ylabel(r"$\sqrt n\,(\bar X_n - \mu)$")

txt_left = "\n".join([
    r"$\bar X_n - \mu = o_p(1)$\quad \textbf{T}\;\;(WLLN)",
    r"$\bar X_n - \mu = O_p(1/\sqrt n)$\quad \textbf{T}",
    r"$\bar X_n - \mu = o_p(1/\sqrt n)$\quad \textbf{F}",
])
axes[0].text(0.30, 0.30, txt_left, transform=axes[0].transAxes, va="top", ha="left",
             fontsize=10, family="serif",
             bbox=dict(boxstyle="round,pad=0.5", fc="white", ec="0.6", alpha=0.95))

txt_right = "\n".join([
    r"$\sqrt n\,(\bar X_n - \mu) = O_p(1)$\quad \textbf{T}\;\;(CLT)",
    r"$\sqrt n\,(\bar X_n - \mu) = o_p(1)$\quad \textbf{F}",
])
axes[1].text(0.20, 0.30, txt_right, transform=axes[1].transAxes, va="top", ha="left",
             fontsize=10, family="serif",
             bbox=dict(boxstyle="round,pad=0.5", fc="white", ec="0.6", alpha=0.95))

plt.tight_layout(); plt.show()

왼쪽 path 들이 0 으로 수렴 (\(o_p(1)\)), 오른쪽은 폭이 줄어들지 않고 일정한 진동 (\(O_p(1)\)). probabilistic 오더는 deterministic 오더와 수렴 양식 (a.s. / in prob / in dist) 의 차이를 빼면 같은 게임. CLT 가 \(O_p(1)\) tightness 의 표준 source, WLLN 이 \(o_p(1)\) vanishing 의 표준 source.

다섯 예제를 한 표로 묶으면 대표 글의 T/F 표가 시뮬로 검증된다. ratio 가 어떻게 자라거나 줄어드는가만 보면 어느 오더에 해당하는지 즉각 판정 — \(\sim \subsetneq \Theta \subsetneq O\) 의 포함 관계, \(o\) 는 \(\Theta\) 와 disjoint. probabilistic 버전도 ratio 의 분포 가 tight 인지 0 으로 수렴 하는지의 차이로 같은 구도가 유지된다.
