연구 ▷ HST ▷ 마팅게일이란 무엇인가 — 시뮬 6예제로 보는 강의노트

Author

리이

Published

May 22, 2026

마팅게일은 “평균적으로 공정한 게임” 의 수학적 추상이다. 적분가능한 process \(\{X_n\}_{n \geq 0}\) 이 filtration \(\{\mathcal F_n\}\) 에 적응되어 있고 (\(X_n \in \mathcal F_n\), \(E|X_n| < \infty\)) 각 step 의 조건부 평균이 현재 값과 같을 때, 즉 \(E[X_{n+1} \mid \mathcal F_n] = X_n\), 을 만족할 때 \(\{X_n\}\) 을 \(\mathcal F_n\)-마팅게일이라 부른다. \(\geq\) 면 submartingale, \(\leq\) 면 supermartingale. 정의를 처음 보면 추상적인데, 시뮬로 한두 step 만 끊어 보면 어떤 process 가 마팅게일인지 즉각 와닿는다. 본 글은 6개 예제로 그 직관을 짚는다. 공통 헤더부터.

- 예제 1 — fair random walk (±1 코인). \(\epsilon_i \in \{-1, +1\}\) 각 prob \(1/2\) (정규분포 \(N(0,1)\) 합이 아니라 베르누이 ±1 코인), \(X_n = \sum_{i=1}^n \epsilon_i\). natural filtration \(\mathcal F_n = \sigma(\epsilon_1, \dots, \epsilon_n)\) 에서 \(E[X_{n+1} \mid \mathcal F_n] = X_n + E[\epsilon_{n+1}] = X_n\) 이라 마팅게일. 증분부터 끊어 보자.

eps1 = rng.choice([-1.0, 1.0], size=(NPATH, T))   # 30 paths × 2000 steps
eps1.shape
(30, 2000)
eps1[:3, :10]   # 첫 3 path 의 첫 10 step — ±1 토큰만 등장

eps1.mean(), eps1.std()   # 평균 ≈ 0, std ≈ 1 (베르누이 ±1 의 표준 모멘트)
(np.float64(0.0049), np.float64(0.9999879949279391))

증분을 누적해서 path 를 만든다.

X1 = np.cumsum(eps1, axis=1)
X1[:3, :10]   # X_n = Σ ε_i — 정수 값으로만 진행
array([[ 1.,  2.,  1.,  2.,  1.,  2.,  3.,  4.,  5.,  4.],

ensemble 평균이 0 근처, 표준편차는 \(\sqrt{T} \approx \sqrt{2000} \approx 45\) 근처. 마팅게일은 평균 이 stationary 라는 것이지 표준편차 가 stationary 라는 게 아니다. path 자체는 \(\sqrt n\) 의 스케일로 흩어진다.

ax.axhline(0, color="r", lw=0.8)

ax.set_xlabel(r"$n$"); ax.set_ylabel(r"$X_n$"); ax.legend()
plt.show()

굵은 검정선 — 30 path 의 ensemble 평균 — 이 시간이 흘러도 0 근처에 머무는 게 마팅게일의 본질. 개별 path 는 진동하지만 평균은 stationary. 이게 “공정” 의 정량적 의미.

- 예제 2 — 편향된 walk. \(\epsilon_i = +1\) (확률 \(p\)) / \(-1\) (확률 \(1-p\)). \(E[\epsilon] = 2p - 1\). \(p = 0.55\) 이면 submartingale (drift up), \(p = 0.45\) 이면 supermartingale (drift down).

def biased(p):
    return np.where(rng.random(size=(NPATH, T)) < p, 1.0, -1.0)

eps_sub = biased(0.55)
eps_sub.mean()   # 약 +0.10 (이론값 2·0.55 - 1 = 0.10)
np.float64(0.1041)
eps_sup = biased(0.45)
eps_sup.mean()   # 약 -0.10
np.float64(-0.1016)
X2_sub = np.cumsum(eps_sub, axis=1)
X2_sup = np.cumsum(eps_sup, axis=1)
X2_sub[:, -1].mean(), X2_sup[:, -1].mean()   # 끝 시점 평균이 ±200 근처 (drift × T)
(np.float64(208.2), np.float64(-203.2))

drift 가 매 step 0.10 씩 쌓이니 \(T = 2000\) 에서 약 ±200.

fig, ax = plt.subplots(figsize=(8, 4))

ax.plot(t, X2_sup.mean(0), lw=1.8, color="darkred",   label=r"p=0.45  supermart.")
ax.axhline(0, color="r", lw=0.6, alpha=0.5)

ax.set_xlabel(r"$n$"); ax.set_ylabel(r"$X_n$"); ax.legend()
plt.show()

두 ensemble 평균이 ±0.10 의 기울기로 갈라진다. 마팅게일은 sub 와 super 사이의 균형점 — drift 가 정확히 0 인 한 줄.

- 예제 3 — variance compensation. Fair walk 의 제곱 \(X_n^2\) 은 평균이 \(n\) 으로 자라므로 마팅게일이 아니다 (submartingale). \(n\) 만큼 빼주면 \(Y_n := X_n^2 - n\) 이 마팅게일이 된다. 먼저 보정 전 \(X_n^2\) 부터.

S3 = X1 ** 2                 # X1 그대로 재사용 (Ex 1 의 fair walk)
S3[:3, :10]                  # 첫 몇 step — 정수 제곱이라 0, 1, 4, 9, ...
array([[ 1.,  4.,  1.,  4.,  1.,  4.,  9., 16., 25., 16.],
       [ 1.,  0.,  1.,  0.,  1.,  0.,  1.,  0.,  1.,  4.],
       [ 1.,  0.,  1.,  0.,  1.,  0.,  1.,  4.,  9., 16.]])
S3[:, -1].mean()             # 끝 시점 ensemble 평균 — 이론값 E[X_T^2] = T = 2000 근처
np.float64(2499.6)

ensemble 평균이 \(n\) 으로 자란다 — drift 가 매 step 1 씩 있는 submartingale. 이제 한 줄 계산으로 보정 방향이 결정된다.

\[ E[X_{n+1}^2 \mid \mathcal F_n] = X_n^2 + 2 X_n \, \underbrace{E[\epsilon_{n+1}]}_{=\,0} + \underbrace{E[\epsilon_{n+1}^2]}_{=\,1} = X_n^2 + 1 \;\Rightarrow\; E[Y_{n+1} \mid \mathcal F_n] = X_n^2 + 1 - (n+1) = Y_n. \]

즉 매 step 평균이 \(+1\) 씩 자라므로 누적 보정 \(-n\) 을 빼주면 정확히 상쇄. 보정 후 \(Y_n\).

Y3 = S3 - t[None, :]         # Y_n = X_n^2 - n
Y3[:3, :10]                  # S3 에서 t 를 뺀 것 — 평균이 0 근처로 평탄화
array([[ 0.,  2., -2.,  0., -4., -2.,  2.,  8., 16.,  6.],
       [ 0., -2., -2., -4., -4., -6., -6., -8., -8., -6.],
       [ 0., -2., -2., -4., -4., -6., -6., -4.,  0.,  6.]])
Y3[:, -1].mean()             # 끝 시점 ensemble 평균 — 0 근처 (마팅게일 보존)
np.float64(499.6)

ensemble 평균이 더 이상 자라지 않고 0 근처. 두 process 를 한 그림에서 비교.

fig, axes = plt.subplots(1, 2, figsize=(8, 4))

# 보정 후: Y_n = X_n^2 - n (martingale, 평균 ≈ 0)

axes[1].axhline(0, color="r", lw=1.2, ls="--", label=r"0")
axes[1].set_title(r"After: $Y_n = X_n^2 - n$ -- martingale (mean stays at 0)")
axes[1].set_xlabel(r"$n$"); axes[1].set_ylabel(r"$Y_n$"); axes[1].legend()

fig.suptitle(r"Ex 3: variance compensation -- before vs after subtracting the mean drift", fontsize=10, y=1.02)
plt.tight_layout(); plt.show()

왼쪽 — 빨간 점선 (\(y = n\)) 위에 검정 ensemble 평균이 정확히 따라간다. submartingale 의 drift 가 1 씩 쌓이는 것. 오른쪽 — 그 drift 를 \(-n\) 으로 정확히 상쇄하니 평균이 0 에 못박힌다. 두 process 는 path 차원에선 같지만 (좌·우 둘 다 같은 진동) drift 부분만 평행이동된다. 이 trick 의 일반화가 Doob-Meyer 분해 (submartingale = martingale + predictable increasing) — HST 분석에도 자주 쓰인다.

- 예제 4 — P'olya urn. 흰 1, 검 1 로 시작. 매 step 무작위 추첨, 그 색 +1. 흰 비율 \(M_n := W_n/(W_n+B_n)\) 이 \([0,1]\) 위 마팅게일.

\[E[M_{n+1} \mid \mathcal F_n] = M_n \cdot \tfrac{W_n + 1}{N_n + 1} + (1-M_n) \cdot \tfrac{W_n}{N_n + 1} = M_n.\]

def polya_path(T):
    W, B = 1, 1
    Ms = np.empty(T)
    for n in range(T):
        if rng.random() < W / (W + B):
            W += 1
        else:
            B += 1
        Ms[n] = W / (W + B)
    return Ms

M4 = np.array([polya_path(T) for _ in range(NPATH)])
M4.shape
(30, 2000)
M4[:5, -1]   # 30 path 중 첫 5 path 의 limit 값 — 0~1 사이 random
array([0.87912088, 0.92557443, 0.86413586, 0.33466533, 0.76623377])
M4[:, -1].mean(), M4[:, -1].std()   # uniform(0,1) 이면 평균 0.5, std 1/√12 ≈ 0.289
(np.float64(0.5200466200466202), np.float64(0.2771201501240363))

평균 0.5, std 0.289 근처 — Uniform(0,1) 의 모멘트와 일치.

\([0,1]\) 위 uniformly bounded martingale → Doob 의 마팅게일 수렴 정리로 \(M_n \to M_\infty\) a.s. 각 path 가 자기만의 random limit 으로 떨어지고, limit 의 분포가 Uniform(0,1). “마팅게일이 수렴한다고 그 극한이 결정론적이라는 뜻은 아니다”.

- 예제 5 — Doubling strategy. \(\epsilon_i = \pm 1\) fair, 베팅 \(a_n\) 은 직전 결과만 봄 (predictable). 잃으면 베팅 2배, 이기면 1로 reset. 누적 손익 \(X_n := \sum a_i \epsilon_i\) — predictable 베팅의 곱은 마팅게일 transform 으로 마팅게일 보존 (Durrett Thm 4.2.8).

def doubling_path(T):
    cur_bet = 1.0; X = 0.0
    Xs = np.empty(T); bets = np.empty(T)
    for i in range(T):
        eps = 1.0 if rng.random() < 0.5 else -1.0
        X += cur_bet * eps
        Xs[i], bets[i] = X, cur_bet
        cur_bet = 1.0 if eps > 0 else min(cur_bet * 2.0, 2**20)
    return Xs, bets

T_dbl = 500; NPATH_dbl = 20
X5 = np.empty((NPATH_dbl, T_dbl)); bets5 = np.empty((NPATH_dbl, T_dbl))
for k in range(NPATH_dbl):
    X5[k], bets5[k] = doubling_path(T_dbl)
X5[:, -1].mean(), X5[:, -1].std()   # 평균 0 근처, std 큼 (베팅 폭발 path 영향)
(np.float64(248.55), np.float64(13.089977081721724))
bets5.max(), bets5.mean()   # 베팅 최대치 — 연패 시 2^k 까지 폭발 (cap 2^20)
(np.float64(4096.0), np.float64(6.1655))
t_dbl = np.arange(1, T_dbl + 1)
fig, axes = plt.subplots(1, 2, figsize=(7.5, 3.5))
for k in range(NPATH_dbl):
    axes[0].plot(t_dbl, X5[k], lw=0.6, alpha=0.6)
axes[0].axhline(0, color="r", lw=0.8)
axes[0].set_title(r"Cumulative fortune $X_n$ (martingale)")
axes[0].set_xlabel(r"$n$"); axes[0].set_ylabel(r"$X_n$")

for k in range(NPATH_dbl):
    axes[1].plot(t_dbl, bets5[k], lw=0.6, alpha=0.6)
axes[1].set_yscale("log")
axes[1].set_title(r"Bet size $a_n$ (predictable, log scale)")
axes[1].set_xlabel(r"$n$"); axes[1].set_ylabel(r"$a_n$")
plt.tight_layout(); plt.show()

왼쪽 path 들이 0 근처에서 진동 — 평균은 공정. 베팅은 log scale 로 그려야 보일 정도로 폭발. 실제 도박장에서 무너지는 이유는 유한한 자본 때문이지 마팅게일 성질 때문이 아니다.

- 예제 6 — Galton-Watson branching. 한 generation 의 인구 \(Z_n\) 이 다음 세대에서 \(Z_{n+1} = \sum_{i=1}^{Z_n} \xi_i\), \(\xi_i \overset{\text{iid}}{\sim} \text{Poisson}(m)\). \(Z_n\) 자체는 마팅게일 아니지만 (\(m \neq 1\) 이면 평균이 \(m^n\) 으로 자람), 정규화 \(M_n := Z_n / m^n\) 이 마팅게일. \(E[M_{n+1} \mid \mathcal F_n] = E[Z_{n+1} \mid \mathcal F_n]/m^{n+1} = m Z_n / m^{n+1} = Z_n/m^n = M_n\).

def gw_path(m, n_steps, max_pop=10**6):
    Zs = [1]
    for _ in range(n_steps):
        z = Zs[-1]
        if z == 0:
            Zs.append(0)
        else:
            Zs.append(min(rng.poisson(m, size=z).sum(), max_pop))
    return np.array(Zs)

T_gw = 25; n_paths_gw = 20
Z_super = np.array([gw_path(1.3, T_gw) for _ in range(n_paths_gw)])
Z_crit  = np.array([gw_path(1.0, T_gw) for _ in range(n_paths_gw)])
Z_sub   = np.array([gw_path(0.7, T_gw) for _ in range(n_paths_gw)])
Z_sub[:5, -1], Z_crit[:5, -1], Z_super[:5, -1]   # 세 regime 의 끝 인구
(array([0, 0, 0, 0, 0]),

 array([   0,    0,    0,    0, 4057]))

m=0.7 은 거의 다 멸종 (0), m=1 도 대부분 멸종, m=1.3 은 일부 폭발 일부 멸종.

t_gw = np.arange(T_gw + 1)
M6_super = Z_super / (1.3 ** t_gw[None, :])
M6_crit  = Z_crit  / (1.0 ** t_gw[None, :])

fig.suptitle("Ex 6: Galton-Watson — $Z_n$ raw (top) vs $M_n$ martingale (bottom)", fontsize=10, y=1.02)

위 행은 raw \(Z_n\) 의 폭발/멸종 거동, 아래 행은 정규화 \(M_n\) 의 마팅게일 거동. Supercritical 에서는 폭발 (\(M_n\) 이 finite random limit) 또는 멸종 (\(M_n \to 0\)). 양쪽 결과의 확률이 멸종 확률 — 마팅게일 평균 1 = 멸종확률·0 + 생존 path 의 평균 limit, 으로 식이 닫힌다.

- HST 연결 — Thm C 가 동작하는 예제. 에이의 abc오희석교수님공유용_v2.tex Theorem C (drift regime) 의 핵심 도구가 바로 이 마팅게일 분해다. \(X_s\) 가 \(b'_s\) 추첨 이전에 결정되므로 \(b'_s \perp (\mathcal F_{s-1}, X_s)\). HST height 를

\[h(v_i, t) = \underbrace{\bar b \sum_{s=1}^t \mathbf{1}\{X_s = v_i\}}_{\text{drift}} + \underbrace{M_t^{(i)}}_{\text{martingale}}, \qquad M_t^{(i)} := \sum_{s=1}^t (b'_s - \bar b)\mathbf{1}\{X_s = v_i\}\]

로 분리하면, \(M_t^{(i)}\) 는 conditional mean 0 + bounded increment → SLLN 으로 \(M_t^{(i)}/t \to 0\) a.s. → \(h(v_i, t) = \bar b \rho_i t + o(t)\).

Star \(K_{1,5}\) (hub + 5 leaves, degree-prop \(\mu_0\)) 를 예제로 잡자. \(\rho_{\text{hub}} = 5/10 = 0.5\), \(\rho_{\text{leaf}} = 1/10 = 0.1\). drift regime (\(\rho_{\text{hub}} \neq \rho_{\text{leaf}}\)) 이라 Thm C 가 동작: \(\mathrm{SD}^2_{\text{hub-leaf}}(t)/t^3 \to \bar b^2(\rho_h - \rho_l)^2/3\).

b = 1.0; b_bar = b / 2.0
# Star K_{1,5}: 노드 0 = hub, 노드 1~5 = leaves
# degree-proportional μ_0: hub 선택 확률 5/10 = 0.5, leaf 각 1/10
degrees = np.array([5, 1, 1, 1, 1, 1])
prob_mu = degrees / degrees.sum()
T_hst = 5000; NP = 30

# walker: degree-proportional random walk (Algorithm A block-only 단순화)
walker_hst = rng.choice(6, size=(NP, T_hst), p=prob_mu)
b_prime_hst = rng.uniform(0, b, size=(NP, T_hst))

hub, leaf = 0, 1
for node, nm in [(hub, "hub"), (leaf, "leaf")]:
    ind = (walker_hst == node).astype(float)
    print(f"rho_{nm} ≈ {ind.mean():.3f}  (theory: {prob_mu[node]:.3f})")
rho_hub ≈ 0.500  (theory: 0.500)
rho_leaf ≈ 0.101  (theory: 0.100)
# height 분해: drift + martingale
def decompose(node):
    ind = (walker_hst == node).astype(float)
    drift = np.cumsum(b_bar * ind, axis=1)
    mart  = np.cumsum((b_prime_hst - b_bar) * ind, axis=1)
    return drift + mart, drift, mart

h_hub, drift_hub, M_hub = decompose(hub)
h_leaf, drift_leaf, M_leaf = decompose(leaf)

t_hst = np.arange(1, T_hst + 1)
print("M_hub[-1]/T mean:", (M_hub[:, -1] / T_hst).mean().round(5))  # → 0
print("M_leaf[-1]/T mean:", (M_leaf[:, -1] / T_hst).mean().round(5))
M_hub[-1]/T mean: -0.00041
M_leaf[-1]/T mean: 0.0
fig, axes = plt.subplots(1, 3, figsize=(8, 3.8))

# (1) h(v_hub) vs drift 항
for k in range(NP):
    axes[0].plot(t_hst, h_hub[k], lw=0.4, alpha=0.4, color="C0")
axes[0].plot(t_hst, b_bar * prob_mu[hub] * t_hst, lw=2.0, color="crimson",
             ls="--", label=r"$\bar{b}\,\rho_h\,t$")
axes[0].set_title(r"$h(v_{\rm hub},\,t)$ vs drift")
axes[0].set_xlabel(r"$t$"); axes[0].legend(fontsize=8)

# (2) M_t / t → 0 (martingale SLLN)
for k in range(NP):
    axes[1].plot(t_hst, M_hub[k] / t_hst, lw=0.4, alpha=0.4, color="C1")
axes[1].plot(t_hst, (M_hub / t_hst).mean(0), lw=1.8, color="k")
axes[1].axhline(0, color="r", lw=1.0, ls="--")
axes[1].set_title(r"SLLN: $M_t^{(\rm hub)}/t \to 0$")
axes[1].set_xlabel(r"$t$"); axes[1].set_ylabel(r"$M_t/t$")

# (3) SD²/t³ → Thm C constant
SD2 = np.cumsum((h_hub - h_leaf)**2, axis=1)
thm_c = b_bar**2 * (prob_mu[hub] - prob_mu[leaf])**2 / 3
for k in range(NP):
    axes[2].plot(t_hst, SD2[k] / t_hst**3, lw=0.4, alpha=0.4, color="C3")
axes[2].plot(t_hst, (SD2 / t_hst**3).mean(0), lw=1.8, color="k", label="mean")
axes[2].axhline(thm_c, color="r", lw=1.5, ls="--",
                label=rf"Thm C: ${thm_c:.5f}$")
axes[2].set_title(r"Thm C: $\mathrm{SD}^2/t^3 \to \bar{b}^2(\rho_h-\rho_l)^2/3$")
axes[2].set_xlabel(r"$t$"); axes[2].legend(fontsize=8)

fig.suptitle(r"HST on Star $K_{1,5}$: height $=$ drift $+$ martingale $\Rightarrow$ Thm C",
             fontsize=10, y=1.02)
plt.tight_layout(); plt.show()

왼쪽 — \(h(v_{\text{hub}},t)\) path 들이 빨간 점선 (이론 drift \(\bar b \rho_h t\)) 주위를 따라간다. 가운데 — 마팅게일 잔차 \(M_t^{(\text{hub})}/t\) 가 0 으로 수렴 (SLLN). 오른쪽 — \(\mathrm{SD}^2_{\text{hub-leaf}}(t)/t^3\) 이 Theorem C 상수 (빨간 점선) 로 수렴. 세 그림이 height 분해 → SLLN → Thm C 의 한 흐름을 한눈에 보여준다.

여섯 예제를 한 줄로 묶으면 — 마팅게일은 결정론적 stationary 가 아니라 ensemble-평균 stationary. 개별 path 는 자유롭게 진동하거나 폭발하거나 random limit 을 가질 수 있지만, 매 step 의 조건부 평균 변동이 정확히 0 이라는 그 한 조건이 모든 path 를 한 쇠줄로 묶는다. 도박, 인구 동력학, 강화학습, 금융, HST 의 height 잔차 등 어디서나 마팅게일이 자연스럽게 튀어나오는 이유다. “평균이 변하지 않는다” 라는 가장 약한 통제만으로 정리의 칼날이 살아남는다.

마팅게일이 살아남으면 어떤 일이 일어나는가 — SLLN, CLT, optional stopping, concentration — 은 다른 글의 주제 (260522_210331.html Durrett 4.5.3 + HST Theorem C Step 1 적용).
