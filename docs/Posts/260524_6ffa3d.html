연구 ▷ HST ▷ Pushforward Density of \(\Delta_1 U\)

Author

유진

Published

May 24, 2026

\((X_2-X_1,\ldots,X_n-X_1)\)은 HST 초기 설정에서 상대 높이 벡터다. 절대 높이 \(X_i\)는 시간이 지날수록 무한히 커지지만, 상대 높이는 bounded region에 머문다. Lemma 4는 이 벡터의 pushforward density가 특정 영역 안에서 아래로 균일하게 bound됨을 보인다.

Lemma 4 (Pushforward density). Let \(X_1,\ldots,X_n\overset{\text{iid}}{\sim}\text{Unif}(0,b)\). The density \(f_{\text{pdf}}\) of \((X_2-X_1,\ldots,X_n-X_1)\) satisfies \[f_{\text{pdf}}(y_2,\ldots,y_n)\;\geq\;\frac{b^{1-n}}{2}\qquad\text{whenever }\max_{i\geq 2}|y_i|<\frac{b}{4}.\]

Proof. Set \(Y_1:=X_1\) and \(Y_i:=X_i-X_1\) for \(i\geq 2\). The map \((X_1,\ldots,X_n)\mapsto(Y_1,\ldots,Y_n)\) is lower-triangular with Jacobian \(1\), so the joint density of \((Y_1,\ldots,Y_n)\) equals that of \((X_1,\ldots,X_n)\): \[f_{Y_1,\ldots,Y_n}(y_1,\ldots,y_n)=b^{-n}\cdot\mathbf{1}[X\in[0,b]^n].\] The inverse \(X_1=Y_1\), \(X_i=Y_1+Y_i\) rewrites the feasibility constraint as \[X_1=Y_1\in[0,b],\qquad X_i=Y_1+Y_i\in[0,b]\;\Rightarrow\;Y_1\in[-Y_i,\,b-Y_i]\quad(i=2,\ldots,n).\] Combining, \(X\in[0,b]^n\;\Leftrightarrow\;y_1\in[c^-,c^+]\) where \[c^+=b-\max(0,\max_{i\geq 2}y_i),\qquad c^-=\max(0,-\min_{i\geq 2}y_i).\] The marginal density of \((Y_2,\ldots,Y_n)\) is obtained by integrating out \(Y_1\): \[f_{\text{pdf}}(y_2,\ldots,y_n)=\int_{-\infty}^{\infty}f_{Y_1,\ldots,Y_n}(y_1,\ldots,y_n)\,dy_1=\int_{c^-}^{c^+}b^{-n}\,dy_1=b^{-n}(c^+-c^-).\] Under \(\max_{i\geq 2}|y_i|<b/4\): \(c^+>3b/4\) and \(c^-<b/4\), so \(c^+-c^->b/2\), giving \(f_{\text{pdf}}>b^{1-n}/2\). \(\square\)

해설. 핵심 아이디어는 \(Y_i:=X_i-X_1\)으로 좌표를 바꾸면 \(Y_1\) 하나에만 적분이 남는다는 것이다. \(b/4\) 조건은 \(n\)개의 uniform 구간 \([0,b]\), \([-Y_i,\,b-Y_i]\)의 공통 부분이 길이 \(b/2\) 이상임을 보장한다. \(n\)이 커질수록 하한 \(b^{1-n}/2\)은 작아지지만, \(\max_{i\geq 2}|y_i|<b/4\) 안에서 density가 uniformly positive하다는 성질은 보존된다.

import numpy as np
import matplotlib.pyplot as plt
import pathlib

plt.rcParams.update({'text.usetex': True, 'font.family': 'serif'})

b = 1.0
N = 300_000
rng = np.random.default_rng(42)

fig, axes = plt.subplots(1, 2, figsize=(8, 3))

# n=2: Y_2 = X_2 - X_1, exact density = triangular (b-|y|)/b^2
X = rng.uniform(0, b, (N, 2))
Y2 = X[:, 1] - X[:, 0]

ax = axes[0]
y = np.linspace(-b, b, 500)
f_exact = (b - np.abs(y)) / b**2
ax.hist(Y2, bins=120, density=True, alpha=0.35, color='steelblue')
ax.plot(y, f_exact, 'k-', lw=1.5, label=r'exact $f_{\mathrm{pdf}}$')
ax.axhline(1/(2*b), color='tomato', lw=1.5, ls='--', label=r'lower bound $\frac{b^{1-n}}{2}$')
ax.axvspan(-b/4, b/4, alpha=0.18, color='orange', label=r'$|y_2|<b/4$')
ax.set_xlabel(r'$y_2$'); ax.set_title(r'$n=2$')
ax.legend(fontsize=7.5); ax.set_xlim(-b, b)

# n=3: (Y_2, Y_3) = (X_2-X_1, X_3-X_1)
X = rng.uniform(0, b, (N, 3))
Y2 = X[:, 1] - X[:, 0]
Y3 = X[:, 2] - X[:, 0]

ax = axes[1]
h = ax.hist2d(Y2, Y3, bins=80, density=True, cmap='Blues')
fig.colorbar(h[3], ax=ax, label='density')
from matplotlib.patches import Rectangle
ax.add_patch(Rectangle((-b/4, -b/4), b/2, b/2,
    fill=False, edgecolor='tomato', lw=2, label=r'$\max|y_i|<b/4$'))
ax.set_xlabel(r'$y_2$'); ax.set_ylabel(r'$y_3$'); ax.set_title(r'$n=3$')
ax.legend(fontsize=7.5)

fig.tight_layout()
out = pathlib.Path('../results/figures/260524_유진_HST_Lemma4pushforwarddensity.qmd')
out.mkdir(parents=True, exist_ok=True)
fig.savefig(out / 'lemma4_sim.png', dpi=150)
plt.show()
