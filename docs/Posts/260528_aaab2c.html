연구 ▷ HST ▷ AAA 알고리즘 정리 + BAB에서 본 두 현상 (Cov 잔차·핑퐁 atom)

Author

소미

Published

May 28, 2026

HST의 한 step에는 세 차원의 자유도가 있다. 각 차원의 옵션 A — 본 글의 정본 — 를 풀어 적으면 다음과 같다.

  1. snowfall — 매 step 쌓는 눈 크기 \(b'\)를 어떻게 뽑을지. 옵션은 네 가지.
    • 옵션 A (정본): 매 step 새로 \(b'_{t+1}\sim\mathrm{Unif}(0,b)\) 를 독립적으로 뽑는다 — past randomness 와 무관, 다음 step 의 추첨과도 무관.
    • 옵션 B: 라운드 시작에 한 번 \(b'^{(r)}\sim\mathrm{Unif}(0,b)\) 를 뽑아 그 라운드의 모든 deposit 에 같은 값을 재사용한다 — 라운드 내부 deposit 은 완전 상관.
    • 옵션 C: B 처럼 라운드 시작에 한 번 \(b'^{(r)}\sim\mathrm{Unif}(0,b)\) 를 뽑은 뒤 step-내 감쇠 함수 \(f\) 를 곱해 \(b'_{t_r+s} := b'^{(r)} f(s)\) 로 쓴다 — 라운드 안에서 deposit 이 점진적으로 변하는 양식. 감쇠 \(f\) 는 사전에 정해 두는 추가 자유도. 본 글은 미사용.
    • 옵션 D: deterministic. 매 step \(b'_s = b\) 로 고정, 추첨 없음. legacy 양식, 본 글은 미사용.
  2. flow — walker 가 현재 노드에서 어디로 흐를지. 옵션은 두 가지(C/D 없음).
    • 옵션 A (정본): downstream-filter — 현재 노드 \(X_t\) 의 이웃 중 높이가 같거나 낮은 노드 집합 \(\mathcal D_t=\{u\sim X_t : h(u,t)\le h(X_t,t)\}\) 에서만 차수-가중 확률로 다음 노드를 뽑는다. uphill 로는 절대 흐르지 않는다.
    • 옵션 B: 모든 이웃에서 일단 뽑은 뒤 결과가 uphill 이면 그 step 을 block 처리(=walker 제자리, 다음 step Fall).
  3. \(T_{\max}\) — block timer 상한값을 어떻게 정할지. 옵션은 두 가지(C/D 없음).
    • 옵션 A (정본): 라운드마다 새로 \(T_{\max}^{(r)}\sim\mathrm{Unif}\{n,\dots,2n\}\) 을 뽑아 라운드별로 다른 timer 한계를 쓴다 — 즉 \(T_{\max}\) 자체가 \(n\) 과 \(2n\) 사이의 random 정수.
    • 옵션 B: 입력 매개변수로 받은 상수를 모든 라운드에 고정으로 쓴다.

세 차원의 옵션을 한 글자씩 모아 모델 코드 \(\langle\)snowfall\(\rangle\langle\)flow\(\rangle\langle T_{\max}\rangle\) 로 적는다. snowfall 은 4 종, flow·\(T_{\max}\) 는 각각 2 종이라 가능한 모델 코드는 \(4\times 2\times 2 = 16\) 가지. 우리가 정본으로 쓰는 모델은 AAA = (A, A, A) — 세 차원 모두 옵션 A. 비교 대상은 BAB = (B, A, B) — flow 차원은 양쪽 모두 A 에 둔 채 snowfall 과 \(T_{\max}\) 만 옵션 B 로 바꾼 모델.

본 글은 BAB 에서 시뮬로 관찰되는 두 현상 — 누적 적설량이 단순 기대와 어긋나게 만드는 Cov 잔차, 그리고 \(K_2\) 의 높이차에 atom 을 만드는 핑퐁 동역학 — 을 정리한다. 두 현상 모두 snowfall A→B 의 차이가 만들어낸다. 한 라운드는 Fall 로 시작해 Flow 를 이어가다 Block (또는 timer 소진) 으로 끝나며, 라운드 \(r\) 의 길이를 \(m_r\), 라운드 동안 노드 \(i\) 의 방문수를 \(N_r^{(i)}\) (\(m_r=\sum_i N_r^{(i)}\)) 로 적는다 — 아래 식에서 쓴다.

현상 1 — 누적 적설량이 단순 기대와 어긋난다 (Cov 잔차)

실험 그래프는 노드 10 개의 완전그래프 \(K_{10}\) — 모든 노드 쌍이 직접 이웃이고 차수가 9로 균일, vertex-transitive (모든 노드가 구조적으로 동등).

\(K_{10}\) 위에서 \(b=0.05\), \(T\) step 시뮬한다. 매 step 의 \(b'\) 기대값은 두 모델 모두 \(\bar b=b/2=0.025\)이고, vertex-transitive 대칭으로 walker 의 stationary 방문율도 두 모델 모두 \(\rho_i=1/n=0.1\) 로 결정된다. 그래서 노드 \(i\)의 적설률 \(\tilde\rho_i:=\lim_t h_i(t)/t\) 는 순진한 기대로

\[\tilde\rho_i \;\stackrel{?}{=}\; \bar b\,\rho_i \;=\; 0.025\times 0.1 \;=\; 0.0025\]

이 되어야 할 것 같다. 시뮬로 두 모델을 같은 walker 규칙으로 돌려보자.

Code 
import numpy as np

B = 0.05; bbar = B / 2

def run(W, T, model, seed, fixed_maxflow=None):
    """공통: flow A(downstream) + block-stay. AAA: per-step b + T_max~U[n,2n].
       BAB: per-round b + fixed T_max."""
    n = W.shape[0]; deg = W.sum(1); mu0 = deg / deg.sum()
    nb = [np.where(W[i] > 0)[0] for i in range(n)]
    rng = np.random.default_rng(seed)
    h = np.zeros(n); visit = np.zeros(n, np.int64)
    draw_mf = lambda: int(rng.integers(n, 2*n+1)) if model == "AAA" else (fixed_maxflow or 2*n)
    maxflow = draw_mf(); Z = maxflow; X = 0
    b_round = float(rng.uniform(0, B))
    N_r = np.zeros(n, np.int64); rec_b = []; rec_N = []
    for t in range(T):
        fall = (Z >= maxflow)
        if fall:
            if N_r.sum() > 0:
                rec_b.append(b_round); rec_N.append(N_r.copy())
            maxflow = draw_mf(); b_round = float(rng.uniform(0, B)); Z = 0
            N_r = np.zeros(n, np.int64)
            b_step = float(rng.uniform(0, B)) if model == "AAA" else b_round
            X = int(rng.choice(n, p=mu0))
        else:
            b_step = float(rng.uniform(0, B)) if model == "AAA" else b_round
            nbr = nb[X]; down = nbr[h[nbr] <= h[X]]
            if len(down) > 0:
                w = W[X, down]; X = int(rng.choice(down, p=w/w.sum())); Z += 1
            else:
                Z = maxflow   # block: 제자리
        h[X] += b_step; visit[X] += 1; N_r[X] += 1
    return h, visit, np.array(rec_b), np.stack(rec_N)

n = 10; W = np.ones((n, n)) - np.eye(n); T = 800_000
res = {}
for model in ["BAB", "AAA"]:
    h, visit, rb, RN = run(W, T, model, seed=20, fixed_maxflow=2*n)
    rho = (visit / visit.sum())
    excess = h / T - bbar * (visit / T)              # = Cov_i / m̄
    cov_i = np.array([np.cov(rb, RN[:, i])[0, 1] for i in range(n)])
    mean_hT = (h / T).mean()
    expected = bbar * rho.mean()
    print(f"[{model}] 노드당 h/T 평균 = {mean_hT:.5f}   "
          f"(순진한 기대 b̄ρ_i = {expected:.5f},  잉여 {(mean_hT/expected-1)*100:+5.1f}%)")
    print(f"        Cov_i 평균 = {cov_i.mean():+.2e}   |excess_i| 평균 = {np.abs(excess).mean():.2e}")
    res[model] = excess

AAA는 시뮬값이 순진한 기대 \(0.0025\)와 정확히 일치한다. BAB는 노드당 약 \(0.0029\) — 기대보다 16% 더 쌓인다. 매 step의 \(b'\) 평균은 두 모델 모두 \(\bar b\)로 같은데, 왜 BAB만 더 쌓이는가? 라운드 단위로 풀면 보인다. BAB에서 라운드 \(r\)의 총 적설은 \(b'^{(r)}m_r\)이므로 한 step당 평균 적설은

\[\frac{\mathbb E_\pi\!\big[b'^{(r)}m_r\big]}{\mathbb E_\pi[m_r]} \;=\;\frac{\bar b\,\mathbb E_\pi[m_r]+\mathrm{Cov}_\pi(b'^{(r)},m_r)}{\bar m} \;=\;\bar b+\frac{\mathrm{Cov}_\pi(b'^{(r)},m_r)}{\bar m}\qquad(\ast)\]

다. 즉 큰 \(b'\)를 뽑은 라운드가 평균보다 길거나 짧으면 누적 적설량이 \(\bar b\)에서 그만큼 어긋난다. \(K_{10}\) 측정에서 \(\mathrm{Cov}_\pi(b'^{(r)},m_r)>0\) — 큰 \(b'\)의 라운드가 약간 더 길다 — 그 결합이 +16% 잉여로 나타난다.

노드별로 분해해도 같은 식의 노드 버전:

\[\tilde\rho_i\;=\;\bar b\,\rho_i+\frac{\mathrm{Cov}_\pi(b'^{(r)},N_r^{(i)})}{\bar m}\qquad(\ast\ast)\]

AAA에선 매 step의 \(b'_s\)가 그 step의 위치 \(X_s\)와 독립이므로 \(\mathrm{Cov}\equiv 0\), 식 \((\ast\ast)\)가 즉시 \(\tilde\rho_i=\bar b\rho_i\)로 닫혀 그래프에서 결정되는 \(\rho_i\)와 \(b\)만 알면 노드별 적설률이 끝난다 — 시뮬 없이 답이 떨어진다.

BAB에선 라운드 내내 같은 \(b'^{(r)}\)가 모든 deposit에 들어가고, 그 라운드의 walker 패턴 \(N_r^{(i)}\)는 같은 \(b'^{(r)}\)가 만든 높이지형에서 결정되어 \(\mathrm{Cov}_i\neq 0\). 그리고 이 잔차는 \(\bar b\)나 \(\rho_i\) 같은 그래프 invariant 하나로 환원되지 않는다 — 큰 \(b'\)가 어느 정도로 더 긴 라운드 / 더 많은 특정 노드 방문과 결합되는지는 walk dynamics와 그래프 구조의 joint 통계라, 시뮬해야 비로소 값이 나온다. 그래프만 보고는 16%인지 5%인지 50%인지 미리 추측할 수 없다.

이 잔차를 노드별로 띄우면 다음과 같다.

\(K_{10}\)의 대칭성으로 \(\mathrm{Cov}_i\)가 노드별 균등해, BAB의 잉여도 모든 노드에서 동일한 +0.4×10⁻³이다. 그러니 balance(\(\tilde\rho_i\)의 노드 간 동일성) 자체는 우연히 보존된다. 다만 그 값은 \(\bar b\rho_i\)가 아니라 graph+dynamics joint 통계에 의해 결정되어 시뮬에서야 보인다는 점이 현상의 핵심이다.

현상 2 — \(K_2\)의 핑퐁 동역학이 높이차에 atom을 만든다

가장 작은 connected 그래프 \(K_2\)에서 BAB를 한 step씩 따라가 보자. 라운드 시작 Fall: 한 노드(예: 0)에 deposit \(b'^{(r)}\). \(h=(b'^{(r)},0)\), \(Z=0\). Step 2: walker at 0, 이웃 \(=\{1\}\), \(h_1=0\le h_0=b'^{(r)}\) → flow, \(h_1\mathrel{+}=b'^{(r)}\). \(h=(b'^{(r)},b'^{(r)})\), \(Z=1\). Step 3: walker at 1, 이웃 \(=\{0\}\), \(h_0=b'^{(r)}\le h_1=b'^{(r)}\) → flow, \(h_0\mathrel{+}=b'^{(r)}\). \(h=(2b'^{(r)},b'^{(r)})\), \(Z=2\). 핑퐁이 계속되며 — 모든 deposit이 같은 \(b'^{(r)}\)이므로 — 높이차 \(\delta=h_2-h_1\)이 정확히 \(0\)과 \(b'^{(r)}\)를 번갈아 오간다.

라운드는 \(Z\)가 \(T_{\max}\)에 닿을 때 끝나는데, 그 시점의 \(\delta\)는 라운드 안 deposit 수의 홀짝에 따라 결정된다. \(1+T_{\max}\)가 짝수면(예: \(T_{\max}=3\)) 라운드 경계의 \(\delta\)가 정확히 \(0\)으로 돌아오는 경우가 발생해, 전체 step 가운데 \(\delta=0\)인 비율이 정확히 50%가 된다. AAA에선 같은 핑퐁이라도 매 step의 \(b'_s\)가 독립이라 \(\delta\)에 독립 증분이 누적되어 연속 분포로 퍼진다.

Code 
W2 = np.array([[0., 1.], [1., 0.]])
T2 = 150_000

def run_delta(model, fixed_maxflow, seed=7):
    n = 2; mu0 = np.array([0.5, 0.5]); nb = [np.array([1]), np.array([0])]
    rng = np.random.default_rng(seed)
    h = np.zeros(2)
    draw_mf = lambda: int(rng.integers(n, 2*n+1)) if model == "AAA" else fixed_maxflow
    maxflow = draw_mf(); Z = maxflow; X = 0; b_round = float(rng.uniform(0, B))
    out = np.empty(T2)
    for t in range(T2):
        if Z >= maxflow:
            maxflow = draw_mf(); b_round = float(rng.uniform(0, B)); Z = 0
            b_step = float(rng.uniform(0, B)) if model == "AAA" else b_round
            X = int(rng.choice(2, p=mu0))
        else:
            b_step = float(rng.uniform(0, B)) if model == "AAA" else b_round
            nb_x = nb[X]; down = nb_x[h[nb_x] <= h[X]]
            if len(down) > 0:
                X = int(down[0]); Z += 1
            else:
                Z = maxflow
        h[X] += b_step; out[t] = h[1] - h[0]
    return out

d_bab = run_delta("BAB", 3)        # 1+T_max = 4 (짝수)
d_aaa = run_delta("AAA", None)
for tag, d in [("BAB(1+Tmax even)", d_bab), ("AAA", d_aaa)]:

AAA(파랑)는 평균 0 근처의 매끈한 연속 분포. BAB(\(1+T_{\max}\) 짝수, 빨강)는 \(\delta\)가 \([-b,b]\)에 갇히고 \(\delta=0\)에 절반의 질량이 atom으로 솟는다 — Lebesgue-영집합 위에 양의 질량이 얹힌 것, 즉 \(\delta\)의 법칙이 절대연속이 아닌 특이 성분을 갖는다. 라운드의 핑퐁 동역학과 같은 \(b'^{(r)}\)의 라운드 내 재사용이 결합해 만들어 낸 결과다.

두 현상의 출처는 같다 — BAB의 라운드 동안 같은 \(b'\) 재사용(snowfall B)이다. AAA의 per-step 독립(snowfall A)에서는 식 \((\ast)\,(\ast\ast)\)의 공분산이 \(\equiv 0\)이 되고, \(K_2\) 핑퐁이 만든 atom은 연속 증분에 풀려 사라진다.
