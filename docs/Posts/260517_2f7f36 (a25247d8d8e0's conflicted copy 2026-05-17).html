이 문서는 계속 자라는 노트다. 대표(2026-05-17)의 가설 — “HST 의 multi-scale 거리 분해가 그래프 안에 숨은 고차구조(higher-order structure)의 자동 검출 도구가 될 수 있다” — 를 출발점으로, 매핑·근거·반론·실험 항목을 차곡차곡 추가해 간다. 현 버전은 v0.1 초안.

0. 한 줄 직관

Important요지

HST 의 \(\SD^2/t,\ \SD^2/t^2,\ \SD^2/t^3\) 세 regime 은 노드 쌍에 자동으로 부여되는 “차원” 이다. 그래프가 보이는 1-cell (edge) 만으로 코딩되었어도, HST 는 그 안에 잠재된 2-cell·3-cell 의 흔적을 t-스케일링 차수로 분리해낸다 — 라는 가설.

1. 출발점: 더블헬름이 보여준 것

더블헬름(double helm) 그래프 \(H_{2,n}\) 은 중앙 1개 (빨강), 안쪽 ring \(n\)개 (파랑), 안쪽 외팔 \(n\)개 (안쪽 녹색), 바깥쪽 ring \(n\)개 (보라), 바깥쪽 외팔 \(n\)개 (바깥쪽 녹색) 의 다섯 노드 그룹으로 구성된다.

같은 그래프 위에서 노드 쌍들이 보이는 SD² 곡선의 점근 거동은 균일하지 않다.

  • 빨강 ↔︎ 파랑 한 쌍: 점유율이 비슷 → \(\SD^2/t \to c\) (Regime A)
  • 안쪽 녹색끼리 (서로 대칭 위치): \(\SD^2/t^2 \to \sigma^2/2\) (Regime C)
  • 빨강 ↔︎ 바깥쪽 보라: 점유율 크게 다름 → \(\SD^2/t^3 \to \bar b^2 (\rho_i - \rho_j)^2 / 3\) (Regime B)

이게 단순히 “노드 점유율 \(\rho_i\) 의 분포 차이”의 귀결이라는 것은 이미 알려져 있다. 그러나 한 그래프에서 세 regime 이 동시에 등장한다는 사실 자체가 그래프 구조에 잠재된 계층을 드러낸다 — 이게 대표가 던진 핵심 관찰.

2. 핵심 주장 — Hodge 분해의 친척

Important작업 가설

HST 의 multi-scale 분해는 simplicial complex 의 Hodge 분해

\[ \mathrm{cochain}^k = \mathrm{im}\,\partial_k^* \;\oplus\; \ker\Delta_k \;\oplus\; \mathrm{im}\,\partial_{k+1} \]

와 (정확히 일치하진 않지만) 닮은 일을 한다. 즉 HST 의 \(t\)-스케일링 차수가 grid (cell 차원) 와 자연스럽게 짝지어진다.

2.1 Lyapunov 함수의 quadratic form

HST 의 핵심 도구인 Lyapunov 함수 \(\Phi(t) = \sum_i \hbar_i(t)^2 = \hbar^\top \hbar\) 는 centered height \(\hbar = h - \bar h\) 의 \(\ell^2\) 제곱. 한편 표준 graph Laplacian \(\mathbf L = \mathbf D - \mathbf W\) 의 quadratic form 은

\[ \hbar^\top \mathbf L \hbar \;=\; \tfrac{1}{2}\sum_{(i,j) \in \calE} W_{ij}\,(\hbar_i - \hbar_j)^2. \]

HST 의 flow step 은 본질적으로 \((\hbar_i - \hbar_j)\) 가 큰 edge 위에서 일어나는 운반. 따라서 \(\Phi\) 의 시간변화는 곧 \(\mathbf L\) 의 spectral mode 별 진폭변화로 해석할 수 있다. 이게 첫 번째 다리.

2.2 매핑 표 (v0.1, 정밀화 예정)

HST 의 관찰 Hodge / 차원 해석
\(\Phi(t) = \hbar^\top \hbar = \bsh^\top \mathbf L^+ \mathbf L \bsh\) k=0 cochain space 의 norm; \(\mathrm{im}\,\partial_1\) 안에 살고 있음
\(\SD^2/t\) regime (Balanced) \(\ker \Delta_0 = \mathbf{1}\) 직교 평면 위 평활화 — k=0 stationary mode
\(\SD^2/t^2\) regime (Intermediate) 동일 점유율 두 노드가 만드는 1-cycle 위의 잔존 drift — k=1 mode 의 graph harmonic
\(\SD^2/t^3\) regime (Drift) 글로벌 점유율 불균형 = \(\ker \Delta_0\) 에 직교한 component 의 1-차 polynomial 성장
Block 사건 flow chain 의 길이 한정 — \(\partial\) 의 chain decomposition 에 대응

2.3 왜 \(t, t^2, t^3\) 인가 (직관)

centered height 의 누적합 \(H_n := \sum_{s=1}^n \hbar(s)\) 의 평방이 \(\SD^2(t)\) 의 본질. 노드 \(i, j\) 의 차이 \(\hbar_i(s) - \hbar_j(s)\) 의 시간 누적이 :

  • 평균 0 의 마팅게일에 가까울 때 (Balanced): \(\Var(H_n) \sim t\) → \(\SD^2 \sim t\).
  • 일정한 변동성을 가진 stationary process 의 부분합 (Intermediate): \(\Var(H_n) \sim t^2/2\) → \(\SD^2 \sim t^2\).
  • 일정한 평균 drift 를 가진 (Drift): \(H_n \sim t \cdot \text{(drift)}\), 그 평방의 누적 \(\sim t^3/3\) → \(\SD^2 \sim t^3\).

세 거동은 fluctuation 의 차수 (\(O(\sqrt t)\), \(O(1)\), \(O(t)\)) 에 해당하며, 이는 곧 노드 쌍이 만드는 “유효 차원”을 나누는 것과 같다 — 0차원 (잡음), 1차원 (cycle), 2차원 (drift). 차원 부여가 자동.

3. Topological signal generalization

NoteFall/Flow/Block 의 cell 차원 일반화 (제안)

현재 HST 의 신호 \(y\) 는 vertices 에 산다 (k=0 cochain). 토폴로지 시그널 처리(TSP) 의 진짜 일반화는 신호가 edges (k=1), triangles (k=2) 등 더 높은 cell 에 사는 경우.

자연스러운 확장 시안:

HST step k=0 (현재) k≥1 일반화
Fall 노드 \(v_i\) 에 눈 \(+b\) \(k\)-cell \(\sigma\) 에 눈 \(+b\), \(\mu_0\) 은 cell volume 비례
Flow 이웃 중 낮은 노드로 이동 \(\partial_k\) 또는 \(\partial_k^*\) 를 따라 인접 cell 로 이동, “더 낮은 cochain 값” 우선
Block 이웃이 모두 높거나 \(T_{\max}\) 회 flow flow 가능한 인접 cell 이 없거나 차원 전환 필요 시

특히 Block 의 정의가 핵심: simplicial complex 에서는 한 cell 에서 나가는 boundary 가 여러 차원으로 분기 가능 (예: triangle → 3개 edges; edge → 2개 vertices). “더 이상 흐를 곳이 없다”의 cell-차원-별 정의가 필요.

후보 A — 차원 고정형

한 라운드 안에서는 항상 동일 차원 \(k\) 의 cell 사이만 이동. Block 후 차원은 그대로. 가장 단순하지만 차원 간 정보 흐름이 없다.

후보 B — Hodge-호환형

\(\Delta_k = \partial_{k+1} \partial_{k+1}^* + \partial_k^* \partial_k\) 의 두 항을 각각 flow 모드로: - “down-flow”: \(\partial_k^*\) — 차원 ↓ (예: edge → vertex) - “up-flow”: \(\partial_{k+1}\) — 차원 ↑ (예: edge → triangle 의 face)

매 step 에서 둘 중 더 큰 height gradient 가 있는 쪽 선택. 자연스럽지만 분석 난도 ↑.

후보 C — Random-dimension Fall

Fall 시점에 차원 \(k\) 를 추첨 (cell 개수 비례). 이후 flow 는 그 차원 내. Block 후 다시 Fall 추첨. 모델 B 의 round-단위 추첨과 호환.

후보 C 가 사내 모델 B 결정 (round-시작 시 1회 추첨) 의 직접적 연장이라 가장 자연스러워 보임.

4. 한 가지 명시적 caveat

Tip너무 쉽게 결론짓기 전에

\(t^1, t^2, t^3\) 분리는 점유율 분포의 직접적 귀결일 뿐, 그 자체가 고차구조의 검출은 아니다. 고차구조 검출을 주장하려면 적어도 다음을 보여야 한다:

  1. 점유율 분포 자체가 cell 차원 구조와 정량적으로 일대일 대응됨 (혹은 일대다 대응이라도 명시적 함수로)
  2. 위 §3 의 cell 차원 일반화가 실제로 작동 — 단순 simplicial complex 한 개 (예: octahedron, complete bipartite 위의 \(K_3\)-flag) 에서 두 차원의 신호가 분리되어 관찰됨
  3. 분리된 신호가 Hodge basis 와 잘 정렬됨 (그래프 spectral matching 정도가 아니라 cell-차원 단위)

이 셋이 안 보이면 “다중 스케일 노드 임베딩” 정도로 표현이 절제되어야 한다.

6. 회사 본업과의 정합성

가장 중요한 점: 위 가설이 사실이라 해도 HST 본 논문의 기본형은 그대로 유지된다. 고차구조 일반화는 이지 base case 가 아니다. 사내 본 논문 (Choi–Oh) 이 vertex-도메인 함수 \(y: \calV \to \mathbb R\) 에 집중한 것은 의도된 범위 설정; 본 노트의 가설이 실험적으로 확인되면 별도 후속 논문 (또는 본 논문의 Discussion §6 의 확장 항목) 으로 분리되는 게 자연스럽다.
