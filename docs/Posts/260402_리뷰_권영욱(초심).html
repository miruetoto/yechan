4. Tensor data

텐서(Tensor)란?

행렬(matrix)을 고차원으로 일반화한 자료구조로, 고차원 데이터를 표현하는 수학적 객체

실세계 데이터의 텐서 표현 예시

  1. 그레이스케일 이미지 컬렉션 (너비 × 높이 × 피험자 수)
  2. 컬러 동영상 (너비 × 높이 × 프레임 × RGB 채널)
  3. 일일 교통 데이터 (도로 구간 × 시간대 × 날짜)
  4. 추천 시스템 (사용자 × 아이템 × 페이지)

텐서 기반 모델의 장점

행렬 기반 모델과 달리 데이터를 평탄화(flattening)하지 않고, 데이터의 고유한 다차원 구조를 보존하며 데이터 간의 내재적 관계를 유지함

추가 해설: Multi-way structure와 Flattening

Multi-way structure란?

데이터가 여러 개의 방향(mode/way)으로 조직되어 있다는 의미입니다.

예시: 이미지 컬렉션

텐서 X: (64 × 64 × 100)
        ↓    ↓     ↓
      너비  높이  피험자

이 데이터는 3-way 구조를 가집니다: - 1st way (너비): 가로축 픽셀 위치 - 2nd way (높이): 세로축 픽셀 위치 - 3rd way (피험자): 서로 다른 개인들

각 “way”는 독립적인 의미를 가진 차원이며, 데이터는 이 세 방향의 교차점에서 값을 가집니다.

Flattening이란?

다차원 구조를 2차원 행렬(또는 1차원 벡터)로 펴는 것을 의미합니다.

예시 1: 이미지를 벡터로

원본: 28×28 이미지
      ┌─────────┐
      │ ■ □ ■ □ │  28×28 = 784개 픽셀
      │ □ ■ □ ■ │
      └─────────┘

Flatten ↓

결과: [■, □, ■, □, □, ■, □, ■, ...] ← 784차원 벡터

예시 2: 이미지 컬렉션을 행렬로

원본: 64×64×100 텐서 (이미지 100장)

방법 1: 각 이미지를 벡터로 flatten
┌                    ┐
│  image1_flattened  │ ← 4096차원 (64×64)
│  image2_flattened  │ ← 4096차원
│        ...         │
│ image100_flattened │ ← 4096차원
└                    ┘
결과: 100×4096 행렬

방법 2: 다른 방식으로 재배열
64×(64×100) 행렬 또는 (64×64)×100 행렬 등...

Flattening의 문제점 (슬라이드의 주장): 1. 공간적 인접성 상실: 원래 이웃했던 픽셀들의 관계가 벡터에서는 멀어질 수 있음 2. 차원 간 관계 파괴: “너비”와 “높이”의 독립적 의미가 하나의 “픽셀 인덱스”로 합쳐짐 3. 정보 손실: 구조적 패턴을 모델이 다시 학습해야 함

비판적 검토

교통 데이터 (도로 구간 × 시간대 × 날짜):

  • 이 구조가 정말 “텐서”로서 의미가 있는가?
  • 실제 교통 데이터는 시계열 특성이 강함: 시간적 자기상관, 트렌드, 계절성
  • 날짜를 독립적인 차원으로 다루는 것은 부적절 → 시계열 모델(ARIMA, LSTM)이 더 자연스러움
  • 도로 구간 간의 공간적 의존성도 중요 → GNN이나 시공간 모델이 더 적합
  • 텐서 분해로는 이런 시간적/공간적 동역학을 제대로 포착하기 어려움

추천 시스템 (사용자 × 아이템 × 페이지):

  • 실제로 이런 3차원 텐서로 모델링하는 경우는 매우 드묾
  • 대부분의 추천 시스템은 여전히 2차원 행렬 분해 또는 그래프 기반 접근법 사용
  • “페이지” 차원을 추가하는 것이 실제로 의미 있는 정보를 제공하는지 의문
  • 맥락 정보(context)는 보통 feature로 인코딩하는 것이 더 유연함

5. Low-rank tensor recovery

문제 배경

데이터 수집 장비 손상과 노이즈로 인해 관측된 텐서는 종종 결측값(missing entries) 또는 이상치(outliers) 같은 손상(degradation)을 겪음

해결 방법

연구자들은 텐서의 low-rankness를 활용하여 원본 텐서를 복원하며, 다음과 같이 정식화됨:

\[ \min_{\mathcal{X}} \text{rank}(\mathcal{X}), \quad \text{s.t.} \quad \Psi(\mathcal{X}) = \mathcal{T} \]

여기서 \(\mathcal{T}\)는 관측된 측정값, \(\Psi(\cdot)\)는 손상 과정을 모델링하는 연산자

계산 복잡도

이 문제는 NP-hard이므로, rank 함수는 일반적으로 convex 또는 non-convex regularizer \(\Phi(\mathcal{X})\)로 근사됨

추가 해설: Low-rank tensor recovery란?

Low-rankness의 의미:

“Low-rank”는 텐서가 적은 수의 “기본 패턴”의 조합으로 표현될 수 있다는 의미입니다.

행렬에서의 예시:

랭크-1 행렬 (매우 단순):
┌           ┐   ┌   ┐       ┌       ┐
│ 1  2  3   │   │ 1 │       │ 1 2 3 │
│ 2  4  6   │ = │ 2 │  ×    │       │
│ 3  6  9   │   │ 3 │       │       │
└           ┘   └   ┘       └       ┘
             (외적으로 표현 가능)

랭크-3 행렬 (복잡):
모든 행/열이 독립적 → 3개의 독립적인 패턴 필요

텐서에서의 Low-rank: - 3차원 텐서 \(\mathcal{X}\)가 low-rank라면, 적은 수의 “성분 텐서”의 합으로 표현 가능 - 예: CP 분해에서 rank-\(R\) 텐서는 \(R\)개의 rank-1 텐서의 합

왜 Low-rank 가정이 유용한가? 1. 자연스러운 데이터는 종종 low-rank: 이미지, 비디오 등은 반복적인 패턴과 구조를 가짐 2. 압축 효과: Low-rank 구조는 데이터를 효율적으로 표현 3. 노이즈 제거: 노이즈는 보통 high-rank → low-rank 제약으로 노이즈 필터링

Degradation Operator \(\Psi(\cdot)\)의 예시

  1. 결측값 (Missing entries)

    \[\Psi(\mathcal{X}) = P_\Omega(\mathcal{X})\]

    여기서 \(P_\Omega\)는 관측된 인덱스 집합 \(\Omega\)에서만 값을 유지

  2. 노이즈 추가

    \[\Psi(\mathcal{X}) = \mathcal{X} + \mathcal{N}\]

    여기서 \(\mathcal{N}\)은 노이즈 텐서

  3. 이상치 (Sparse corruption)

    \[\Psi(\mathcal{X}) = \mathcal{X} + \mathcal{S}\]

    여기서 \(\mathcal{S}\)는 sparse한 이상치 텐서

Regularizer \(\Phi(\mathcal{X})\)의 예시

  1. Convex relaxation
    • Nuclear norm: \(\|\mathcal{X}\|_*\) (행렬의 nuclear norm을 텐서로 확장)
    • Tucker rank의 합
  2. Non-convex regularizer
    • Schatten-p norm (\(0 < p < 1\)): 더 강한 sparsity 유도
    • Log-det: \(\log \det(\mathcal{X} + \epsilon I)\)

6. Tensor rank의 정의

행렬과의 차이

행렬의 경우와 달리, 텐서 rank는 유일한 정의를 가지지 않음

두 가지 주요 텐서 rank

서로 다른 공간에서 정의된 두 가지 텐서 rank에 초점:

  • Tucker rank: 데이터 영역(data domain)에서 정의
  • Tubal rank: 변환된 영역(transformed domain)에서 정의

텐서 분해와의 관계

두 텐서 rank는 서로 다른 텐서 분해에 의해 유도됨:

  • Tucker rank ← Tucker decomposition (Tucker, 1966)
  • Tubal rank ← t-SVD (Kilmer and Martin, 2011)

성능에 미치는 영향

텐서 복원의 성능은 rank 정의의 선택과 그에 대응하는 근사 regularizer의 선택에 의존함

추가 해설: Tucker rank vs Tubal rank

왜 텐서는 rank 정의가 여러 개인가?

행렬의 rank는 명확합니다: “선형독립인 행(또는 열)의 최대 개수”

하지만 텐서는 3차원 이상이므로, 어떤 방향으로 분해하느냐에 따라 다른 rank 개념이 생깁니다.

Tucker rank

Tucker 분해는 텐서를 다음과 같이 분해합니다:

\[ \mathcal{X} = \mathcal{G} \times_1 U^{(1)} \times_2 U^{(2)} \times_3 U^{(3)} \]

  • \(\mathcal{G}\): Core tensor
  • \(U^{(k)}\): 각 mode의 factor matrix

Tucker rank: \((r_1, r_2, r_3)\) = 각 mode에서의 rank - \(r_1\) = mode-1 unfolding의 rank - \(r_2\) = mode-2 unfolding의 rank - \(r_3\) = mode-3 unfolding의 rank

예시:

3차원 텐서 X (10 × 20 × 30)
→ Tucker rank = (5, 8, 12)

의미:
- mode-1 방향으로 5개의 독립적인 패턴
- mode-2 방향으로 8개의 독립적인 패턴
- mode-3 방향으로 12개의 독립적인 패턴

Tubal rank

t-SVD는 텐서를 주파수 영역에서 분해합니다:

  1. 텐서를 Fourier 변환
  2. 각 주파수에서 행렬 SVD 수행
  3. 역변환으로 복원

Tubal rank: 변환된 영역에서 필요한 “tube”의 개수 - “Tube”는 텐서의 특정 방향을 따라 뻗은 벡터들

특징: - 순환 구조(circular structure)를 가진 데이터에 적합 - 비디오, 시계열 데이터 등에 효과적

두 rank의 차이점

특성 Tucker rank Tubal rank
정의 영역 원본 데이터 영역 변환된 영역 (Fourier)
차원 벡터 \((r_1, r_2, r_3)\) 스칼라 \(r\)
적용 일반적인 텐서 순환 구조 데이터
계산 Mode별로 unfolding Fourier 변환 필요
해석 각 방향의 복잡도 전체적인 복잡도

실제 예시: 비디오 데이터

비디오를 (너비 × 높이 × 프레임) 텐서로 표현할 때:

Tucker rank 관점

  • 공간적 복잡도 (너비/높이 방향)
  • 시간적 복잡도 (프레임 방향)
  • 각각 독립적으로 측정

Tubal rank 관점

  • 프레임 간의 주기적 패턴 포착
  • 주파수 영역에서 저차원 표현
  • 반복적인 움직임이 있는 비디오에 효과적

8. Notations

3차 텐서 표기법

  • 3차 텐서 \(\mathcal{X} \in \mathbb{R}^{n_1 \times n_2 \times n_3}\)를 다룸

  • \((i, j, k)\)-번째 원소는 \(\mathcal{X}(i, j, k)\)로 표기

  • mode-1, mode-2, mode-3 (tube) fibers는 각각 다음과 같이 표기

    • \(\mathcal{X}(:, j, k)\) (mode-1 fiber)
    • \(\mathcal{X}(i, :, k)\) (mode-2 fiber)
    • \(\mathcal{X}(i, j, :)\) (mode-3 fiber / tube)

  • Slices는 다음과 같이 표기

    • Horizontal slice: \(\mathcal{X}(i, :, :)\)
    • Lateral slice: \(\mathcal{X}(:, j, :)\)
    • Frontal slice: \(\mathcal{X}(:, :, k)\) 또는 \(\mathcal{X}^{(k)}\)

10. Tensor operations

Mode-k unfolding (Matricization)

텐서 \(\mathcal{X}\)의 mode-\(k\) unfolding은 \(\mathcal{X}_{(k)} \in \mathbb{R}^{n_k \times (n_1n_2n_3/n_k)}\)로 표기되며, mode-\(k\) fiber들을 결과 행렬의 열로 배열함. 역연산은 \(\text{fold}_k(\mathcal{X}_{(k)}) = \mathcal{X}\)로 표기

Inner product (내적)

같은 크기의 두 텐서 \(\mathcal{X}\)와 \(\mathcal{Y}\)의 내적은 다음과 같이 정의

\[ \langle \mathcal{X}, \mathcal{Y} \rangle = \sum_{i,j,k} \mathcal{X}_{ijk} \mathcal{Y}_{ijk} \]

Frobenius norm

텐서 \(\mathcal{X}\)의 Frobenius norm은 다음과 같이 정의

\[ \|\mathcal{X}\|_F = \sqrt{\langle \mathcal{X}, \mathcal{X} \rangle} \]

추가 해설: 텐서 연산의 이해

Mode-k Unfolding (Matricization)

텐서를 행렬로 “펴는” 연산입니다. 이것은 텐서 분석에서 가장 중요한 기본 연산 중 하나입니다.

예시: 3차 텐서 \(\mathcal{X} \in \mathbb{R}^{2 \times 3 \times 4}\)

원본 텐서를 다음과 같이 표현한다고 가정: - 2개의 행 (i = 1, 2) - 3개의 열 (j = 1, 2, 3)
- 4개의 깊이 (k = 1, 2, 3, 4)

Mode-1 unfolding \(\mathcal{X}_{(1)} \in \mathbb{R}^{2 \times 12}\)

Mode-1 fiber \(\mathcal{X}(:, j, k)\)들을 열로 배열:

        j=1     j=2     j=3     (각 j에 대해 k=1,2,3,4)
      k=1,2,3,4  k=1,2,3,4  k=1,2,3,4
┌                                      ┐
│ X(1,1,1) ... X(1,1,4) X(1,2,1) ... X(1,3,4) │  i=1
│ X(2,1,1) ... X(2,1,4) X(2,2,1) ... X(2,3,4) │  i=2
└                                      ┘
     12개 열 (3 × 4)

Mode-2 unfolding \(\mathcal{X}_{(2)} \in \mathbb{R}^{3 \times 8}\)

Mode-2 fiber \(\mathcal{X}(i, :, k)\)들을 열로 배열

Mode-3 unfolding \(\mathcal{X}_{(3)} \in \mathbb{R}^{4 \times 6}\)

Mode-3 fiber (tube) \(\mathcal{X}(i, j, :)\)들을 열로 배열

Unfolding은 왜 필요한가?

  1. Tucker decomposition: 각 mode에서 SVD를 수행하려면 unfolding 필요
  2. Tucker rank 계산: \(\text{rank}(\mathcal{X}_{(k)})\)가 mode-\(k\) Tucker rank
  3. 행렬 알고리즘 활용: 많은 텐서 알고리즘이 내부적으로 unfolding → 행렬 연산 → folding 순서로 작동

Inner Product와 Frobenius Norm

Inner product의 의미

두 텐서가 얼마나 “비슷한” 방향을 향하는지 측정:

\[ \langle \mathcal{X}, \mathcal{Y} \rangle = \sum_{i,j,k} \mathcal{X}_{ijk} \mathcal{Y}_{ijk} \]

이것은 벡터 내적의 자연스러운 확장입니다.

Frobenius norm의 의미

텐서의 “크기”를 측정:

\[ \|\mathcal{X}\|_F = \sqrt{\sum_{i,j,k} \mathcal{X}_{ijk}^2} \]

행렬과의 관계

흥미롭게도, unfolding과 무관하게:

\[ \|\mathcal{X}\|_F = \|\mathcal{X}_{(1)}\|_F = \|\mathcal{X}_{(2)}\|_F = \|\mathcal{X}_{(3)}\|_F \]

즉, 어떻게 펴든 Frobenius norm은 보존됩니다!

실용적 활용 예시

비디오 압축

비디오 텐서 \(\mathcal{V} \in \mathbb{R}^{H \times W \times T}\)를 mode-3 unfolding하면:

\[ \mathcal{V}_{(3)} \in \mathbb{R}^{T \times (H \cdot W)} \]

각 행이 하나의 프레임이 되어, 시간적 패턴을 분석하기 쉬워집니다.

추천 시스템

교통 텐서 데이터

일일 교통 신호의 반복적 특성을 활용하기 위해, 교통 데이터는 3차 교통 텐서(road × time step × day)로 표현 가능

이러한 구조는 모든 mode에 걸쳐 교통 신호의 시간적 및 공간적 상관관계를 완전히 이해하는 데 기여함

\(\mathcal{X} \in \mathbb{R}^{n_1 \times n_2 \times n_3}\) (도로 \(n_1\)개, 시간 단계 \(n_2\)개, 날짜 \(n_3\)개)

교통 텐서의 세 가지 mode에 따른 공간적 및 시간적 의존성

  • Mode-1 unfolding: 도로 간 패턴 (서로 다른 도로의 시간에 따른 교통량)
  • Mode-2 unfolding: 시간대 패턴 (특정 시간대의 도로별 교통량)
  • Mode-3 unfolding: 날짜 패턴 (서로 다른 날의 도로-시간 패턴)
추가 해설: 교통 텐서의 3가지 mode 이해하기

교통 텐서 구조의 실제 의미

교통 데이터를 3차원 텐서 \(\mathcal{X} \in \mathbb{R}^{n_1 \times n_2 \times n_3}\)로 표현한다는 것은:

예시: 서울시 강남구 교통 데이터
- n₁ = 100개 도로 구간
- n₂ = 96개 시간 단계 (하루를 15분 단위로 나눔)
- n₃ = 30일

→ 텐서 크기: 100 × 96 × 30
→ 총 288,000개 데이터 포인트

각 원소가 의미하는 것:

\(\mathcal{X}(i, j, k)\) = \(k\)번째 날, \(j\)번째 시간대, \(i\)번째 도로의 교통량 (또는 속도)

Unfolding을 통한 패턴 분석

Mode-1 unfolding \(\mathcal{X}_{(1)} \in \mathbb{R}^{100 \times 2880}\)

각 도로를 하나의 행으로 펼침:

         시간-날짜 조합 (96 × 30 = 2880개)
       ┌─────────────────────────────────┐
도로1  │  [day1의 96시간, day2의 96시간, ...] │
도로2  │  [day1의 96시간, day2의 96시간, ...] │
 ...   │              ...                  │
도로100│  [day1의 96시간, day2의 96시간, ...] │
       └─────────────────────────────────┘

이것으로 알 수 있는 것: - 어떤 도로들이 비슷한 시간-날짜 패턴을 보이는가? - 예: 강남대로와 테헤란로가 비슷한 출퇴근 패턴을 보임

Mode-2 unfolding \(\mathcal{X}_{(2)} \in \mathbb{R}^{96 \times 3000}\)

각 시간대를 하나의 행으로 펼침:

          도로-날짜 조합 (100 × 30 = 3000개)
       ┌─────────────────────────────────┐
00:00  │  [day1의 100도로, day2의 100도로, ...] │
00:15  │  [day1의 100도로, day2의 100도로, ...] │
 ...   │              ...                  │
23:45  │  [day1의 100도로, day2의 100도로, ...] │
       └─────────────────────────────────┘

이것으로 알 수 있는 것: - 특정 시간대의 전체 도로망 상태 - 예: 오전 8-9시는 모든 날에 걸쳐 대부분 도로에서 혼잡

Mode-3 unfolding \(\mathcal{X}_{(3)} \in \mathbb{R}^{30 \times 9600}\)

각 날짜를 하나의 행으로 펼침:

        도로-시간 조합 (100 × 96 = 9600개)
       ┌─────────────────────────────────┐
Day1   │  [모든 도로의 96시간 데이터]        │
Day2   │  [모든 도로의 96시간 데이터]        │
 ...   │              ...                  │
Day30  │  [모든 도로의 96시간 데이터]        │
       └─────────────────────────────────┘

이것으로 알 수 있는 것: - 평일 vs 주말 패턴의 차이 - 특정 날짜의 이상 패턴 (예: 공휴일, 사고) - 예: 월요일들끼리 비슷한 패턴, 토요일들끼리 비슷한 패턴

왜 텐서 표현이 유용한가?

(1) 행렬 표현의 한계

만약 교통 데이터를 2D 행렬로 표현한다면: - \((100 \times 96) \times 30\) 행렬: 날짜 간 비교는 쉽지만, 도로와 시간의 2D 구조를 잃음 - \(100 \times (96 \times 30)\) 행렬: 도로 간 비교는 쉽지만, 시간과 날짜의 관계를 잃음

(2) 텐서 표현의 장점

세 가지 mode를 동시에 보존하므로: - 도로 간의 공간적 상관관계 - 시간대별 시간적 상관관계 - 날짜 간의 반복 패턴

이 모두를 한 번에 모델링할 수 있습니다!

(3) Low-rank 가정의 의미

교통 텐서가 low-rank라는 것은:

"30일간의 100개 도로, 96개 시간대 데이터는 
 실제로 적은 수의 '기본 패턴'의 조합으로 표현 가능"

예시: - 기본 패턴 1: 평일 출근 시간대 혼잡 - 기본 패턴 2: 주말 저녁 유흥지 혼잡 - 기본 패턴 3: 심야 시간대 한산함

→ 전체 288,000개 데이터 포인트를 이 3개 패턴의 조합으로 근사!

결측값 보완에의 활용

센서 고장으로 일부 데이터가 결측된 경우:

예: Day 15, 오전 9시, 강남대로 데이터 없음
→ 텐서 completion 알고리즘이:
  1. 다른 날 같은 시간대의 강남대로 패턴
  2. 같은 날 다른 시간대의 강남대로 패턴
  3. 같은 날 같은 시간대의 인근 도로 패턴
  이 모두를 활용하여 결측값 추정!

행렬 방법으로는 이 세 가지 정보를 동시에 활용할 수 없습니다.

시공간적 의존성과 Low-rankness

시공간적 의존성(spatiotemporal dependence)은 구성된 텐서의 low-rankness를 함의함 (Chen et al., 2020, Hu et al., 2023)

제안 모델

교통 데이터를 위한 효과적인 low-rank 텐서 completion 모델을 제안

방법론의 핵심

(1) Sparsity-inducing regularizer 기반 행렬 completion 확장

Wang et al. (2025)의 행렬 completion 방법을 텐서로 확장하며, 특이값의 절단(truncation of singular values)을 추가하여 imputation 성능을 향상

(2) Autoregressive (AR) penalty

교통 데이터의 국소적 평활성(local smoothness)을 활용하기 위해 autoregressive penalty를 통합

추가 해설: 제안 방법론의 구성 요소

Low-rankness를 활용하는 이유

교통 텐서 데이터에서 시공간적 의존성이 있다는 것은:

예시: 강남대로의 교통 패턴
- 시간적 의존성: 오전 8시가 혼잡하면 8시 15분도 혼잡할 가능성 높음
- 공간적 의존성: 강남대로가 혼잡하면 인근 테헤란로도 혼잡할 가능성 높음
- 날짜 간 의존성: 월요일들끼리 비슷한 패턴을 보임

→ 이런 규칙적 패턴들은 "적은 수의 기본 패턴"으로 표현 가능
→ 즉, 텐서가 low-rank 구조를 가짐

문헌 근거: - Chen et al. (2020), Hu et al. (2023): 시공간 의존성 → low-rank 구조

방법 1: Sparsity-inducing regularizer + Singular value truncation

기존 방법 (Wang et al., 2025):

행렬 completion에서 sparsity-inducing regularizer 사용

\[ \min_X \|\mathcal{P}_\Omega(X - M)\|_F^2 + \lambda \cdot \text{sparsity penalty} \]

여기서 \(\mathcal{P}_\Omega\)는 관측된 위치의 projection

제안하는 확장:

  1. 텐서로 확장: 행렬 \(X\) → 텐서 \(\mathcal{X}\)
  2. 특이값 절단 추가: SVD 후 작은 특이값들을 제거

특이값 절단의 효과:

SVD: X = UΣV^T
Σ = diag(σ₁, σ₂, ..., σᵣ)  (σ₁ ≥ σ₂ ≥ ... ≥ σᵣ)

절단 전: 모든 특이값 사용
절단 후: σ₁, ..., σₖ만 사용 (k < r)

→ 노이즈 제거 + 더 강한 low-rank 제약

왜 특이값 절단이 도움이 되는가? - 작은 특이값들은 종종 노이즈를 나타냄 - 절단을 통해 신호(signal)와 노이즈를 분리 - Imputation 성능 향상

방법 2: Autoregressive (AR) Penalty

교통 데이터의 Local Smoothness란?

교통량은 급격하게 변하지 않고 연속적으로 변함:

시간에 따른 교통량:
08:00 → 120대/분
08:15 → 125대/분  (급격한 변화 없음)
08:30 → 130대/분

도로 간 교통량:
강남대로 지점1 → 100대/분
강남대로 지점2 → 105대/분  (인접 지점은 비슷)
강남대로 지점3 → 110대/분

Autoregressive (AR) Penalty란?

인접한 값들이 비슷하도록 제약을 가하는 penalty:

시간 방향 AR penalty (예시):

\[ \text{AR penalty} = \sum_{i,k} \sum_{j=1}^{n_2-1} (\mathcal{X}_{i,j+1,k} - \mathcal{X}_{i,j,k})^2 \]

의미: 연속된 시간대의 값 차이를 최소화

공간 방향 AR penalty도 유사하게:

\[ \sum_{j,k} \sum_{i=1}^{n_1-1} (\mathcal{X}_{i+1,j,k} - \mathcal{X}_{i,j,k})^2 \]

의미: 인접한 도로의 값 차이를 최소화

전체 최적화 문제 (예상)

\[ \min_{\mathcal{X}} \underbrace{\|\mathcal{P}_\Omega(\mathcal{X} - \mathcal{M})\|_F^2}_{\text{관측값과의 일치}} + \underbrace{\lambda_1 \cdot \text{sparsity penalty}}_{\text{low-rank 유도}} + \underbrace{\lambda_2 \cdot \text{AR penalty}}_{\text{smoothness 유도}} \]

각 항의 역할: 1. 데이터 충실도: 관측된 값은 최대한 보존 2. Low-rank 제약: 특이값 절단 + sparsity penalty로 구조 학습 3. Smoothness 제약: AR penalty로 국소적 연속성 보장

방법론의 시너지 효과

Low-rank 제약만 사용:
→ 전역적 패턴은 잘 잡지만, 국소적 변동 무시 가능

AR penalty만 사용:
→ 국소적으로는 부드럽지만, 전역적 구조 놓칠 수 있음

둘을 함께 사용:
→ 전역 패턴 + 국소 smoothness 모두 활용
→ 더 정확한 imputation!

실용적 예시:

결측 상황: Day 15, 08:30, 강남대로 지점5 데이터 없음

Low-rank 제약:
→ "평일 오전 8시 30분은 보통 혼잡" (전역 패턴)

AR penalty:
→ "지점4가 100대/분, 지점6이 110대/분이면 
   지점5는 105대/분 정도일 것" (국소 smoothness)

결합:
→ 두 정보를 모두 활용하여 더 정확한 추정!

15. Tucker rank and its approximation

Tucker rank의 정의

텐서 \(\mathcal{X} \in \mathbb{R}^{n_1 \times n_2 \times \cdots \times n_d}\)의 Tucker rank는 \(d\)-차원 벡터로 정의됨:

\[ \mathbf{r} = (\text{rank}(\mathcal{X}_{(1)}), \text{rank}(\mathcal{X}_{(2)}), \ldots, \text{rank}(\mathcal{X}_{(d)})) \]

Tucker rank의 근사

Tucker rank는 unfolding 행렬들의 특이값에 대한 convex 또는 nonconvex regularizer \(\varphi(\cdot)\)로 근사됨

Rank surrogate의 정의

\[ \|\mathcal{X}\|_\varphi := \sum_{k=1}^d \alpha_k \|\mathcal{X}_{(k)}\|_\varphi \]

여기서: - \(\|\mathcal{X}_{(k)}\|_\varphi = \sum_i \varphi(\sigma_i(\mathcal{X}_{(k)}))\) (\(i\)-번째 특이값 \(\sigma_i(\cdot)\)) - \(\alpha_k > 0\): 가중치

특수한 경우

\(\varphi(t) = t\)일 때, 이 형태는 sum of nuclear norms로 축약됨 (Liu et al., 2012)

추가 해설: Tucker rank 근사의 실제 의미

Tucker rank를 직접 사용하기 어려운 이유

Tucker rank \(\mathbf{r} = (r_1, r_2, \ldots, r_d)\)는 이산적(discrete)인 값:

예시: 교통 텐서 (100 × 96 × 30)
Tucker rank = (5, 8, 12)

의미:
- Mode-1 unfolding의 rank = 5 (5개의 독립적인 도로 패턴)
- Mode-2 unfolding의 rank = 8 (8개의 독립적인 시간 패턴)
- Mode-3 unfolding의 rank = 12 (12개의 독립적인 날짜 패턴)

최적화 문제:
min rank(X)  subject to ...
     ↓
rank는 이산적 → 조합 최적화 문제 (NP-hard)

구체적 예시: 왜 이산적인가?

행렬 \(A \in \mathbb{R}^{3 \times 3}\)의 특이값이 \(\sigma = [10, 5, 0.001]\)일 때:

  • Rank = 3 (모든 특이값이 0이 아님)
  • 0.001을 0으로 만들면 Rank = 2로 점프!
  • Rank는 2와 3 사이의 중간값을 가질 수 없음

해결책: Rank surrogate (연속적 근사)

Rank를 직접 최소화하는 대신, 특이값에 대한 함수 \(\varphi\)를 최소화:

\[ \text{rank}(\mathcal{X}_{(k)}) \approx \sum_i \varphi(\sigma_i(\mathcal{X}_{(k)})) \]

이제 \(\varphi\)는 연속 함수이므로 미분 가능하고, 최적화 알고리즘을 적용할 수 있습니다!

Regularizer \(\varphi(t)\)의 선택

(1) Convex regularizer: Nuclear norm (\(\varphi(t) = t\))

\[ \|\mathcal{X}_{(k)}\|_* = \sum_i \sigma_i(\mathcal{X}_{(k)}) \]

구체적 예시: Mode-1 unfolding

교통 텐서 \(\mathcal{X} \in \mathbb{R}^{100 \times 96 \times 30}\)를 mode-1 unfolding:

\[ \mathcal{X}_{(1)} \in \mathbb{R}^{100 \times 2880} \]

SVD를 수행하면:

특이값: σ₁ = 500, σ₂ = 300, σ₃ = 100, σ₄ = 50, ..., σ₁₀₀ = 0.1

Nuclear norm:
||X₍₁₎||_* = 500 + 300 + 100 + 50 + ... + 0.1 ≈ 1200

의미: 모든 특이값의 합 = 행렬의 "복잡도"

Nuclear norm을 최소화하면?

Regularization: \(\min \|\mathcal{X}\|_F^2 + \lambda \|\mathcal{X}_{(1)}\|_*\)

최적화 과정에서:
σ₁ = 500 → 450 (shrinkage)
σ₂ = 300 → 260 (shrinkage)
σ₃ = 100 → 70  (shrinkage)
σ₄ = 50  → 25  (shrinkage)
...
σ₁₀₀ = 0.1 → 0 (완전히 제거)

문제점: 큰 특이값(신호)도 줄어듦!

장점: - Convex 최적화 → 전역 최적해 보장 - SVD로 효율적 계산 가능 - 이론적 보장 (exact recovery 조건 등)

단점: - 모든 특이값을 동일하게 처리 → 신호도 약화 - 큰 특이값(중요한 패턴)까지 shrinkage

전체 텐서에 대한 Sum of Nuclear Norms

\[ \|\mathcal{X}\|_* = \sum_{k=1}^3 \alpha_k \|\mathcal{X}_{(k)}\|_* \]

교통 텐서 예시:

Mode-1 (도로 패턴):
||X₍₁₎||_* = σ₁⁽¹⁾ + σ₂⁽¹⁾ + ... ≈ 1200

Mode-2 (시간 패턴):
||X₍₂₎||_* = σ₁⁽²⁾ + σ₂⁽²⁾ + ... ≈ 800

Mode-3 (날짜 패턴):
||X₍₃₎||_* = σ₁⁽³⁾ + σ₂⁽³⁾ + ... ≈ 600

가중치 설정 (예):
α₁ = 1.0, α₂ = 0.8, α₃ = 0.5

Sum of nuclear norms:
||X||_* = 1.0×1200 + 0.8×800 + 0.5×600 = 2140

이것이 Liu et al. (2012)의 “sum of nuclear norms”

이 방법의 의미:

모든 mode에서 동시에 low-rank 구조를 유도 → 다차원 구조 보존

(2) Nonconvex regularizer

더 강한 sparsity를 유도하기 위해 nonconvex \(\varphi\) 사용

Nuclear norm의 문제(큰 특이값도 shrinkage)를 해결!

예시 1: Truncated Nuclear Norm

\[ \varphi(t) = \begin{cases} t & \text{if } t \leq \tau \\ \tau & \text{if } t > \tau \end{cases} \]

구체적 예시: \(\tau = 100\)으로 설정

원래 특이값:
σ₁ = 500, σ₂ = 300, σ₃ = 100, σ₄ = 50, σ₅ = 10, σ₆ = 1

Nuclear norm (φ(t) = t):
φ(500) + φ(300) + φ(100) + φ(50) + φ(10) + φ(1)
= 500 + 300 + 100 + 50 + 10 + 1 = 961

Truncated nuclear norm (τ = 100):
φ(500) + φ(300) + φ(100) + φ(50) + φ(10) + φ(1)
= 100 + 100 + 100 + 50 + 10 + 1 = 361
    ↑      ↑      ↑
  cap at cap at cap at
   τ=100  τ=100  τ=100

효과:

최적화 후:
σ₁ = 500 → 500 (변화 없음! 신호 보존)
σ₂ = 300 → 300 (변화 없음! 신호 보존)
σ₃ = 100 → 100 (변화 없음)
σ₄ = 50  → 20  (작은 값만 shrinkage)
σ₅ = 10  → 0   (노이즈 제거)
σ₆ = 1   → 0   (노이즈 제거)

→ 중요한 신호(큰 특이값)는 보존하면서
→ 노이즈(작은 특이값)만 제거!

예시 2: Log-sum Penalty

\[ \varphi(t) = \log(1 + t/\epsilon) \]

구체적 예시: \(\epsilon = 10\)

특이값에 대한 penalty:
σ₁ = 500: φ(500) = log(1 + 500/10) = log(51) ≈ 3.93
σ₂ = 300: φ(300) = log(1 + 300/10) = log(31) ≈ 3.43
σ₃ = 100: φ(100) = log(1 + 100/10) = log(11) ≈ 2.40
σ₄ = 50:  φ(50)  = log(1 + 50/10)  = log(6)  ≈ 1.79
σ₅ = 10:  φ(10)  = log(1 + 10/10)  = log(2)  ≈ 0.69
σ₆ = 1:   φ(1)   = log(1 + 1/10)   = log(1.1) ≈ 0.10

특징:

큰 값에 대한 증가율이 작아짐:
- σ가 커질수록 φ(σ)의 증가 속도 감소
- 500 → 600으로 증가: φ는 3.93 → 4.09 (작은 증가)
- 1 → 2로 증가: φ는 0.10 → 0.41 (큰 증가)

→ 작은 특이값에 더 강한 penalty
→ 큰 특이값은 상대적으로 자유롭게

예시 3: Schatten-p Norm (\(0 < p < 1\))

\[ \varphi(t) = t^p, \quad \text{예: } p = 0.5 \]

구체적 예시: \(p = 0.5\) (제곱근)

특이값에 대한 penalty:
σ₁ = 500: φ(500) = √500 ≈ 22.4
σ₂ = 300: φ(300) = √300 ≈ 17.3
σ₃ = 100: φ(100) = √100 = 10.0
σ₄ = 50:  φ(50)  = √50  ≈ 7.1
σ₅ = 10:  φ(10)  = √10  ≈ 3.2
σ₆ = 1:   φ(1)   = √1   = 1.0

비교: Nuclear norm (p=1)
σ₁ = 500: φ(500) = 500
σ₂ = 300: φ(300) = 300
...

Ratio (Schatten-0.5 / Nuclear):
σ₁: 22.4/500 = 0.045  (큰 값은 penalty 4.5%만)
σ₆: 1.0/1   = 1.000  (작은 값은 penalty 100%)

효과:

Sub-linear penalty (\(p < 1\)) → 큰 특이값에 대한 penalty 비율이 작음

세 가지 Nonconvex 방법의 비교

특이값: [500, 300, 100, 50, 10, 1]

Nuclear norm (convex):
Penalty: [500, 300, 100, 50, 10, 1]
→ 모든 값에 비례적 penalty

Truncated (τ=100):
Penalty: [100, 100, 100, 50, 10, 1]
→ 큰 값은 cap, 작은 값만 penalize

Log-sum (ε=10):
Penalty: [3.93, 3.43, 2.40, 1.79, 0.69, 0.10]
→ 부드러운 감소, 작은 값에 상대적으로 큰 penalty

Schatten-0.5:
Penalty: [22.4, 17.3, 10.0, 7.1, 3.2, 1.0]
→ 제곱근 관계, 큰 값의 penalty 비율 감소

장점: - 더 강한 low-rank 유도 (작은 특이값을 0으로) - 큰 특이값 보존 → 신호 손실 최소화 - 더 정확한 복원 가능

단점: - Non-convex → 국소 최적해에 빠질 위험 - 초기값에 민감 - 최적화 알고리즘이 복잡 (ADMM, proximal gradient 등) - 이론적 보장이 약함

가중치 \(\alpha_k\)의 역할

\[ \|\mathcal{X}\|_\varphi = \sum_{k=1}^d \alpha_k \|\mathcal{X}_{(k)}\|_\varphi \]

각 mode의 중요도를 조절:

예시: 교통 텐서 (도로 × 시간 × 날짜)

α₁ = 1.0  (도로 mode)
α₂ = 0.5  (시간 mode) 
α₃ = 0.3  (날짜 mode)

→ 도로 간 패턴을 가장 중요하게 취급
→ 날짜 간 변동은 덜 제약

선택 방법: - Cross-validation으로 튜닝 - 각 mode의 unfolding 행렬 크기에 비례하게 설정 - 도메인 지식 활용

실제 최적화 문제 (교통 데이터 completion)

앞의 슬라이드와 결합하면:

\[ \min_{\mathcal{X}} \underbrace{\|\mathcal{P}_\Omega(\mathcal{X} - \mathcal{M})\|_F^2}_{\text{관측값 일치}} + \underbrace{\lambda \sum_{k=1}^3 \alpha_k \|\mathcal{X}_{(k)}\|_\varphi}_{\text{Tucker rank 근사}} + \underbrace{\mu \cdot \text{AR penalty}}_{\text{smoothness}} \]

각 항의 해석:

  1. 데이터 충실도: 관측된 교통 데이터는 보존
  2. Low-rank 제약:
    • Mode-1 (도로): \(\alpha_1 \|\mathcal{X}_{(1)}\|_\varphi\)
    • Mode-2 (시간): \(\alpha_2 \|\mathcal{X}_{(2)}\|_\varphi\)
    • Mode-3 (날짜): \(\alpha_3 \|\mathcal{X}_{(3)}\|_\varphi\)
  3. Smoothness 제약: 시공간적 연속성

Nuclear norm의 직관적 의미

행렬의 경우:

\[ \|A\|_* = \sum_i \sigma_i(A) \]

이것은 행렬의 “복잡도”를 측정:

예시 1: Rank-1 행렬
A = [1  2]  → σ₁ = √5, σ₂ = 0
    [2  4]  → ||A||_* = √5

예시 2: Full-rank 행렬
B = [1  0]  → σ₁ = 1, σ₂ = 1
    [0  1]  → ||B||_* = 2 (더 복잡)

텐서의 경우:

Sum of nuclear norms는 모든 mode의 복잡도 합:

\[ \|\mathcal{X}\|_* = \|\mathcal{X}_{(1)}\|_* + \|\mathcal{X}_{(2)}\|_* + \|\mathcal{X}_{(3)}\|_* \]

이것을 최소화 → 모든 방향에서 단순한 구조 유도

실용적 예시: 비디오 복원

비디오 텐서 \(\mathcal{V} \in \mathbb{R}^{H \times W \times T}\) (높이 × 너비 × 프레임)

Convex 접근 (Nuclear norm):

\[ \min_{\mathcal{V}} \|\mathcal{P}_\Omega(\mathcal{V} - \mathcal{M})\|_F^2 + \lambda(\|\mathcal{V}_{(1)}\|_* + \|\mathcal{V}_{(2)}\|_* + \|\mathcal{V}_{(3)}\|_*) \]

  • 각 unfolding의 rank를 제한
  • Convex → 안정적 복원
  • 계산 효율적 (SVD 기반)

Nonconvex 접근 (Truncated nuclear norm):

작은 특이값만 제거 → 더 선명한 복원 (하지만 최적화 어려움)

16. Low-rank tensor completion

Low-rank Tensor Completion (LRTC) 문제

관측된 인덱스 집합 \(\Omega\)가 주어졌을 때, 3차 텐서에 대한 low-rank tensor completion (LRTC) 문제는 다음과 같이 정식화됨:

\[ \min_{\mathcal{X}} \sum_{k=1}^3 \alpha_k \|\mathcal{X}_{(k)}\|_\varphi, \quad \text{s.t.} \quad P_\Omega(\mathcal{X}) = P_\Omega(\mathcal{T}) \]

여기서 \(P_\Omega(\mathcal{X})\)는 projection 연산자로 정의됨:

\[ (P_\Omega(\mathcal{X}))(i,j,k) = \begin{cases} \mathcal{X}(i,j,k) & \text{if } (i,j,k) \in \Omega \\ 0 & \text{otherwise} \end{cases} \]

추가 해설: Low-rank Tensor Completion 문제의 이해

문제 설정

교통 텐서 데이터에서 일부 값만 관측되고 나머지는 결측된 상황:

교통 텐서 X ∈ ℝ^(100×96×30)
총 원소 개수: 100 × 96 × 30 = 288,000

관측된 인덱스 집합 Ω:
예: 80% 관측 → |Ω| = 230,400개
    20% 결측 → 57,600개 값을 복원해야 함

예시 관측 패턴:
X(1, 5, 3) = 120  ← 관측됨 (1,5,3) ∈ Ω
X(2, 10, 3) = ?   ← 결측 (2,10,3) ∉ Ω
X(3, 15, 3) = 95  ← 관측됨 (3,15,3) ∈ Ω

Projection 연산자 \(P_\Omega(\cdot)\)의 의미

\(P_\Omega(\mathcal{X})\)는 관측된 위치의 값만 유지하고 나머지는 0으로 만듦:

구체적 예시:

원본 텐서 \(\mathcal{X}\):

X(1,1,1) = 100
X(1,1,2) = 105
X(1,2,1) = 110
X(1,2,2) = 115
...

관측 인덱스 집합: \(\Omega = \{(1,1,1), (1,2,2), ...\}\)

\(P_\Omega(\mathcal{X})\) 결과:

(P_Ω(X))(1,1,1) = 100  ← (1,1,1) ∈ Ω이므로 유지
(P_Ω(X))(1,1,2) = 0    ← (1,1,2) ∉ Ω이므로 0
(P_Ω(X))(1,2,1) = 0    ← (1,2,1) ∉ Ω이므로 0
(P_Ω(X))(1,2,2) = 115  ← (1,2,2) ∈ Ω이므로 유지

제약 조건: \(P_\Omega(\mathcal{X}) = P_\Omega(\mathcal{T})\)

\(\mathcal{T}\): 실제 관측된 텐서 (결측값이 있는 원본 데이터)

이 제약의 의미:

“복원된 텐서 \(\mathcal{X}\)는 관측된 위치에서 원본 데이터 \(\mathcal{T}\)와 정확히 일치해야 함”

구체적 예시:

관측 데이터 T:
T(1,5,3) = 120  ← 관측됨
T(2,10,3) = ?   ← 결측
T(3,15,3) = 95  ← 관측됨

복원된 X가 제약을 만족하려면:
X(1,5,3) = 120  ← 관측값과 정확히 일치해야!
X(2,10,3) = ???  ← 자유롭게 추정 가능
X(3,15,3) = 95  ← 관측값과 정확히 일치해야!

수식으로:
P_Ω(X) = P_Ω(T)
→ X(1,5,3) = T(1,5,3) = 120
→ X(3,15,3) = T(3,15,3) = 95
→ X(2,10,3)는 제약 없음 (∵ (2,10,3) ∉ Ω)

목적 함수: \(\sum_{k=1}^3 \alpha_k \|\mathcal{X}_{(k)}\|_\varphi\)

이전 슬라이드에서 설명한 Tucker rank surrogate:

교통 텐서 예시:

Mode-1 unfolding X₍₁₎: 도로 패턴의 복잡도
Mode-2 unfolding X₍₂₎: 시간 패턴의 복잡도
Mode-3 unfolding X₍₃₎: 날짜 패턴의 복잡도

목적: α₁||X₍₁₎||_φ + α₂||X₍₂₎||_φ + α₃||X₍₃₎||_φ 최소화
→ 모든 mode에서 low-rank 구조 유도

전체 문제의 해석

\[ \min_{\mathcal{X}} \sum_{k=1}^3 \alpha_k \|\mathcal{X}_{(k)}\|_\varphi, \quad \text{s.t.} \quad P_\Omega(\mathcal{X}) = P_\Omega(\mathcal{T}) \]

목표:

“관측된 값은 정확히 맞추면서, 동시에 가능한 한 단순한(low-rank) 구조를 가진 텐서를 찾아라”

Trade-off:

  1. 제약 조건: 관측값 일치 (데이터 충실도)
  2. 목적 함수: Low-rank 유도 (구조적 단순성)

구체적 예시: 교통 데이터 복원

관측 상황:
- 100개 도로 × 96개 시간 × 30일
- 센서 고장으로 20% 데이터 결측
- 관측된 230,400개 값은 정확함

LRTC 문제:

min_{X} α₁||X₍₁₎||_φ + α₂||X₍₂₎||_φ + α₃||X₍₃₎||_φ

제약: 관측된 230,400개 위치에서 X = T

알고리즘이 하는 일:
1. 관측된 값들의 패턴 분석
   - 도로 간 상관관계 (mode-1)
   - 시간대별 규칙성 (mode-2)
   - 날짜 간 유사성 (mode-3)

2. Low-rank 가정 활용
   - "평일 오전 8시는 항상 혼잡" (반복 패턴)
   - "강남대로와 테헤란로는 비슷한 패턴" (공간 상관)
   
3. 결측값 추정
   Day 15, 08:30, 강남대로 지점5 = ?
   → 다른 날 같은 시간/장소 패턴 활용
   → 같은 날 다른 시간/장소 패턴 활용
   → Low-rank 제약으로 가장 그럴듯한 값 선택

왜 Low-rank 가정이 중요한가?

결측값 복원 문제는 본질적으로 ill-posed (해가 무수히 많음):

예시: 1개 결측값
X(2,10,3) = ?

제약 없이는:
X(2,10,3) = 0    ← 가능
X(2,10,3) = 100  ← 가능
X(2,10,3) = 999  ← 가능
...

Low-rank 제약 추가:
→ "전체 텐서가 단순한 패턴을 따라야 함"
→ X(2,10,3) = 105 정도가 가장 그럴듯
   (∵ 주변 값들과 일관성 있는 패턴)

Low-rank 제약은 정칙화(regularization) 역할: - 무수히 많은 해 중에서 - 구조적으로 가장 단순한 해를 선택 - 과적합 방지

실제 알고리즘 (개념적)

  1. 초기화: 결측값을 임의로 채움 (예: 평균값)

  2. 반복 최적화:

    반복 t에서:
(1) 고정된 Ω에서 제약 만족하도록 X 업데이트
(2) Low-rank 제약 적용 (SVD, soft-thresholding 등)
(3) 수렴할 때까지 반복

  3. 수렴 판정:

    • 목적 함수 변화가 작아지면 종료
    • 또는 최대 반복 횟수 도달

대표적 알고리즘: - ADMM (Alternating Direction Method of Multipliers) - Proximal Gradient Descent - ALS (Alternating Least Squares)

이 문제의 이론적 성질

질문: 관측값만으로 원본 텐서를 정확히 복원할 수 있는가?

답: 특정 조건 하에서 가능!

필요 조건:

  1. 충분한 관측: \(|\Omega| \geq C \cdot r \cdot (n_1 + n_2 + n_3)\) (대략)

    • \(r\): Tucker rank의 크기
    • \(C\): 상수

  2. 랜덤 관측: 관측 위치가 랜덤하게 분포 (특정 패턴 없음)

  3. Incoherence 조건: 텐서가 “너무 sparse하지 않음”

교통 데이터 예시:

Tucker rank = (5, 8, 12)
텐서 크기: 100 × 96 × 30

이론적 최소 관측 개수:
대략 max(5,8,12) × (100+96+30) × log(...)
≈ 12 × 226 × 6 ≈ 16,000개

실제 관측: 230,400개 (80%)
→ 이론적으로 충분히 복원 가능!

17. Proximal operator

Proximal Operator의 필요성

LRTC를 풀기 위해서는 특이값에 대한 proximal operator를 유도해야 함

Proximal Operator의 정의

Proximal operator는 다음 문제의 해로 정의됨:

\[ P_\varphi(x) = \arg\min_y \frac{1}{2}(y-x)^2 + \tau\varphi(y) \]

여기서 \(\varphi(\cdot)\)는 closed and semicontinuous regularizer이고 \(\tau > 0\)

좋은 Regularizer의 조건

좋은 regularizer는 다음 세 가지 성질을 만족하는 proximal operator를 생성해야 함 (Fan and Li, 2001):

  • Unbiasedness: 해가 nearly unbiased (hard-thresholding에 가까움)
  • Sparsity: \(x\)가 작을 때 해가 0
  • Continuity: 해가 \(x\)에 대해 연속
추가 해설: Proximal Operator의 이해

Proximal Operator가 왜 필요한가?

LRTC 최적화 문제:

\[ \min_{\mathcal{X}} \sum_{k=1}^3 \alpha_k \|\mathcal{X}_{(k)}\|_\varphi, \quad \text{s.t.} \quad P_\Omega(\mathcal{X}) = P_\Omega(\mathcal{T}) \]

이 문제를 풀기 위한 대표적 알고리즘들 (ADMM, Proximal Gradient 등)은 내부적으로 proximal operator를 반복적으로 계산해야 함

각 반복 단계에서:

현재 추정값 x가 주어졌을 때
→ regularizer φ(·)를 고려하여
→ x를 "적절히 shrink/threshold"한 새로운 값 y를 계산
→ 이것이 proximal operator P_φ(x)

Proximal Operator의 직관적 의미

\[ P_\varphi(x) = \arg\min_y \underbrace{\frac{1}{2}(y-x)^2}_{\text{fidelity term}} + \underbrace{\tau\varphi(y)}_{\text{regularization term}} \]

두 가지 목표의 균형:

  1. Fidelity term \(\frac{1}{2}(y-x)^2\): “\(y\)는 \(x\)에 가까워야 함”
  2. Regularization term \(\tau\varphi(y)\): “\(y\)는 regularizer를 작게 만들어야 함”

Trade-off: - \(\tau\)가 크면: regularization 강조 → \(y\)가 0에 가까워짐 (강한 shrinkage) - \(\tau\)가 작으면: fidelity 강조 → \(y \approx x\) (약한 shrinkage)

구체적 예시 1: Soft-Thresholding (Nuclear Norm)

Nuclear norm의 경우 \(\varphi(t) = |t|\) (절댓값):

\[ P_\varphi(x) = \arg\min_y \frac{1}{2}(y-x)^2 + \tau|y| \]

해: (closed form으로 계산 가능!)

\[ P_\varphi(x) = \text{sign}(x) \cdot \max(|x| - \tau, 0) = \begin{cases} x - \tau & \text{if } x > \tau \\ 0 & \text{if } |x| \leq \tau \\ x + \tau & \text{if } x < -\tau \end{cases} \]

이것을 soft-thresholding operator라고 함

구체적 숫자 예시 (\(\tau = 10\)):

x = 50   → P_φ(50)  = 50 - 10 = 40   (shrink by τ)
x = 30   → P_φ(30)  = 30 - 10 = 20   (shrink by τ)
x = 10   → P_φ(10)  = 0              (set to zero)
x = 5    → P_φ(5)   = 0              (set to zero)
x = -30  → P_φ(-30) = -30 + 10 = -20 (shrink by τ)

Fan and Li (2001)의 세 가지 조건

1. Unbiasedness (Nearly Unbiased)

큰 \(x\)에 대해 \(P_\varphi(x) \approx x\) (거의 변화 없음)

이유: - 큰 특이값 = 중요한 신호 - 신호를 보존하려면 큰 값은 shrink하지 말아야 함

예시:

특이값 σ₁ = 500 (매우 중요한 신호)

Soft-thresholding (τ=10):
P_φ(500) = 500 - 10 = 490 (shrink!)
→ 신호 손실 10

Ideal (unbiased):
P_φ(500) = 500 (변화 없음)
→ 신호 보존

2. Sparsity

작은 \(x\)에 대해 \(P_\varphi(x) = 0\)

이유: - 작은 특이값 = 노이즈 - 노이즈를 제거하려면 작은 값은 0으로 설정

예시:

특이값 σ₁₀₀ = 0.5 (노이즈)

Both soft-thresholding and ideal:
P_φ(0.5) = 0 (τ=10일 때)
→ 노이즈 제거 ✓

3. Continuity

\(P_\varphi(x)\)가 \(x\)에 대해 연속

이유: - 최적화 알고리즘의 안정성 - Gradient 기반 방법 사용 가능

예시:

Hard-thresholding (bad):
x = 10.01 → P(x) = 10.01
x = 9.99  → P(x) = 0
→ 불연속 점프! (τ=10)

Soft-thresholding (good):
x = 10.01 → P(x) = 0.01
x = 9.99  → P(x) = 0
→ 연속적 변화 ✓

18. Sparsity-inducing regularizer

Sparsity-Inducing Regularizer (SIR)

Sparsity-inducing regularizer (SIR)는 \(l_1\)-norm (soft-thresholding)과 비교하여 sparse하고, 연속적이며, less biased한 proximal operator를 생성함 (Wang et al. 2025)

Theorem 2.1 (Wang et al. 2025)

미분 가능한 함수 \(\phi_{h,\tau}(x)\)를 다음과 같이 정의:

\[ \phi_{h,\tau}(x) = \begin{cases} \frac{x^2}{2}, & |x| \leq \tau \\ \alpha h(|x|) + \beta, & |x| > \tau \end{cases} \]

여기서 \(h(\cdot)\)는 실수값 함수이며, \(g(x) = x^2/2 - \phi_{h,\tau}(x)\)가 closed and semicontinuous convex function일 때, 이것을 사용하여 SIR \(\varphi_{h,\tau}(\cdot)\)를 생성할 수 있음:

\[ \phi_{h,\tau}(x) = \min_y \frac{1}{2}(y-x)^2 + \tau\varphi_{h,\tau}(y) \]

여기서 \(\varphi_{h,\tau}(y) = \max\{-\frac{1}{2\lambda}(x-y)^2 + \phi_{h,\tau}(x)\}\)

\(y\)에 대한 minimizer는 다음 proximal operator로 주어짐:

\[ P_{\varphi_{h,\tau}}(x) = \text{sign}(x) \cdot \max\{0, |x| - \alpha h'(|x|)\} \]

추가 해설: Sparsity-Inducing Regularizer의 이해

SIR의 동기: Soft-thresholding의 한계

Soft-thresholding (Nuclear norm)의 문제점:

\[ P_{\text{soft}}(x) = \text{sign}(x) \cdot \max(|x| - \tau, 0) \]

모든 값에 균일하게 \(\tau\)를 빼기 때문에:

큰 특이값 (신호):
σ₁ = 500 → 500 - τ = 490  (2% 손실)
σ₂ = 300 → 300 - τ = 290  (3.3% 손실)

작은 특이값 (노이즈):
σ₉₀ = 20 → 20 - τ = 10   (50% 손실)
σ₁₀₀ = 5 → 5 - τ = 0     (100% 제거)

문제: 큰 값도 일정량 손실 → Biased!

SIR의 목표:

“작은 값은 강하게 shrink (sparsity), 큰 값은 거의 보존 (unbiased)”

Theorem 2.1의 구조 이해

Step 1: \(\phi_{h,\tau}(x)\) 정의

\[ \phi_{h,\tau}(x) = \begin{cases} \frac{x^2}{2}, & |x| \leq \tau \\ \alpha h(|x|) + \beta, & |x| > \tau \end{cases} \]

이것은 두 영역으로 나뉜 함수:

  • 작은 값 영역 (\(|x| \leq \tau\)): 이차 함수 \(x^2/2\)
  • 큰 값 영역 (\(|x| > \tau\)): 사용자 정의 함수 \(\alpha h(|x|) + \beta\)

함수 \(h(\cdot)\)의 역할:

\(h(\cdot)\)를 적절히 선택하여 큰 값에 대한 penalty 형태를 조절

예시 1: \(h(t) = t\) (선형)

|x| ≤ τ: φ(x) = x²/2
|x| > τ: φ(x) = αx + β

→ 큰 값에 대해 선형 penalty (soft-thresholding과 유사)

예시 2: \(h(t) = \log(t)\) (로그)

|x| ≤ τ: φ(x) = x²/2
|x| > τ: φ(x) = α log(|x|) + β

→ 큰 값에 대해 penalty 증가율 감소

Step 2: Convexity 조건

\[ g(x) = \frac{x^2}{2} - \phi_{h,\tau}(x) \text{ is closed and semicontinuous convex} \]

이 조건은 \(\phi_{h,\tau}(x)\)가 “적절한 형태”를 가지도록 보장:

\(g(x)\)의 형태:

|x| ≤ τ:
g(x) = x²/2 - x²/2 = 0  (상수)

|x| > τ:
g(x) = x²/2 - (αh(|x|) + β)

g(x)가 convex하려면:
→ h(·)는 특정 조건 만족해야 함
→ 예: h(t) = t (선형)일 때 조건 만족

이 조건이 만족되면, 유도되는 regularizer \(\varphi_{h,\tau}\)가 좋은 성질을 가짐

Step 3: SIR \(\varphi_{h,\tau}\)의 유도

Moreau envelope을 통해 regularizer를 정의:

\[ \varphi_{h,\tau}(y) = \max\left\{-\frac{1}{2\lambda}(x-y)^2 + \phi_{h,\tau}(x)\right\} \]

(이 부분은 이론적이므로 자세한 계산은 생략)

중요한 점:

이렇게 유도된 \(\varphi_{h,\tau}\)를 proximal operator 정의에 사용하면:

\[ \phi_{h,\tau}(x) = \min_y \frac{1}{2}(y-x)^2 + \tau\varphi_{h,\tau}(y) \]

이것이 성립함 (즉, \(\phi_{h,\tau}\)가 자신의 regularizer의 proximal operator)

Step 4: Proximal Operator의 Closed Form

\[ P_{\varphi_{h,\tau}}(x) = \text{sign}(x) \cdot \max\{0, |x| - \alpha h'(|x|)\} \]

핵심: Shrinkage 양이 \(\alpha h'(|x|)\)로 결정됨!

Soft-thresholding과 비교:

Soft-thresholding:
P_soft(x) = sign(x) · max{0, |x| - τ}
→ 고정된 τ만큼 shrink

SIR:
P_SIR(x) = sign(x) · max{0, |x| - αh'(|x|)}
→ h'(|x|)에 따라 shrinkage 양이 변함!

구체적 예시: \(h(t) = \log(1 + t/\epsilon)\)

함수 설정:

\[ h(t) = \log(1 + t/\epsilon), \quad h'(t) = \frac{1}{\epsilon + t} \]

Proximal operator:

\[ P_{\varphi_{h,\tau}}(x) = \text{sign}(x) \cdot \max\left\{0, |x| - \frac{\alpha}{\epsilon + |x|}\right\} \]

Shrinkage 양 분석:

|x|가 작을 때:
h'(|x|) = 1/(ε + |x|) ≈ 1/ε (큼)
→ Shrinkage = α/ε (큼)
→ 작은 값 강하게 제거

|x|가 클 때:
h'(|x|) = 1/(ε + |x|) ≈ 1/|x| (작음)
→ Shrinkage = α/|x| (작음)
→ 큰 값 거의 보존!

구체적 숫자 (\(\alpha = 10, \epsilon = 1\)):

x = 500:
h'(500) = 1/(1+500) ≈ 0.002
Shrinkage = 10 × 0.002 = 0.02
P(500) = 500 - 0.02 ≈ 500 (거의 변화 없음!)

x = 100:
h'(100) = 1/(1+100) ≈ 0.0099
Shrinkage = 10 × 0.0099 ≈ 0.1
P(100) = 100 - 0.1 ≈ 99.9

x = 10:
h'(10) = 1/(1+10) ≈ 0.091
Shrinkage = 10 × 0.091 ≈ 0.91
P(10) = 10 - 0.91 ≈ 9.09

x = 1:
h'(1) = 1/(1+1) = 0.5
Shrinkage = 10 × 0.5 = 5
P(1) = max(0, 1-5) = 0 (완전 제거!)

다양한 \(h(\cdot)\) 함수의 선택

1. \(h(t) = t\) (선형)

\[ h'(t) = 1 \quad \Rightarrow \quad P(x) = \text{sign}(x) \cdot \max\{0, |x| - \alpha\} \]

→ Soft-thresholding과 동일 (고정 shrinkage)

2. \(h(t) = \log(1 + t/\epsilon)\) (로그)

\[ h'(t) = \frac{1}{\epsilon + t} \quad \Rightarrow \quad P(x) = \text{sign}(x) \cdot \max\left\{0, |x| - \frac{\alpha}{\epsilon + |x|}\right\} \]

→ Adaptive shrinkage (큰 값은 적게)

3. \(h(t) = \sqrt{t}\) (제곱근)

\[ h'(t) = \frac{1}{2\sqrt{t}} \quad \Rightarrow \quad P(x) = \text{sign}(x) \cdot \max\left\{0, |x| - \frac{\alpha}{2\sqrt{|x|}}\right\} \]

→ 더 강한 adaptive shrinkage

적절히 설계된 SIR (예: log \(h\))는 세 가지 조건 모두 만족:

1. Sparsity: ✓

작은 |x|에서:

2. Unbiasedness: ✓

큰 |x|에서:
h'(|x|) → 0 → Shrinkage → 0 → P(x) ≈ x

3. Continuity: ✓

$h(\cdot)$가 연속이고 미분 가능하면

구체적인 \(h(\cdot)\) 함수의 선택

두 가지 \(h(\cdot)\) 함수를 고려:

  • Cauchy function: \(h_\gamma(x) = \log(1 + (x/\gamma)^2)\) (\(\gamma > 0\))
  • \(l_p\)-norm function: \(h_p(x) = |x|^p\) (\(0 < p < 1\))

대응하는 Proximal Operator

(SIC) Cauchy function에 대한 proximal operator:

\[ P_{\varphi_{\gamma,\tau}}(x) = \text{sign}(x) \cdot \max\left\{0, |x| - \frac{(\gamma^2 + \tau^2)|x|}{\gamma^2 + x^2}\right\} \]

(SIP) \(l_p\)-norm function에 대한 proximal operator:

\[ P_{\varphi_{p,\tau}}(x) = \text{sign}(x) \cdot \max\{0, |x| - \tau^{2-p}|x|^{p-1}\} \]

추가 해설: SIC와 SIP Proximal Operator의 상세 분석

SIC: Sparsity-Inducing Cauchy

함수 정의:

\[ h_\gamma(x) = \log(1 + (x/\gamma)^2) \]

미분:

\[ h_\gamma'(x) = \frac{2x/\gamma^2}{1 + (x/\gamma)^2} = \frac{2x}{\gamma^2 + x^2} \]

Proximal operator 유도:

일반 SIR 공식에서:

\[ P(x) = \text{sign}(x) \cdot \max\{0, |x| - \alpha h'(|x|)\} \]

\(\alpha = (\gamma^2 + \tau^2)/2\)로 설정하면:

\[ P_{\varphi_{\gamma,\tau}}(x) = \text{sign}(x) \cdot \max\left\{0, |x| - \frac{\gamma^2 + \tau^2}{\gamma^2 + x^2} \cdot |x|\right\} \]

SIC의 Shrinkage 양 분석

Shrinkage amount:

\[ s(x) = \frac{(\gamma^2 + \tau^2)|x|}{\gamma^2 + x^2} \]

\(|x|\)에 따른 변화:

|x| → 0일 때:
s(x) = (γ² + τ²)|x| / γ² ≈ (1 + τ²/γ²)|x|
→ |x|에 비례 (작은 값은 많이 shrink)

|x| → ∞일 때:
s(x) = (γ² + τ²)|x| / x² = (γ² + τ²) / |x| → 0
→ 거의 0 (큰 값은 거의 안 shrink)

구체적 숫자 예시 (\(\gamma = 10, \tau = 5\)):

γ² + τ² = 100 + 25 = 125

|x| = 1:
s(1) = 125 × 1 / (100 + 1) ≈ 1.24
P(1) = max(0, 1 - 1.24) = 0 (제거!)

|x| = 5:
s(5) = 125 × 5 / (100 + 25) = 625/125 = 5
P(5) = max(0, 5 - 5) = 0 (경계선)

|x| = 10:
s(10) = 125 × 10 / (100 + 100) = 1250/200 = 6.25
P(10) = 10 - 6.25 = 3.75 (62.5% shrink)

|x| = 50:
s(50) = 125 × 50 / (100 + 2500) = 6250/2600 ≈ 2.40
P(50) = 50 - 2.40 = 47.6 (4.8% shrink)

|x| = 100:
s(100) = 125 × 100 / (100 + 10000) = 12500/10100 ≈ 1.24
P(100) = 100 - 1.24 = 98.76 (1.24% shrink)

|x| = 500:
s(500) = 125 × 500 / (100 + 250000) ≈ 0.25
P(500) = 500 - 0.25 = 499.75 (0.05% shrink)

패턴:

|x|     Shrinkage   비율
1       1.24        124%  → 완전 제거
5       5.00        100%  → 경계
10      6.25        62.5% → 강한 shrink
50      2.40        4.8%  → 약한 shrink
100     1.24        1.24% → 매우 약함
500     0.25        0.05% → 거의 없음

→ 매우 강한 adaptive shrinkage!

파라미터 \(\gamma\)의 역할

\(\gamma\)는 “전환점(transition point)”을 조절:

\(\gamma\)가 작을 때:

γ = 1, τ = 5일 때:

|x| = 10:
s(10) = (1 + 25) × 10 / (1 + 100) = 260/101 ≈ 2.57
P(10) = 10 - 2.57 = 7.43

→ 더 빨리 unbiased 영역으로 전환

\(\gamma\)가 클 때:

γ = 100, τ = 5일 때:

|x| = 10:
s(10) = (10000 + 25) × 10 / (10000 + 100) = 100250/10100 ≈ 9.93
P(10) = 10 - 9.93 = 0.07

→ 더 느리게 전환 (더 많이 shrink)

권장 설정:

\(\gamma \approx\) “중요한 신호”의 크기 정도로 설정

SIP: Sparsity-Inducing \(l_p\)-norm

함수 정의:

\[ h_p(x) = |x|^p, \quad 0 < p < 1 \]

미분:

\[ h_p'(x) = p|x|^{p-1} \]

Proximal operator:

\[ P_{\varphi_{p,\tau}}(x) = \text{sign}(x) \cdot \max\{0, |x| - \tau^{2-p}|x|^{p-1}\} \]

Shrinkage 양:

\[ s(x) = \tau^{2-p}|x|^{p-1} \]

SIP의 Shrinkage 양 분석

\(p\)의 값에 따른 특성:

\(p < 1\)이므로 \(p - 1 < 0\) → sub-linear!

|x|가 작을 때:
|x|^(p-1) = 1/|x|^(1-p) → 큼
→ Shrinkage 큼

|x|가 클 때:
|x|^(p-1) → 0
→ Shrinkage 작음

구체적 예시 (\(p = 0.5\), \(\tau = 10\)):

\(p - 1 = -0.5\), \(\tau^{2-p} = 10^{1.5} \approx 31.62\)

|x| = 1:
s(1) = 31.62 × 1^(-0.5) = 31.62
P(1) = max(0, 1 - 31.62) = 0 (제거!)

|x| = 10:
s(10) = 31.62 × 10^(-0.5) = 31.62 / √10 ≈ 10
P(10) = max(0, 10 - 10) = 0 (경계)

|x| = 100:
s(100) = 31.62 × 100^(-0.5) = 31.62 / 10 = 3.16
P(100) = 100 - 3.16 = 96.84 (3.16% shrink)

|x| = 1000:
s(1000) = 31.62 × 1000^(-0.5) = 31.62 / 31.62 = 1
P(1000) = 1000 - 1 = 999 (0.1% shrink)

|x| = 10000:
s(10000) = 31.62 × 10000^(-0.5) = 31.62 / 100 ≈ 0.316
P(10000) = 10000 - 0.316 = 9999.68 (0.003% shrink)

패턴:

|x|      Shrinkage   비율
1        31.62       3162%  → 완전 제거
10       10.00       100%   → 경계
100      3.16        3.16%  → 약한 shrink
1000     1.00        0.1%   → 매우 약함
10000    0.316       0.003% → 거의 없음

→ 매우 강한 adaptive shrinkage!

파라미터 \(p\)의 역할

\(p\)가 작을수록 더 강한 sparsity:

\(p = 0.8\):

|x|^(p-1) = |x|^(-0.2)

|x| = 100:
s(100) = τ^1.2 × 100^(-0.2) ≈ τ^1.2 / 2.51

→ 덜 aggressive

\(p = 0.5\):

|x|^(p-1) = |x|^(-0.5) = 1/√|x|

|x| = 100:
s(100) = τ^1.5 × 100^(-0.5) = τ^1.5 / 10

→ 중간

\(p = 0.2\):

|x|^(p-1) = |x|^(-0.8)

|x| = 100:
s(100) = τ^1.8 × 100^(-0.8) ≈ τ^1.8 / 39.8

→ 매우 aggressive

권장 설정:

\(p \in [0.3, 0.7]\) 정도가 실용적

21. Truncated SIR

Truncated SIR의 동기

가장 큰 특이값들은 교통 행렬의 시간적 추세를 반영하는 본질적 정보를 포함함 (Chen et al., 2020)

Truncated SIR 정의

텐서에 대해 첫 \(r\)개의 가장 큰 특이값에 추가 truncation을 적용한 truncated SIR을 정의

Definition 2.2 (Truncated sparsity-inducing regularizer; TSIR)

3차 텐서 \(\mathcal{X} \in \mathbb{R}^{n_1 \times n_2 \times n_3}\)에 대해 TSIR은 다음과 같이 정의됨:

\[ \|\mathcal{X}\|_{\varphi_{h,\tau,\theta}} = \sum_{k=1}^3 \alpha_k \|\mathcal{X}_{(k)}\|_{\varphi_{h,\tau,\theta}} = \sum_{k=1}^3 \alpha_k \left( \sum_{i=r_k+1}^{m_k} \varphi_{h,\tau}(\sigma_i(\mathcal{X}_{(k)})) \right) \]

여기서: - \(m_k = \min(n_k, (n_1n_2n_3/n_k))\) - \(r_k = \lceil \theta m_k \rceil\), \(k = 1, 2, 3\) - Truncation rate \(\theta \in [0, 1]\)

추가 해설: Truncated SIR (TSIR)의 상세 이해

왜 Truncation이 필요한가?

문제 상황:

교통 텐서 Mode-1 unfolding:
특이값: [500, 300, 100, 50, 20, 10, 5, 2, 1, 0.5, ...]
         ↑              ↑                      ↑
      매우 중요    중간 정도 중요           노이즈

SIR만 적용하면:
- 큰 값 (500, 300): 거의 그대로 (good!)
- 중간 값 (100, 50): 약간 shrink (괜찮음)
- 작은 값 (5, 2, 1): shrink되지만 0은 아님 (문제!)

문제: 작은 특이값들이 완전히 제거되지 않고 남아있음

Truncated SIR의 아이디어:

“가장 큰 특이값 몇 개는 보존하고, 나머지에만 SIR 적용”

Definition 2.2의 구조 분석

핵심 수식:

\[ \|\mathcal{X}_{(k)}\|_{\varphi_{h,\tau,\theta}} = \sum_{i=r_k+1}^{m_k} \varphi_{h,\tau}(\sigma_i(\mathcal{X}_{(k)})) \]

주목: Summation이 \(i=1\)이 아니라 \(i=r_k+1\)부터 시작!

의미:

특이값: σ₁, σ₂, ..., σ_rₖ, σ_{rₖ+1}, ..., σ_{mₖ}
        ↑________________↑  ↑_________________↑
         이 부분은 제외!      이 부분만 SIR 적용

즉:
- 처음 rₖ개 특이값: penalty 없음 (완전 보존!)
- 나머지: SIR penalty 적용

파라미터 설명

\(m_k\): mode-\(k\) unfolding의 최대 rank

\[ m_k = \min(n_k, n_1n_2n_3/n_k) \]

예시: 교통 텐서 (100 × 96 × 30)

Mode-1 unfolding X₍₁₎ ∈ ℝ^(100 × 2880):
m₁ = min(100, 2880) = 100
→ 최대 100개 특이값

Mode-2 unfolding X₍₂₎ ∈ ℝ^(96 × 3000):
m₂ = min(96, 3000) = 96
→ 최대 96개 특이값

Mode-3 unfolding X₍₃₎ ∈ ℝ^(30 × 9600):
m₃ = min(30, 9600) = 30
→ 최대 30개 특이값

\(r_k\): 보존할 특이값 개수

\[ r_k = \lceil \theta m_k \rceil \]

\(\theta \in [0, 1]\): truncation rate (보존 비율)

예시:

θ = 0.1 (10% 보존):
r₁ = ⌈0.1 × 100⌉ = 10  → 처음 10개 특이값 보존
r₂ = ⌈0.1 × 96⌉ = 10   → 처음 10개 특이값 보존
r₃ = ⌈0.1 × 30⌉ = 3    → 처음 3개 특이값 보존

θ = 0.2 (20% 보존):
r₁ = ⌈0.2 × 100⌉ = 20  → 처음 20개 특이값 보존
r₂ = ⌈0.2 × 96⌉ = 20
r₃ = ⌈0.2 × 30⌉ = 6

θ = 0 (0% 보존):
r₁ = r₂ = r₃ = 0  → 모든 특이값에 SIR 적용 (원래 SIR)

θ = 1 (100% 보존):
r₁ = 100, r₂ = 96, r₃ = 30  → 모든 특이값 보존 (no penalty!)

구체적 예시: Mode-1 unfolding (θ = 0.1)

특이값 (100개):
σ₁ = 500, σ₂ = 300, ..., σ₁₀ = 80,  ← 처음 10개
σ₁₁ = 50, σ₁₂ = 30, ..., σ₁₀₀ = 0.1 ← 나머지 90개

TSIR 적용 (r₁ = 10):

Penalty = 0 × φ(σ₁) + ... + 0 × φ(σ₁₀)     ← 보존!
        + φ(σ₁₁) + φ(σ₁₂) + ... + φ(σ₁₀₀)  ← SIR 적용

결과:
σ₁ = 500 → 500  (변화 없음!)
σ₂ = 300 → 300  (변화 없음!)
...
σ₁₀ = 80 → 80   (변화 없음!)
σ₁₁ = 50 → P_SIR(50) ≈ 47.6  (SIR shrinkage)
σ₁₂ = 30 → P_SIR(30) ≈ 26.5
...
σ₁₀₀ = 0.1 → 0  (제거)

  • 처음 2개 (θ=0.1 × 20개 중): 완전 보존
  • 나머지: 동일하게 SIR 적용

왜 이게 효과적인가?

1. 중요한 신호 완벽 보존

일반 SIR:
σ₁ = 500 → 499.75
→ 0.25 손실 (작지만 누적되면 문제)

σ₁ = 500 → 500
→ 0 손실 (완벽!)

2. 계산 효율

일반 SIR:
100개 특이값 모두 proximal operator 계산

TSIR (θ=0.1):
10개는 그대로 (계산 불필요)
90개만 proximal operator 계산
→ 10% 계산량 감소

3. 이론적 정당성

Chen et al. (2020): > “가장 큰 특이값들은 시간적 추세(temporal trends)를 반영”

→ 이것들은 노이즈가 아니므로 shrink하면 안 됨!

Truncation Rate θ의 선택

θ가 작을 때 (예: 0.05):

r = ⌈0.05 × 100⌉ = 5

장점:
- 소수의 중요한 특이값만 보존
- 나머지 대부분에 SIR 적용 → 강한 regularization

단점:
- 중요한 특이값이 5개보다 많으면 손실

θ가 클 때 (예: 0.3):

r = ⌈0.3 × 100⌉ = 30

장점:
- 더 많은 특이값 보존
- 중요한 정보 손실 최소화

단점:
- Regularization 효과 감소
- 노이즈가 남을 수 있음

권장 설정:

교통 데이터:
θ ∈ [0.05, 0.2]

이유:
- 주요 패턴은 상위 5-20% 특이값에 집중
- 나머지 80-95%는 노이즈 또는 미세 변동

Cross-validation:

θ 후보: [0.05, 0.1, 0.15, 0.2]
→ Validation 오차가 최소인 θ 선택

전체 LRTC with TSIR

최적화 문제:

\[ \min_{\mathcal{X}} \sum_{k=1}^3 \alpha_k \left( \sum_{i=r_k+1}^{m_k} \varphi_{h,\tau}(\sigma_i(\mathcal{X}_{(k)})) \right), \quad \text{s.t.} \quad P_\Omega(\mathcal{X}) = P_\Omega(\mathcal{T}) \]

ADMM 알고리즘:

각 반복에서:

Mode-1 처리:
1. X₍₁₎ unfolding
2. SVD: U₁Σ₁V₁ᵀ
3. 상위 r₁개 특이값: 그대로 유지
4. 나머지: SIR proximal operator 적용
5. 재구성 및 fold

Mode-2, Mode-3 동일하게 처리

투영: P_Ω(X) = P_Ω(T)

Pseudocode:

for iteration in range(max_iter):
    for k in [1, 2, 3]:
        # Unfolding
        X_k = unfold(X, mode=k)
        
        # SVD
        U, Σ, V = svd(X_k)
        
        # TSIR 적용
        r_k = ceil(theta * len(Σ))
        Σ_new = Σ.copy()
        
        # 처음 r_k개: 보존
        Σ_new[:r_k] = Σ[:r_k]
        
        # 나머지: SIR proximal operator
        for i in range(r_k, len(Σ)):
            Σ_new[i] = SIR_proximal(Σ[i], h, tau)
        
        # 재구성
        X_k = U @ diag(Σ_new) @ V.T
        X = fold(X_k, mode=k)
    
    # 제약 조건
    X[Ω] = T[Ω]

설정:

교통 텐서: 100 × 96 × 30
결측률: 50%

Mode-1 (도로 패턴):

m₁ = 100

→ 모두 완전 보존!

→ SIR로 적절히 처리

예상 효과:

TSIR의 예상 장점:

Soft-thresholding 대비:
- 중요한 특이값 완전 보존 (θ truncation)
- 중간 특이값 adaptive shrinkage (SIR)
- 작은 특이값 효과적 제거

예상되는 시너지:
1. 중요한 패턴 완전 보존 (θ truncation)
2. 노이즈 효과적 제거 (SIR)
3. 두 효과의 결합으로 성능 향상 기대

θ=0일 때와의 관계

\[ \theta = 0 \Rightarrow r_k = 0 \Rightarrow \text{TSIR} = \text{SIR} \]

θ=0:
Σ_{i=0+1}^{m_k} φ(σᵢ) = Σ_{i=1}^{m_k} φ(σᵢ)
→ 모든 특이값에 SIR 적용 (일반 SIR)

∴ TSIR은 SIR의 일반화 (generalization)

이론적 vs 실용적 고려

이론적 문제:

TSIR은 비볼록(non-convex)이고 불연속: - 상위 \(r_k\)개는 penalty 0 - 그 아래는 penalty 있음 - 경계에서 불연속

실용적 해결:

ADMM 같은 알고리즘에서: 1. 각 반복에서 \(r_k\)는 고정 2. Proximal operator는 연속 (SIR 부분) 3. 이론적으로 수렴 가능성 있음

예상 특성:

TSIR 적용 시: - 각 반복에서 안정적 업데이트 예상 - SIR의 연속성 덕분에 수렴 가능성 - 실제 데이터에서 검증 필요

TSIR의 기여 정리

  1. 이론적 기여:
    • SIR을 truncation과 결합한 framework
    • 명확한 수학적 정의 (Definition 2.2)
  2. 실용적 기여:
    • 중요한 신호 완전 보존
    • 계산 효율 향상
    • 교통 데이터에서 검증된 성능 개선
  3. 파라미터 \(\theta\):
    • 직관적: 보존할 특이값 비율
    • 조정 가능: cross-validation으로 선택
    • 안정적: 다양한 데이터에서 작동

22. Proximal operator for TSIR

Proximal Operator for TSIR

Theorem 2.2 (Proximal operator for TSIR)

함수 \(\varphi_{h,\tau}(\cdot)\)가 \(\phi_{h,\tau}(\cdot)\)로부터 생성된 SIR이라고 가정. \(\tau > 0\), \(0 \leq \theta \leq 1\)이고, 행렬 \(\mathbf{B} \in \mathbb{R}^{n_1 \times n_2}\)의 SVD 형태가 \(\mathbf{B} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^T\), \(\mathbf{\Sigma} = \text{diag}(\sigma_1, \ldots, \sigma_m)\), \(m = \min(n_1, n_2)\)일 때, 다음 rank minimization 문제를 고려:

\[ \min_{\mathbf{X}} \frac{1}{2}\|\mathbf{X} - \mathbf{B}\|_F^2 + \tau\|\mathbf{X}\|_{\varphi_{h,\tau,\theta}} \]

문제의 해:

\[ P_{\varphi_{h,\tau,\theta}}(\mathbf{X}) = \mathbf{U}\mathbf{\Delta}\mathbf{V}^T \]

여기서:

\[ \mathbf{\Delta} = \text{diag}(\sigma_1, \ldots, \sigma_r, P_{\varphi_{h,\tau}}(\sigma_{r+1}), \ldots, P_{\varphi_{h,\tau}}(\sigma_m)) \]

그리고 \(r = \lceil \theta m \rceil\)

각 \(P_{\varphi_{h,\tau}}(\sigma)\)는 다음 문제를 풀어서 결정:

\[ P_{\varphi_{h,\tau}}(\sigma) = \arg\min_{s>0} \frac{1}{2}(s-\sigma)^2 + \tau\varphi_{h,\tau}(s) \]

추가 해설: TSIR Proximal Operator의 상세 이해

문제 설정

TSIR을 사용한 행렬 근사 문제:

\[ \min_{\mathbf{X}} \frac{1}{2}\|\mathbf{X} - \mathbf{B}\|_F^2 + \tau\|\mathbf{X}\|_{\varphi_{h,\tau,\theta}} \]

두 항의 의미:

Fidelity term: ||X - B||²_F
→ X는 B에 가까워야 함

Regularization: τ||X||_{φ_h,τ,θ}
→ X는 low-rank + truncated structure

이 문제가 왜 중요한가?

ADMM 같은 최적화 알고리즘의 각 반복마다 이런 형태의 부문제(subproblem)를 풀어야 함

Theorem 2.2의 핵심

놀라운 사실: 이 문제의 해가 closed form으로 존재!

\[ P_{\varphi_{h,\tau,\theta}}(\mathbf{X}) = \mathbf{U}\mathbf{\Delta}\mathbf{V}^T \]

의미:

  1. B의 SVD만 계산하면 됨: \(\mathbf{B} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^T\)
  2. 특이값만 조작: \(\mathbf{\Sigma} \rightarrow \mathbf{\Delta}\)
  3. 같은 U, V로 재구성

\(\mathbf{\Delta}\)의 구조 분석

\[ \mathbf{\Delta} = \text{diag}(\sigma_1, \ldots, \sigma_r, P_{\varphi_{h,\tau}}(\sigma_{r+1}), \ldots, P_{\varphi_{h,\tau}}(\sigma_m)) \]

두 부분으로 나뉨:

처음 r개 특이값: σ₁, σ₂, ..., σᵣ
→ 그대로 유지! (truncation)

나머지 특이값: σᵣ₊₁, ..., σₘ
→ SIR proximal operator 적용

구체적 예시 (m=100, θ=0.1):

r = ⌈0.1 × 100⌉ = 10

B의 특이값:
Σ = diag(500, 300, 100, 80, 50, ..., 1, 0.5)

Δ 구성:
Δ = diag(
    500,                    ← σ₁ 그대로
    300,                    ← σ₂ 그대로
    ...
    80,                     ← σ₁₀ 그대로
    P_φ(50),                ← σ₁₁ SIR 적용 → 47.6
    P_φ(30),                ← σ₁₂ SIR 적용 → 26.3
    ...
    P_φ(0.5)                ← σ₁₀₀ SIR 적용 → 0
)

SIR Proximal Operator 계산

각 특이값 σ에 대해:

\[ P_{\varphi_{h,\tau}}(\sigma) = \arg\min_{s>0} \frac{1}{2}(s-\sigma)^2 + \tau\varphi_{h,\tau}(s) \]

이것은 이전에 배운 SIR proximal operator!

SIC의 경우:

\[ P_{\varphi_{\gamma,\tau}}(\sigma) = \max\left\{0, \sigma - \frac{(\gamma^2 + \tau^2)\sigma}{\gamma^2 + \sigma^2}\right\} \]

SIP의 경우:

\[ P_{\varphi_{p,\tau}}(\sigma) = \max\{0, \sigma - \tau^{2-p}\sigma^{p-1}\} \]

Step 4: 재구성

X = U Δ Vᵀ

왜 이 형태가 최적해인가?

핵심 정리 (SVD의 성질):

Frobenius norm과 특이값의 관계:

\[ \|\mathbf{X} - \mathbf{B}\|_F^2 = \sum_i (\sigma_i(\mathbf{X}) - \sigma_i(\mathbf{B}))^2 \]

(같은 U, V를 공유할 때)

증명 스케치:

원래 문제:
min_X ||X - B||²_F + τ||X||_{φ_h,τ,θ}

X = U Δ Vᵀ로 parametrize하면:
min_Δ ||Δ - Σ||²_F + τ||Δ||_{φ_h,τ,θ}

TSIR 정의에서:
||Δ||_{φ_h,τ,θ} = Σᵢ₌ᵣ₊₁ᵐ φ_h,τ(Δᵢ)

분리 (separable):
min_Δ Σᵢ [(Δᵢ - Σᵢ)² + τ·I(i>r)·φ_h,τ(Δᵢ)]

각 i에 대해 독립적으로 최적화:
- i ≤ r: Δᵢ = Σᵢ (penalty 없음)
- i > r: Δᵢ = P_φ(Σᵢ) (SIR proximal)

∴ Closed form 존재!

일반 SIR vs TSIR Proximal Operator

일반 SIR (θ=0):

def SIR_proximal(B, h, tau):
    U, Σ, V = svd(B)
    Δ = zeros_like(Σ)
    
    for i in range(len(Σ)):
        Δ[i] = P_SIR(Σ[i], h, tau)  # 모든 특이값 처리
    
    return U @ Δ @ V.T

TSIR (θ>0):

def TSIR_proximal(B, h, tau, theta):
    U, Σ, V = svd(B)
    m = len(Σ)
    r = ceil(theta * m)
    Δ = zeros_like(Σ)
    
    # 처음 r개: 보존
    for i in range(r):
        Δ[i] = Σ[i]
    
    # 나머지: SIR
    for i in range(r, m):
        Δ[i] = P_SIR(Σ[i], h, tau)
    
    return U @ Δ @ V.T

차이점: r개 특이값 보존 여부

계산 복잡도

SVD 계산: \(O(\min(n_1^2 n_2, n_1 n_2^2))\)

Proximal operator 적용: \(O(m)\) (m개 특이값)

재구성: \(O(n_1 n_2 \min(n_1, n_2))\)

총 복잡도: SVD가 지배

TSIR의 이점:

일반 SIR: m개 특이값 모두 처리
TSIR: (m - r)개만 처리

r = θm이면:
계산량 절감: θ × 100%

예: θ = 0.1 → 10% 절감

텐서 LRTC에서의 사용

텐서의 각 mode unfolding마다 적용:

def LRTC_TSIR(T, Omega, h, tau, theta, max_iter):
    X = initialize(T, Omega)
    
    for iteration in range(max_iter):
        # Mode-1
        X_1 = unfold(X, mode=1)
        X_1 = TSIR_proximal(X_1, h, tau, theta)
        X = fold(X_1, mode=1)
        
        # Mode-2
        X_2 = unfold(X, mode=2)
        X_2 = TSIR_proximal(X_2, h, tau, theta)
        X = fold(X_2, mode=2)
        
        # Mode-3
        X_3 = unfold(X, mode=3)
        X_3 = TSIR_proximal(X_3, h, tau, theta)
        X = fold(X_3, mode=3)
        
        # Projection
        X[Omega] = T[Omega]
        
        if converged(X):
            break
    
    return X

Theorem 2.2의 실용적 중요성

왜 중요한가?

  1. Closed form 존재
    • 수치 최적화 불필요
    • 정확한 해
    • 빠른 계산
  2. 구현이 간단
    • SVD + 특이값 조작
    • 몇 줄의 코드로 구현 가능
  3. 이론적 보장
    • 최적해임이 증명됨
    • 수렴 보장

만약 closed form이 없었다면?

각 ADMM 반복마다:
  각 mode마다:
    수치 최적화로 부문제 풀기
    → gradient descent 등
    → 매우 느림!

Closed form 덕분에:

각 ADMM 반복마다:
  각 mode마다:
    SVD → 특이값 조작 → 재구성
    → 빠름!

예상되는 성능

TSIR의 예상 장점:

교통 데이터 completion에서 TSIR의 예상 특성:

계산 효율:
- r개 특이값은 처리 불필요 → 계산량 감소
- Closed form 덕분에 빠른 계산

성능:
- 중요한 특이값 완전 보존 → 정확도 향상 예상
- SIR의 adaptive shrinkage 효과 유지

Theorem 2.2 요약
