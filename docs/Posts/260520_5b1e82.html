연구 ▷ HST ▷ 그래프거리 ▷ 스펙트럴 임베딩이 최고인가 — 한계 5가지와 상황별 최선

Author

연

Published

May 20, 2026

대표가 던진 질문 (2026-05-20): “그래프도메인에서 거리를 메져하는건 스펙트럴 임베딩이 최고인가?” — 본 노트는 그 답이 “아니오” 인 이유를 다섯 가지 한계 + 상황별 최선표로 정리한다. 본인의 그래프도메인거리 영문 LaTeX (산출물명: 그래프도메인거리(연,★★)) 와 그래프 거리 참고문헌 카탈로그 (그래프거리참고문헌(연,★★)) 가 토대.

한 줄 요지: 스펙트럴 임베딩 (Laplacian eigenmap, diffusion map, spectral clustering 등) 은 강력하지만 “최고” 가 아니다. 5가지 구조적 한계가 있고, 상황별로 다른 도구가 최선이 된다. 스펙트럴은 강력한 family 이고 family 자체가 reversible + undirected + 노드값 없음 + 고정 scale + k=0 cochain 위에 서 있다 — 이 가정 중 하나라도 깨지면 family 밖이 답.

스펙트럴 family 의 한계와 상황별 최선

좁은 의미의 스펙트럴 임베딩은 [Belkin-Niyogi 2003] Laplacian eigenmaps — 그래프 라플라시안 \(\mathbf{L} = \bfD - \bfW\) 의 작은 고유값에 해당하는 고유벡터들로 노드를 좌표화. 노드 \(i, j\) 거리는 좌표 차이의 유클리드 노름이다. 넓은 의미로는 리이의 책공부 팟캐스트 가 통일한 스펙트럴 필터 family —

\[d_f^2(i, j) \;=\; \sum_{k=2}^n f(\lambda_k)\,\big(\psi_k(i) - \psi_k(j)\big)^2.\]

\(f(\lambda)\) 거리
\((1-\lambda)^{2t}\) Diffusion
\(e^{-t\lambda}\) Heat kernel
\(\alpha^2 /(1-(1-\alpha)(1-\lambda))^2\) Personalised PageRank
\(1/\lambda\) Effective resistance
\(1/\lambda^2\) Biharmonic
\((1+\lambda)/(1-\lambda)\) HST₀ Intermediate-regime 상수 — 본인 최근 결과로 추가

본 노트의 “스펙트럴” 은 이 넓은 family 전체.

다섯 가지 한계를 차례로 본다. (1) 노드값 \(\boldsymbol{y}\) 무시. 스펙트럴은 \(\mathbf{L}\) 만 본다. 그러나 실제 그래프 위 데이터는 \((\mathbf{L}, \boldsymbol{y})\) — 토폴로지 + 노드값의 쌍이다. 같은 그래프 위에 다른 신호 \(\boldsymbol{y}_1, \boldsymbol{y}_2\) 가 올라가도 스펙트럴 거리 \(d_f(i,j)\) 는 똑같다 (필터 \(f\) 와 eigenpair 만 함수). Choi-Oh 2026 (HST 본 논문) §1 의 출발점이 정확히 이 관찰이다 — HST 의 SD 는 \(\boldsymbol{y}\) 의 history 가 누적된 양으로, 같은 \(\mathbf{L}\) 위 다른 \(\boldsymbol{y}\) 에 대해 다른 거리를 준다. graph signal processing 의 관점에서 보면, 스펙트럴 거리는 operator distance 일 뿐 signal-aware distance 가 아니다.

(2) Reversibility 의존. (6.34) 형식 \(\sum_k f(\lambda_k)|\langle \cdot, v_k\rangle|^2\) 자체가 reversible chain (\(\pi_i P_{ij} = \pi_j P_{ji}\)) 가정을 통해 self-adjointness 를 확보한다. 비대칭 \(\bfW\) 면 강제 대칭화 \(\mathbf{L}_s = (\mathbf{L} + \mathbf{L}^\top)/2\) 로 가서 방향성 정보 손실 (directed cycle 의 cycle 방향이 완전히 사라짐. 리이 팟캐스트 §directed cycle 예시), 또는 Hermitian Laplacian (Cucuringu-Singh 2020, ref/PAPER_CucuringuSingh2020_Hermitian.pdf) 으로 가면 eigenstructure 가 복소수로 가게 되어 표준 스펙트럴 임베딩 식과 다른 framework 가 필요해진다.

(3) 큰 그래프 붕괴 (von Luxburg degeneracy). von Luxburg, Radl, Hein 2014 의 결과는, 큰 그래프에서 commute time / resistance distance / spectral embedding 거리 모두 \(1/d_i + 1/d_j\) degree-only ultrametric 으로 점근한다는 것. 즉 노드 쌍의 거리가 두 노드의 degree 만으로 결정되고, 그래프의 세밀한 구조 (geodesic, community 등) 가 완전히 사라진다. 큰 그래프에서 스펙트럴은 trivialise 한다. 소미의 HST₀ d3bd76 가 보인 leaf-leaf 임베딩의 hub/leaf 만 남는 양상도 이 large-\(n\) degeneracy 와 같은 결이다.

(4) 고정 scale. 표준 스펙트럴 임베딩은 처음 \(K\) 개 eigenvector 같은 고정 cutoff 를 쓴다 — multi-scale 조절 부재. Diffusion distance 의 \(t\) parameter 가 일부 보완 (\(f(\lambda) = (1-\lambda)^{2t}\) 의 \(t\) 를 키우면 smoother → community level, 작게 잡으면 finer → local) 하지만 단일 \(t\) 이다. 본 회사 HST 의 \(t\) parameter 는 세 regime 사이를 옮겨다니는 multi-scale 조절 (Thm A/B/C 가 그 회로) 로, 스펙트럴 family 의 단일-\(t\) 와 구조적으로 다르다.

(5) 고차 cochain 무지. 스펙트럴 라플라시안 \(\mathbf{L}\) 은 vertex-domain (k=0 cochain) 위 연산자다. 그러나 그래프 위 데이터에는 edge-flow (k=1), triangle-flow (k=2) 등 고차 cochain 이 있다. Lim 2020 Hodge Laplacians on graphs, Schaub 2020 Random walks on simplicial complexes 가 이 고차 일반화의 핵심 (ref/PAPER_Schaub2020_SimplicialRandomWalks.pdf). 본인의 HST × 토폴로지 시그널 v0.1 의 일반화 후보 A/B/C 가 다루는 영역이 정확히 이쪽 — 스펙트럴이 손대지 못하는 곳이다.

이 다섯 가지 한계를 정황별로 매핑하면 다음 표가 된다:

상황 최선 도구 비고
\(\boldsymbol{y}\) X, undirected, fixed scale 충분 스펙트럴 (Laplacian eigenmap / diffusion) 가장 자연스러운 적용역. Belkin-Niyogi 2003, Coifman-Lafon 2006.
\(\boldsymbol{y}\) X, directed Hitting time / Hermitian Laplacian 비가역 chain. Cucuringu 2020.
\(\boldsymbol{y}\) 있음, 노드값 + 구조 동시 HST \(SD(t)\) (본 회사 본업) 본 회사가 신규로 메우는 자리.
큰 그래프, 점근 거리 Multi-scale 필요 스펙트럴 도 resistance 도 trivialise (von Luxburg 2014).
그래프 간 거리 (inter-graph) Gromov-Wasserstein / Fused GW 노드 쌍이 아닌 그래프-그래프. Mémoli 2011, Vayer 2019.
고차 cell cochain Hodge \(\Delta_k\) / Simplicial walks Lim 2020, Schaub 2020.
Periodic / non-ergodic 동역학 HST의 block + reset 본 회사가 새로 메우는 자리.
Path-기반 explainability Shortest path / hitting 단순하지만 NLP·KG explainability 에서 비교 우위.

HST 의 자리와 결론

본인 그래프도메인거리 영문 LaTeX 가 정리한 7가지 거리 비교를 다시 적으면:

거리 노드값 undirected? multi-scale 고차?
Shortest path ✕ both OK ✕ ✕
Hitting time ✕ OK \(t\) 없음 ✕
Commute time ✕ reversible only ✕ ✕
Effective resistance ✕ reversible only ✕ ✕
ECTD ✕ OK ✕ ✕
Diffusion distance ✕ reversible only \(t\) OK ✕
HST \(SD(t)\) ✓ 방향 가능 \(t\) + Thm A/B/C 확장 후보

이 표가 보여주는 자리는 명확하다 — HST 는 \(\boldsymbol{y}\) 반영 + non-homogeneous \(\mathbf{P}(t)\) + periodic OK 가족의 신규 entry. 그러나 그 댓가로 \(\mathbf{Z}\) 닫힘이 사라진다. 본인 HST₀ 노트 가 이 trade-off 의 분기점을 정확히 짚는다 — HST₀ 만 스펙트럴 가족 안.

요컨대 스펙트럴 임베딩 / 스펙트럴 거리 family 는 단일 reversible \(\mathbf{P}\), 노드값 무관, undirected, 고정 scale, k=0 cochain 의 다섯 가정 위에 서 있다. 이 다섯 가정이 다 만족되는 상황에서는 매우 강력하지만, 5가지 모두 깰 수 있는 상황이 흔하다 — 그래서 family 밖에 더 풍부한 거리들이 존재한다. 본 회사의 HST 가 메우는 자리도 정확히 그 family 밖, 단일 \(\mathbf{P}\) 가 아닌 시변 \(\mathbf{P}(t)\) 위에 노드값 \(\boldsymbol{y}\) 가 함께 누적되는 매우 일반적인 setting 이다. “최고” 의 단일 답은 없고, 상황별 최선의 표가 답이다.
