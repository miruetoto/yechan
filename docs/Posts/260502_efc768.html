03wk — 경사하강법, 회귀분석 도입

1. 1차원 경사하강법의 발산·진동·local minima

함수 \(f(x) = (x - 1)^2\) 의 최소값을 경사하강법 \(x_{sol} \leftarrow x_{sol} - \alpha \cdot f'(x_{sol})\) 으로 찾는다.

(1) \(x_{sol} = 0\) 에서 시작하여 학습률 \(\alpha = 0.5\) 로 1회 업데이트한 후의 \(x_{sol}\) 값은? (단, \(f'(x) = 2(x-1)\))

① \(-1\)
② \(1\)
③ \(0\)
④ \(0.5\)

(2) 위 (1) 의 알고리즘을 충분히 많은 epoch 진행하면 \(x_{sol}\) 가 수렴하는 값은? (\(\alpha = 0.5\))

① \(0\)
② \(0.5\)
③ \(1\) — 1번 만에 도달 후 거기 머무름
④ 발산

(3) 학습률 \(\alpha\) 의 일반적 영향에 대해, 경사하강법 \(x_{sol} \leftarrow x_{sol} - \alpha \cdot f'(x_{sol})\) 의 특성으로 옳은 것을 모두 고르시오.

① \(\alpha = 1\) 이면 1회 만에 정확히 최소값에 도달
② \(\alpha = 1.5\) 이면 진동하면서 점차 발산
③ \(\alpha = 0.001\) 이면 수렴은 하지만 매우 느림
④ \(\alpha < 0\) 이면 최소가 아닌 최대값으로 향함

이번에는 비볼록함수 \(f(x) = x^4 - 2 x^2\) 를 고려한다. 이 함수는 \(x = -1, 1\) 에서 두 개의 local minimum 을 가진다.

(4) 위 함수에 대해 \(x_{sol} = 0.1\) 에서 시작하여 적절한 작은 학습률로 경사하강법을 수행하면 어디로 수렴하는가? (단, \(f'(x) = 4x^3 - 4x\))

① \(x = -1\)
② \(x = 0\)
③ \(x = 1\)
④ 발산

(5) 비볼록함수의 경사하강법 결과 해석으로 옳은 것은?

① 시작점에 따라 도달하는 local minimum 이 달라질 수 있다 (전역 최소값을 보장하지 않음)
② convex 든 non-convex 든 항상 전역 최소값에 수렴
③ 비볼록함수에서는 경사하강법이 절대 수렴하지 않음
④ 비볼록함수에서는 항상 시작점이 최종값

2. 2차원 경사하강법 (algorithm 1 vs 2)

다음 두 알고리즘을 비교한다.

  • 알고리즘1: 주변 격자점을 모두 조사하여 가장 작은 점으로 이동
  • 알고리즘2: 좌표축 방향으로만 조사 (편미분 기반)

다음 표는 차원 \(d\) 별 계산량 (\(3^d\) vs \(2d+1\)).

\(d\) 알고리즘1 (\(3^d\)) 알고리즘2 (\(2d+1\))
2 9 5
3 27 7
5 243 11
10 59049 21
20 \(3.49 \times 10^9\) 41

(1) 차원 \(d = 5\) 일 때 알고리즘1 의 계산량이 알고리즘2 의 약 몇 배인가?

① 약 22 배
② 약 50 배
③ 약 5 배
④ 두 알고리즘 같음

(2) 강의노트의 알고리즘1 (9개 격자점 조사) 과 알고리즘2 (편미분 기반) 가 다른 결과를 줄 수 있는 함수의 예로 적절한 것은?

① 모든 격자점에서 함수값이 같은 함수
② \((x, y) = (-0.1, 0.1)\) 에서만 매우 작고 다른 모든 격자점에서 0인 비convex 함수 (대각선 격자가 가장 작아서 알고리즘1 은 그곳으로 가지만, 알고리즘2 는 축 방향만 보므로 못 봄)
③ 모든 convex 함수
④ 모든 선형 함수

(3) \(f(x, y)\) 가 convex 일 때, 알고리즘1 과 알고리즘2 의 결과 비교로 옳은 것은?

① 항상 정확히 같다
② 일반적으로는 둘 다 같은 최소값으로 수렴하지만, 한 step 의 결과는 다를 수 있다
③ convex 에서도 항상 다르다
④ convex 와 non-convex 모두 항상 같다

(4) 다음 코드는 진정한 (동시 업데이트) 경사하강법인가?

for dummy in range(5):
    x_grad = (f(x_sol + 0.01, y_sol) - f(x_sol, y_sol)) / 0.01
    x_sol = x_sol - alpha * x_grad
    y_grad = (f(x_sol, y_sol + 0.01) - f(x_sol, y_sol)) / 0.01
    y_sol = y_sol - alpha * y_grad

① 진정한 경사하강법이다
② \(x\) 를 업데이트한 후 변경된 \(x\) 로 \(y\) 의 그래디언트를 구하므로 동시 업데이트가 아니어서 진정한 경사하강법이 아니다
③ 미분 근사가 잘못되어 경사하강법이 아니다
④ for 가 5번뿐이라 경사하강법이 아니다

3. SSE 의 해석해와 경사하강법

다음 회귀모형을 고려하자.

\[y_i = \beta_0 + \beta_1 x_i + \epsilon_i, \quad \epsilon_i \overset{i.i.d.}{\sim} N(0, \sigma^2)\]

데이터 \(n\) 개에 대해 다음 통계량이 주어졌다고 하자.

\[\sum x_i = 0, \quad \sum y_i = 0, \quad \sum x_i^2 = 100, \quad \sum x_i y_i = 200\]

(1) SSE \(l(\beta_0, \beta_1) = \sum (y_i - \beta_0 - \beta_1 x_i)^2\) 를 최소화하는 \(\hat \beta_1\) 을 구할 때 사용되는 정규방정식 (편미분 = 0) 으로 옳은 것은?

① \(\sum x_i (y_i - \hat\beta_0 - \hat\beta_1 x_i) = 0\)
② \(\sum (y_i - \hat\beta_0 - \hat\beta_1 x_i)^2 = 0\)
③ \(\sum y_i = 0\)
④ \(\sum x_i = 0\)

(2) 위 데이터로부터 \(\hat\beta_0, \hat\beta_1\) 의 해석해는?

① \(\hat\beta_0 = 0, \hat\beta_1 = 2\)
② \(\hat\beta_0 = 2, \hat\beta_1 = 0\)
③ \(\hat\beta_0 = 1, \hat\beta_1 = 1\)
④ \(\hat\beta_0 = 0, \hat\beta_1 = 0.5\)

(3) 위 (2) 의 데이터에 경사하강법 \(\hat\beta \leftarrow \hat\beta - \alpha \nabla l(\hat\beta)\) 을 충분한 epoch 으로 수행했을 때, \(\hat\beta_1\) 의 값은 어디로 수렴하는가?

① true parameter \(\beta_1^\ast\) (이 값은 데이터로는 모름)
② 해석해 \(\hat\beta_1 = 2\) — 즉 경사하강법은 SSE 의 해석해로 수렴
③ 0
④ \(\alpha\) 의 값

(4) 다음 회귀 관련 설명 중 옳은 것을 모두 고르시오.

① 적절한 \(\alpha\) 와 충분한 epoch 으로 경사하강법은 SSE 의 해석해로 수렴한다
② 적절한 \(\alpha\) 와 충분한 epoch 으로 경사하강법은 true parameter 로 수렴한다
③ SSE 와 MSE 는 같은 \(\hat\beta\) 를 주지만, 같은 학습률에서 수렴 속도는 다르다
④ 경사하강법으로 회귀를 풀면 벡터 미분 공식을 직접 유도할 필요가 없다

2. 회귀의 6가지 동치 코드

3. 자유낙하 — 모델링 토론

물리학과 최교수는 (높이 \(h\), 자유낙하 시간 \(t\)) 자료를 모았다. 두 모형으로 적합한다.

  • 모형 A: 도메인 지식 (\(t \propto \sqrt{h}\)) 활용, \(\hat t = \hat w \cdot \sqrt{h}\) (1 파라미터)
  • 모형 B: 1-은닉층 (노드 512, ReLU), \(\hat t = net(h)\) (1537 파라미터)

학습 데이터 범위 안의 어떤 점 \(h_0\) 에서 두 모형이 비슷한 예측을 내놓았다. 그러나 학습 범위 바깥의 큰 \(h\) 에서는 두 모형의 예측이 꽤 다르게 나왔다.

(1) 학습 데이터 범위 안에서 두 모형이 비슷한 예측을 내놓는 이유로 가장 적절한 것은?

① 두 모형이 같은 함수 (\(\sqrt{h}\)) 를 학습했기 때문
② 학습 데이터 범위에서 두 모형 모두 데이터를 잘 적합하는 어떤 함수 (꼭 같은 함수일 필요 없음) 를 찾았기 때문 — 시벤코는 함수 형태 식별의 보장이 아님
③ \(h_0\) 가 학습 데이터에 직접 포함되어 있기 때문
④ Adam 이 정답을 보장하기 때문

(2) 학습 데이터 범위 바깥의 큰 \(h\) 에서 두 모형의 예측이 다른 이유로 가장 적절한 것은?

① 모형 A 는 \(\sqrt{h}\) 곡선을 그대로 따라가지만, 모형 B 는 ReLU 기반 piecewise linear 라 학습 데이터 끝의 마지막 직선 조각이 그대로 이어지기 때문
② 모형 A 가 잘못 학습됐기 때문
③ 모형 B 가 100% 정확하기 때문
④ 학습 데이터 바깥에서 데이터 잡음이 더 크기 때문

(3) George Box 의 명언 “All models are wrong, but some are useful” 의 가장 적절한 해석은?

① 모든 모형은 본질적으로 현실을 단순화·이상화한 근사이므로 wrong 이지만, 평가 기준은 ‘true vs wrong’ 이 아니라 ‘useful vs useless’ 로 가져가야 한다
② 모든 모형은 틀렸으므로 사용 불가
③ 진짜 모형을 찾는 것이 가장 중요
④ 모형 비교로 항상 어느 모형이 wrong 인지 결정 가능

(4) 다음 학생들의 토론에서 강의 내용과 일치하는 (옳은) 주장만 모은 것은?

  • 재현: “두 모형이 다른 답을 내면 둘 중 적어도 하나는 wrong 이고, 그게 Box 의 ‘all models are wrong’ 의 핵심”
  • 슬기: “Box 의 핵심은 모형 비교가 아니라 평가 기준 자체를 ‘useful vs useless’ 의 관점으로 보라는 것”
  • 희석: “시벤코 정리에 의해 모형 B 는 데이터 뒤의 underlying \(\sqrt{\cdot}\) 형태를 식별해서 학습”

  • 세민: “모형 A 는 1 파라미터, 모형 B 는 ~1500 파라미터라 도메인 지식 비용 vs 모형 복잡도 비용의 trade-off”

② 슬기, 은희, 세민
