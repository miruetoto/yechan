목표는 Doeblin minorisation 이다: sublevel set \(\mathsf{C}_0 = \{s^{\star} : M(s^{\star}) \leq M_0\}\) 에 대해

\[ (P^{\star})^{nL}(s^{\star},\cdot) \;\geq\; \eta\,\mathrm{Unif}(\mathsf{U})\otimes\delta_{v_n} \qquad (\forall\, s^{\star}\in\mathsf{C}_0), \]

즉 창 \(nL\) 라운드 뒤 “높이차는 chamber \(\mathsf{U}\) 위 균등분포의 \(\eta\) 배 이상, walker 는 \(v_n\)” 이라는 공통 바닥을 확보하는 것 (Lemma 19). Def 7 직전까지 확보된 재료는 다음과 같다. 낙하벡터 \(\mathbf{b}^{\sharp}\in[0,b]^{nL}\) (i.i.d. \(\mathrm{Unif}(0,b)\), 라운드당 1개), fall map \(\mathbf{A}^{\sharp}\mathbf{b}^{\sharp} = \bigl(\sum_\ell b^{\sharp}_{2,\ell}-\sum_\ell b^{\sharp}_{1,\ell},\ldots\bigr)\) 와 그 right inverse \((\mathbf{A}^{\sharp})^{+}\), 커널의 정규직교기저 \(\mathbf{Z}^{\sharp}\) 와 자유좌표 \(\mathbf{z}^{\sharp}\), 전단사 \(\mathbf{b}^{\sharp}=(\mathbf{A}^{\sharp})^{+}\boldsymbol{\hbar}^{\sharp}+\mathbf{Z}^{\sharp}\mathbf{z}^{\sharp}\) (Jacobian \(J\)), 그리고 target 집합 \(\mathsf{K}\) 위 fiber 의 slice 부피 바닥

\[ \bigl|\mathsf{Fiber}(\mathbf{k})\bigr|_{\mathrm{Leb}} \;\geq\; m_0 \;>\; 0 \qquad (\forall\,\mathbf{k}\in\mathsf{K}). \]

복권 분포 \(\nu\) 는 “높이차가 \(\mathsf{U}\)” 뿐 아니라 “walker 가 \(v_n\)” 을 요구하지만, 이 \(v_n\) 은 flow 종료점이 아니라 terminal fall time \(t_{r+nL}\) 에 읽은 위치, 즉 마지막 낙하의 타겟이다 (그 라운드의 flow 는 \((t_{r+nL},t_{r+nL+1}]\) 에 속해 window 밖). cyclic 스케줄 \(v_1,\ldots,v_n\) 에 조건을 걸면 마지막 낙하가 \(v_n\) 에 떨어지므로 \(v_n\) 도착은 스케줄 조건(확률 \(\mu_{\min}^{nL}\))만으로 달성되고, walk 을 통제할 필요가 없다.

실제로 채울 구멍은 둘이다. 낙하가 아닌 스텝들이 놓는 non-fall 하중 \(\mathbf{b}^{\flat}\) 는 walker 가 밟은 경로에 실려(\(\mathbf{A}^{\flat}_{\amalg}\) 가 branch 의존) 최종 높이차를 흔든다. 그래서 (1) 밀도를 깨끗이 세려면 경로 branch \(\amalg\) 를 하나로 고정하고 그 실현확률에 균일 바닥을 깔아야 하며 — gap 부호가 경로를 정하고, 동률이면 불안정 — (2) 그 wobble 이 target 을 벗어나지 않게 해야 한다. Def 7 – Lem 19 는 이 둘을 처리한다.

비교의 목록화: gaps 와 퇴화 (Def 7, 8 / Lem 13)

Definition 7 (gaps). 4중 인덱스 배열 \(\mathbf{G}=(G_{ijrk})\), \(1\leq i\neq j\leq n\), \(1\leq r\leq nL\), \(1\leq k\leq nL\):

\[ G_{ijrk} \;=\; \begin{cases} +1 & k\leq r \text{ 이고 라운드 } k \text{ 의 낙하가 } v_i \text{ 에 떨어질 때}, \\ -1 & k\leq r \text{ 이고 라운드 } k \text{ 의 낙하가 } v_j \text{ 에 떨어질 때}, \\ \;\;0 & \text{그 외}. \end{cases} \]

시작 높이차를 \(g_{ijr}(s^{\star})=\hbar(v_i,s^{\star})-\hbar(v_j,s^{\star})\) 라 하면 \((i,j,r)\) 의 gap 은 낙하벡터의 affine 함수

\[ \mathbf{b}^{\sharp} \;\longmapsto\; g_{ijr}(s^{\star}) + \boldsymbol{\alpha}_{ijr}^{\top}\mathbf{b}^{\sharp}, \qquad \boldsymbol{\alpha}_{ijr} := (G_{ijr1},\ldots,G_{ijr,nL}) \]

이다. 뜻은 단순하다: cyclic 낙하 스케줄에 non-fall 하중이 전부 0 인 조건에서, \((i,j,r)\) 의 gap 을 실현된 낙하량에서 평가한 값이 정확히 라운드 \(r\) 의 flow 스텝이 보는 높이차 \(\hbar(v_i,t_r)-\hbar(v_j,t_r)\) 이다. “시각 \(r\) 에 \(v_i\) 와 \(v_j\) 중 누가 낮은가”라는 질문 전부를 계수 \(0,\pm 1\) 짜리 일차식들의 목록으로 바꿔 놓은 것이다.

\(n=3\), \(L=2\) 로 창이 \(v_1,v_2,v_3,v_1,v_2,v_3\) 순서로 6개의 낙하를 떨어뜨리는 예에서, \(v_2\) 대 \(v_3\) 비교의 세 slice 를 직접 만들어 보면 (논문 Example 3):

import numpy as np

n, L = 3, 2
schedule = [1, 2, 3, 1, 2, 3]          # 라운드 k 의 낙하가 떨어지는 노드 (cyclic)

def alpha(i, j, r):
    """slice alpha_{ijr}: +1 if k<=r and fall k on v_i, -1 if on v_j, else 0"""
    return np.array([(+1 if schedule[k] == i else -1 if schedule[k] == j else 0)
                     if k < r else 0
                     for k in range(n * L)])

for r in [1, 4, 6]:
    print(f"alpha_(2,3,{r}) = {alpha(2, 3, r)}")
alpha_(2,3,1) = [0 0 0 0 0 0]
alpha_(2,3,4) = [ 0  1 -1  0  0  0]
alpha_(2,3,6) = [ 0  1 -1  0  1 -1]

\[ \boldsymbol{\alpha}_{2,3,1}^{\top} = (0,0,0,0,0,0), \qquad \boldsymbol{\alpha}_{2,3,4}^{\top} = (0,1,-1,0,0,0), \qquad \boldsymbol{\alpha}_{2,3,6}^{\top} = (0,1,-1,0,1,-1). \]

라운드 1 에는 \(v_2, v_3\) 어느 쪽에도 아직 낙하가 없어 전부 0, 라운드 4 시점엔 라운드 2 의 \(v_2\) 낙하와 라운드 3 의 \(v_3\) 낙하만 셈에 들고, 라운드 6 엔 두 노드의 낙하 전부가 든다.

Definition 8 (degeneracy). fiber 위에서 gap 은 자유좌표의 affine 함수로 제한된다:

\[ \mathbf{z}^{\sharp} \;\longmapsto\; g_{ijr}(s^{\star}) + \boldsymbol{\alpha}_{ijr}^{\top}(\mathbf{A}^{\sharp})^{+}\boldsymbol{\hbar}^{\sharp} + \boldsymbol{\alpha}_{ijr}^{\top}\mathbf{Z}^{\sharp}\,\mathbf{z}^{\sharp}. \]

기울기가 \(\boldsymbol{\alpha}_{ijr}^{\top}\mathbf{Z}^{\sharp}\) 이므로, \(\boldsymbol{\alpha}_{ijr}^{\top}\mathbf{Z}^{\sharp}=\mathbf{0}\) 이면 gap 이 fiber 위에서 상수다 — 이를 퇴화(degenerate), 아니면 비퇴화(nondegenerate) 라 부른다. 최종 높이차를 고정한 채 낙하량을 주무르는 자유가 \(\mathbf{z}^{\sharp}\) 인데, 그 자유로 흔들 수 있는 비교인지 묻는 것이다.

\(n=3,L=2\) 에서 \(\mathbf{Z}^{\sharp}\) 의 네 열은 “\(v_1\) 안 두 낙하 사이 이전”, “\(v_2\) 안 이전”, “\(v_3\) 안 이전”, “여섯 낙하 모두에 균등 추가” 를 정규화한 것으로 잡을 수 있고 (논문 Example 1), 위 세 slice 에 대해 \(\boldsymbol{\alpha}^{\top}\mathbf{Z}^{\sharp}\) 를 계산하면 (논문 Example 4):

s2, s6 = 1 / np.sqrt(2), 1 / np.sqrt(6)
Z = np.array([[ s2, 0, 0, s6],       # b_{1,1}
              [ 0, s2, 0, s6],       # b_{2,1}
              [ 0, 0, s2, s6],       # b_{3,1}
              [-s2, 0, 0, s6],       # b_{1,2}
              [ 0,-s2, 0, s6],       # b_{2,2}
              [ 0, 0,-s2, s6]])      # b_{3,2}

for r in [1, 6, 4]:
    print(f"alpha_(2,3,{r})^T Z# = {np.round(alpha(2, 3, r) @ Z, 4)}")
alpha_(2,3,1)^T Z# = [0. 0. 0. 0.]
alpha_(2,3,6)^T Z# = [0. 0. 0. 0.]
alpha_(2,3,4)^T Z# = [ 0.      0.7071 -0.7071  0.    ]

\[ \boldsymbol{\alpha}_{2,3,1}^{\top}\mathbf{Z}^{\sharp} = \mathbf{0}, \qquad \boldsymbol{\alpha}_{2,3,6}^{\top}\mathbf{Z}^{\sharp} = \mathbf{0}, \qquad \boldsymbol{\alpha}_{2,3,4}^{\top}\mathbf{Z}^{\sharp} = \bigl(0,\ \tfrac{1}{\sqrt 2},\ -\tfrac{1}{\sqrt 2},\ 0\bigr). \]

\((2,3,1)\) 과 \((2,3,6)\) 은 퇴화, \((2,3,4)\) 는 비퇴화다: \(v_2\) 안의 이전(둘째 커널 열)이 단위 \(z^{\sharp}_2\) 당 \(1/\sqrt 2\) 씩 그 gap 을 움직인다. \((2,3,6)\) 이 퇴화인 이유는 모든 낙하가 셈에 들면 노드 내 이전은 \(+1\) 과 \(-1\) 로 상쇄되고 균등 추가는 차에서 상쇄되기 때문이다.

Lemma 13 (퇴화 gap 은 chamber 에 고정된다). 퇴화 gap 은 정확히 두 유형뿐이다.

  • (I) Fall-free (\(r<\min(i,j)\)): \(v_i, v_j\) 에 아직 낙하가 없어 낙하량이 식에서 빠지고, gap 은 시작 상태와 non-fall 하중만의 함수다.
  • (II) Final-equality (그 외): 두 노드의 낙하 전부가 셈에 들고, 착지점 \(\mathbf{u}\in\mathsf{U}\) 를 실현하는 임의의 낙하벡터에서

\[ \hbar(v_i,s^{\star})-\hbar(v_j,s^{\star}) + \sum_{\ell=1}^{L} b^{\sharp}_{i,\ell}-\sum_{\ell=1}^{L} b^{\sharp}_{j,\ell} \;=\; u_i-u_j, \qquad |u_i-u_j|\;\geq\; c_{\mathsf{U}} := \min_{k\neq l}\,\inf_{\mathbf{u}'\in\overline{\mathsf{U}}}|u'_k-u'_l| \;>\;0 . \]

증명의 골자. 퇴화 \(\iff \boldsymbol{\alpha}_{ijr}\perp\ker(\mathbf{A}^{\sharp}) \iff \boldsymbol{\alpha}_{ijr}\in\operatorname{Range}((\mathbf{A}^{\sharp})^{\top})\) 인데, row space 는 “노드 그룹별 상수이고 그룹값 합이 0” 인 벡터 전체다 (Lemma 9). \(\boldsymbol{\alpha}_{ijr}\) 의 성분은 \(0,\pm 1\) 뿐이므로 그룹별 상수가 되려면 한 노드의 낙하를 전부 세거나 전혀 안 세거나 둘 중 하나여야 한다 — 전혀 안 세면 (I), 전부 세면 (II). (II) 의 값은 최종 높이차의 성분 차 \(u_i-u_j\) 이고, \(\overline{\mathsf{U}}\) 는 compact 하며 유한 개의 동률 초평면 \(\{u_i=u_j\}\) 와 서로소이므로 \(c_{\mathsf{U}}>0\).

  1. 이 남긴 질문 — 시작부터 동률이면? — 은 뒤의 Lemma 17 (C) 가 처리한다: 그 값은 \((s^{\star},\mathbf{b}^{\flat})\) 만의 함수라 transport 가 건드리지 못하고, \(\mathbf{b}^{\flat}\)-공간을 유한 개 zero-set 으로 나누면 조각마다 부호 상수다 (정확한 0 은 “not strictly lower” 로 결정론 처리).

심지와 길: robust core 와 pick floor (Lem 14 / Def 9, 10 / Lem 15)

Lemma 14 (robust core keeps mass). 비퇴화 gap 이 동률 \(\pm\delta\) 안에 드는 \(\mathbf{z}^{\sharp}\) 집합과, 낙하량이 큐브 경계 \(\delta\) 이내인 집합은 각각 measure \(\leq C_{\mathrm{tie}}\,\delta\), \(\leq C_{\mathrm{bdry}}\,\delta\) 다. 따라서 \((C_{\mathrm{tie}}+C_{\mathrm{bdry}})\delta\leq m_0/2\) 이고 \(\delta\leq c_{\mathsf{U}}\) 이면 robust core

\[ \mathsf{R}_\delta(s^{\star}) := \{\delta\leq b^{\sharp}_j\leq b-\delta\ \forall j\}\;\cap\;\Bigl\{\min_{(i,j,r)\ \text{nondeg.}}\bigl|\hbar(v_i,t_r)-\hbar(v_j,t_r)\bigr|\geq\delta\Bigr\} \]

의 slice measure 는 모든 target \(\mathbf{k}\in\mathsf{K}\), \(s^{\star}\in\mathsf{C}_0\) 에서 \(m_* := m_0/2\) 이상이다.

증명의 골자는 “얇은 것 유한 개”. 비퇴화 gap 은 \(\mathbf{z}^{\sharp}\) 의 affine 함수로 기울기가 \(\mathbf{0}\) 이 아니고, 비퇴화 gap 은 유한 개이므로 기울기 노름의 최솟값 \(\lambda_*>0\) 가 있다. 기울기 방향으로 slice 하면 \(\{|\cdot|\leq\delta\}\) 는 길이 \(\leq 2\delta/\lambda_*\) 인 구간이고, slice 의 지름은 \(b\sqrt{nL}\) 이하이므로 적분해 합치면 \(C_{\mathrm{tie}}\,\delta\). 경계면 \(\{b^{\sharp}_j=0\},\{b^{\sharp}_j=b\}\) 도 같은 방식인데, 해당 affine 함수의 기울기 \((\mathbf{Z}^{\sharp})^{\top}\mathbf{e}_j\) 가 \(\mathbf{0}\) 이 아님은 row-space 로 확인된다: \(\mathbf{e}_j\) 는 낙하 하나에만 실려 있어 노드 그룹 상수가 될 수 없다. 전 slice 의 바닥 \(m_0\) 에서 절단량 \(\leq m_0/2\) 을 빼면 \(m_*=m_0/2\).

Definition 9 (the branch). 창 동안 walker 가 실제 밟는 flow 경로 전체가 branch:

\[ \mathbf{X} := \bigl(X_{t_r+1},\ldots,X_{t_r+m_r}\bigr)_{r=1}^{nL}, \]

값은 \(\amalg\) 로 쓴다. non-fall 하중이 0 이면 실현 가능한 branch 는 \(\mathbf{b}^{\sharp}\) 만이 정하지만, non-fall 하중이 들어오는 순간 사정이 달라진다. 경로 \(v_1\!-\!v_2\!-\!v_3\) 에서 \(v_1\) 낙하 후 높이가 \((1,\,0.99,\,0.999)\) 라 하자. non-fall 하중이 전부 0 이면 가능한 길은 \(v_1\to v_2\) 하나뿐이지만, 0 이 아니면 \(v_1\to v_2\), \(v_1\to v_2\to v_3\), \(v_1\to v_2\to v_1\) 등 \(T_{\max}\) 가 허락하는 만큼 생긴다. \(\amalg\) 는 non-fall 하중과 독립적으로 처방할 수 없다.

Definition 10 (realisable). \(\amalg\) 가 \(\mathbf{b}^{\sharp}\) 에서 실현 가능하다는 것은, 매 이동(라운드 \(r\) 에 \(v_i\) 에서 인접 \(v_j\) 로)이 \(\hbar(v_i,t_r)-\hbar(v_j,t_r)>0\) 을 만족하고, 각 라운드의 마지막 노드에 strictly lower 이웃이 없다는 것.

Lemma 15 (uniform pick floor). core 는 gap 부호 패턴의 level set 인 branch cell \(\mathsf{R}_{\delta,\amalg}\) 들로 쪼개지고, 각 cell 위에서 라운드 threshold \(T^{(r)}_{\max}\) 가 어떻게 뽑히든

\[ \mathbb{P}_{s^{\star}}\bigl(\mathbf{X}=\amalg \bigm| \mathbf{b}^{\sharp}\bigr) \;\geq\; \Bigl(\frac{1}{n}\Bigr)^{2nL(n-1)} \qquad \forall\,\mathbf{b}^{\sharp}\in\mathsf{R}_{\delta,\amalg}. \]

증명을 세 걸음으로. 첫째, cell 위에서 모든 gap 부호는 상수다 — 비퇴화는 \(\delta\)-margin, final-equality 는 \(c_{\mathsf{U}}\) (Lemma 13, \(\delta\leq c_{\mathsf{U}}\)), fall-free 는 시작의 상수 (정확한 동률은 “not strictly lower” 로 결정론). 따라서 실현 가능한 \(\mathbf{X}\) 값 목록이 cell 전체에서 같다. 둘째, threshold 는 결코 발동하지 않는다 — \(\amalg\) 의 매 이동은 높이를 strict 하게 낮추고 라운드 안에서 높이는 안 변하므로 한 라운드에 같은 노드를 두 번 못 방문, \(m_r\leq n-1\). 그런데 threshold 는 \(T^{(r)}_{\max}\geq n\) 을 허용하므로 모든 라운드는 소진으로 끝난다. 셋째, 남은 무작위는 pick 뿐이고 곱으로 바닥이 나온다:

\[ \mathbb{P}(\text{pick } v_j) = \frac{\deg(v_j)}{\sum_{v_k\sim v_i,\ \text{lower}}\deg(v_k)} \;\geq\; \frac{1}{(n-1)(n-1)} \;\geq\; \frac{1}{n^2}, \]

pick 은 창 전체에 많아야 \(nL(n-1)\) 번이므로 곱하면 \((1/n^2)^{nL(n-1)}=(1/n)^{2nL(n-1)}\).

\(n=3\), \(L=2\) 에서 이 바닥이 얼마나 작은 수인지 보면 — 작지만 양수 상수라는 것이 요점이다:

n, L = 3, 2
floor = (1 / n) ** (2 * n * L * (n - 1))
print(f"(1/n)^(2nL(n-1)) = (1/3)^{2*n*L*(n-1)} = {floor:.3e}")
(1/n)^(2nL(n-1)) = (1/3)^24 = 3.541e-12

이사와 조립: transport 와 Doeblin (Def 11 / Lem 16, 17, 18, 19)

Definition 11 (the non-fall map). non-fall 스텝들의 하중 (스텝당 독립 \(\mathrm{Unif}(0,b)\), 길이 \(nLT_{\max}\) 로 zero-padding) 을 \(\mathbf{b}^{\flat}\) 라 하고, 이를 anchored 높이로 보내는 행렬을 \(\mathbf{A}^{\flat}_{\amalg}\) (\((n-1)\times nLT_{\max}\), 성분 \(0,\pm1\)) 라 한다. \(\mathbf{A}^{\sharp}\) 와 달리 branch \(\amalg\) 에 의존한다 — 낙하는 스케줄이 정하지만 non-fall 눈은 walker 가 서 있는 자리에 놓이기 때문이다. 창의 최종 anchored 높이는

\[ \mathbf{u} \;=\; \boldsymbol{\hbar}(s^{\star}) + \mathbf{A}^{\sharp}\mathbf{b}^{\sharp} + \mathbf{A}^{\flat}_{\amalg}\mathbf{b}^{\flat}. \]

\(\varepsilon>0\) 에 대해 \(\mathsf{E}^{\flat}:=[0,\varepsilon]^{nLT_{\max}}\) (모든 non-fall 하중이 \(\varepsilon\) 이하인 사건).

Lemma 16 (wobble). \(\varepsilon\leq b/(8nT_{\max})\) 이면 \(\ell^\infty\)-operator norm 계산으로

\[ \|\mathbf{A}^{\flat}_{\amalg}\mathbf{b}^{\flat}\|_\infty \;\leq\; nLT_{\max}\,\varepsilon \;\leq\; \frac{Lb}{8}, \]

따라서 흔들린 target \(\mathbf{u}-\boldsymbol{\hbar}(s^{\star})-\boldsymbol{\hbar}^{\flat}\) 은 여전히 \(\mathsf{K}\) 안이다 — \(\mathsf{K}\) 의 정의가 반지름 \(Lb/8\) 의 wobble 여유를 미리 품고 있었다.

Lemma 17 (transport stability). 핵심 트릭. non-fall 하중이 target 을 \(\mathbf{A}^{\flat}_{\amalg}\mathbf{b}^{\flat}\) 만큼 밀면, 낙하벡터를 미리 반대로 옮긴다:

\[ \widehat{\mathbf{b}}^{\sharp} := \mathbf{b}^{\sharp} - (\mathbf{A}^{\sharp})^{+}\mathbf{A}^{\flat}_{\amalg}\mathbf{b}^{\flat} \quad\Longrightarrow\quad \mathbf{A}^{\sharp}\widehat{\mathbf{b}}^{\sharp} = \mathbf{u}-\boldsymbol{\hbar}(s^{\star})-\mathbf{A}^{\flat}_{\amalg}\mathbf{b}^{\flat}. \]

검산 목록: (A) 유한 창엔 branch 가 유한 개라 하나의 상수 \(\Gamma<\infty\) 가 모든 이동량을 \(\Gamma\varepsilon\) 으로 덮고, \(\varepsilon \leq \min\{b/(8nT_{\max}),\ \delta/(4\Gamma),\ c_{\mathsf{U}}/(4\Gamma)\}\) 로 고정한다. (B) transport 는 \((\mathbf{A}^{\sharp})^{+}\)-성분만 바꾸므로 자유좌표 \(\mathbf{z}^{\sharp}\) 는 불변. (C) 비퇴화 gap 은 \(\leq\delta/2\) 만 움직여 부호 유지, final-equality 는 \(c_{\mathsf{U}}/2\) 이상 여유 유지, fall-free gap 은 낙하 좌표가 식에 없어 아예 안 움직이고 \((s^{\star},\mathbf{b}^{\flat})\)-조각별 상수로 resolve 된다. (D) 따라서 \(\widehat{\mathbf{b}}^{\sharp}\in[0,b]^{nL}\) 이고 branch \(\amalg\) 유지. (E) slice measure 는 이동 후에도 \(\geq\) 원래 cell 의 measure, \(\mathbf{b}^{\flat}\) 에 균일하게.

Lemma 18 (uniform scaffold). 조건 걸린 이산·smallness 사건들의 확률을 모으면, 임의의 \(s^{\star}\in\mathsf{C}_0\) 에서 균일하게

\[ \underbrace{\mu_{\min}^{nL}}_{\text{cyclic 스케줄}} \times \underbrace{(1/n)^{2nL(n-1)}}_{\text{pick (Lem 15)}} \times \underbrace{(\varepsilon/b)^{nLT_{\max}}}_{\text{non-fall smallness}} \]

이상의 고정 인자만 지불하면 branch 를 고정할 수 있다.

Lemma 19 (Doeblin). 조립. 고정된 \(\mathbf{b}^{\flat}\) 에 대해 favourable fall image 의 Lebesgue 밀도는 change-of-variables (Lemma 10(II)) 로

\[ \rho_{\mathbf{b}^{\flat}}(\mathbf{u}) = \frac{J}{b^{nL}}\sum_{\amalg}\Bigl|\Bigl\{\mathbf{z}^{\sharp} : (\mathbf{A}^{\sharp})^{+}\bigl(\mathbf{u}-\boldsymbol{\hbar}(s^{\star})-\mathbf{A}^{\flat}_{\amalg}\mathbf{b}^{\flat}\bigr)+\mathbf{Z}^{\sharp}\mathbf{z}^{\sharp} \in \mathsf{R}_{\delta,\amalg}\Bigr\}\Bigr|_{\mathrm{Leb}} \;\geq\; c_* := \frac{m_*\,J}{b^{nL}}, \]

transport (Lem 17) 가 shifted target 에서도 slice measure \(\geq m_*\) 를 보장하기 때문이다. discrete scaffold 와 non-fall 적분을 곱하면

\[ (P^{\star})^{nL}(s^{\star}, \mathsf{B}\times\{v_n\}) \;\geq\; \mu_{\min}^{nL}\,(1/n)^{2nL(n-1)}\,(\varepsilon/b)^{nLT_{\max}}\,c_*\,|\mathsf{B}|_{\mathrm{Leb}}, \]

이고 \(\eta := \mu_{\min}^{nL}(1/n)^{2nL(n-1)}(\varepsilon/b)^{nLT_{\max}}c_*|\mathsf{U}|_{\mathrm{Leb}}\), \(\nu := \mathrm{Unif}(\mathsf{U})\otimes\delta_{v_n}\) 로 두면 \((P^{\star})^{nL}(s^{\star},\cdot)\geq\eta\,\nu\) — \(s^{\star}\in\mathsf{C}_0\) 균일. \(\mathsf{C}_0\) 는 small, 따라서 petite 다. \(\blacksquare\)

\(\nu\) 의 “\(\mathrm{Unif}(\mathsf{U})\)” 를 정확히 읽자. 이것은 minorizing measure, 즉 하한이지 실제 전이분포가 아니다 — \((P^{\star})^{nL}(s^{\star},\cdot)\) 는 \(\mathsf{U}\) 위에서 일반적으로 비균등한 어떤 law 이고, 그것이 평평한 바닥 \(\eta\,\mathrm{Unif}(\mathsf{U})\) 위에 얹혀 있을 뿐이다 (“\(\geq\)”, not “\(=\)”). 바닥을 균등(공간적으로 상수)으로 잡을 수 있는 근거는 위 한 줄, \(\rho_{\mathbf{b}^{\flat}}(\mathbf{u})\geq c_*\) 가 모든 \(\mathbf{u}\in\mathsf{U}\) 에서 같은 상수 \(c_*\) 라는 사실이다 — 밀도 하한이 \(\mathbf{u}\) 에 무관하므로 그 눌림을 measure 로 적으면 \(\mathrm{Unif}(\mathsf{U})\) 가 된다 (하한이 \(\mathbf{u}\) 마다 달랐다면 \(\nu\) 도 비균등하게 잡혔을 것이다). 이는 “\(s^{\star}\) 에 대한 균일성”(\(\eta,\nu\) 가 모든 시작점에 공통, small set 의 정의)과는 층위가 다른 별개의 균일성임에 유의한다. (재생 구성에서는 \(\eta\)-사건에 조건 걸면 높이차가 \(\nu\) 에서, 즉 \(\mathsf{U}\) 위 균등으로 뽑히지만, 그것은 이 밀도-하한 균일성의 귀결이다.)

바닥 \(\eta\) 의 크기 감각을 위해 \(n=3\), \(L=2\), \(T_{\max}=3\), \(\mu_{\min}=1/3\), \(\varepsilon/b=1/100\) 로 각 인자를 찍어 보면:

mu_min, Tmax, eps_over_b = 1/3, 3, 1/100
f1 = mu_min ** (n * L)                       # cyclic 스케줄
f2 = (1 / n) ** (2 * n * L * (n - 1))        # pick floor
f3 = eps_over_b ** (n * L * Tmax)            # non-fall smallness
print(f"schedule  {f1:.2e}\npick      {f2:.2e}\nsmallness {f3:.2e}")
print(f"discrete scaffold product = {f1 * f2 * f3:.2e}")
schedule  1.37e-03
pick      3.54e-12
smallness 1.00e-36
discrete scaffold product = 4.86e-51

천문학적으로 작다. 그러나 Doeblin 논증이 요구하는 것은 크기가 아니라 \(s^{\star}\)-균일한 양수성 뿐이고, 위 곱의 어느 인자에도 \(s^{\star}\) 가 등장하지 않는다는 것이 전부다.

마지막으로 급소 하나. 이 전체가 Snowfall A (낙하 하중이 연속 균등분포) 에 기댄다. 낙하 하나하나가 Lebesgue 밀도를 가져야 \(c_*>0\) 가 산다. 한 라운드의 하중이 전부 같은 상수인 Snowfall B 에서는 \(nL\) 개 낙하 좌표가 라운드당 스칼라 하나로 붕괴하여 fall image 가 \(\mathbb{R}^{n-1}\) 의 저차원(Lebesgue-null) 집합에 갇히고, 밀도 바닥이 존재하지 않는다.
