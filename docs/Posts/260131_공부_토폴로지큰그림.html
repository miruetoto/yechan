공부 ▷ 토폴로지 큰그림

Author

신록예찬

Published

January 31, 2026

- 정의의 다이어그램 - \(X\) → 위상 → 열린집합 - 열린집합 → 근방, 내점, 내부, 닫힌집합 - 닫힌집합 → 폐포 | 근방 → 극한점 → 폐포 - 내부 + 폐포 → 경계 - 폐포 → 조밀집합 - 극한점 → 고립점 - \(X\) → 부분기저 → 기저 → 위상 | \(X\) → 위상 → 열린집합 → 기저 - 열린집합 → 연속함수 → 동형사상 - 열린집합 → 열린덮개 → 컴팩트 - 근방 + 컴팩트 → 국소컴팩트 - 열린집합 → 부분공간 - \(X\) → 거리함수 → 열린공 → 기저 → 위상 - 거리함수 → 코시수열 → 완비성 - 열린집합 → 분리 → 연결 - 열린집합, 동치관계 → 상위상 - 연속함수 → 경로 → 경로연결 - 기저 + 근방 → 가산성 공리 - 근방 → 수열의 수렴 - 근방 → \(T_0\), \(T_1\), \(T_2\) (Hausdorff), \(T_3\) (정칙), \(T_4\) (정규) - 열린집합 + 사영함수 → 곱위상 - 연속함수 → 호모토피

- 성질 - 내점들의 모임 = 내부 - (\(A\)의 폐포 =\(A\)) \(\Leftrightarrow\) \(A\)는 닫힌집합 - (\(A\)의 내부 = \(A\)) \(\Leftrightarrow\) \(A\)는 열린집합 - Hausdorff + 제2가산 + 국소유클리드 → 위상다양체 - 위상다양체 + 좌표변환 → 미분다양체 - 연속함수 → 단체 (simplex) → 단체복체 → 체인복체 → 호몰로지군 \(H_n(X)\)

- 어떠한 집합 \(X\)가 있을때 \(X\)의 부분집합들의 모임 \({\cal T}\)가 어떠한 조건을 만족한다면 \({\cal T}\)를 \(X\)에 대한 위상이라고 한다. 위상을 정의하는 일은 매우 중요한데, 위상을 정의해야 열린집합을 정의할 수 있고, 열린집합을 정의해야 근방을 정의할 수 있고, 근방을 정의해야

- 위상 \({\cal T}\)와는 별개로 집합 \(X\)의 임의의 두 원소에 대한 거리 \(d\)를 정의할 수 있다.

- 집합 \(X\)에서 거리\(d\)를 정의할 수 있다면 \(d\)를 이용하여 ball을 만들 수 있다. (샴 Chap8 참고할것)

- 거리공간 = (집합, 거리함수) - 거리함수가 가져야할 조건 1,2,3은 거리가 가지는 본질적인 속성, 즉 거리의 헌법이라고 비유 할 수 있음. 따라서 어떠한 함수가 거리함수의 조건 1,2,3을 만족하지 않는다면 그 함수는 거리가 가지는 본질적 속성이 없음을 의미함. - 거리의 본질적 속성1: A와 B사이의 거리는 B와 A사이의 거리와 같아야한다. - 거리의 본질적 속성2: 자기자신과의 거리는 0이어야 한다. - 거리의 본질적 속성3: 두 점 사이의 거리는 두 점 사이의 가장 짧은 경로임을 의미해야 한다. - 머신러닝에서의 모델링은, 모델들의 집합에서 정답과 가장 가까운 하나의 모델을 고르는 작업이라 해석해 볼 수 있다. 즉 \(y=f(x)+\epsilon\) 일때 \(d(f,g)\)를 최소로 만드는 \(g\)를 고르는 과정이라 볼 수 있다. 여기에서의 \(d\)는 손실함수의 느낌. - 거리의 동치성: 동치인 거리들은 수렴성, 열린집합등의 위상적 성질을 완벽하게 공유한다. 유클리드 거리와 택시거리는 \(\mathbb{R}^n\)에서는 동치이지만 무한차원에서는 항상 성립하지 않음.

- 위상적성질 - 내부, 경계, 폐포, 조밀성

- 거리공간의 좋은성질들 - 완비성: 공간에 구멍이 없고 꽉찬공간. - 코시수열이 수렴하는 공간 (코시수열을 정의하려면 거리가 정의되어야하니까, 결국 완비성은 거리공간에서만 따질 수 있는 성질임) - 유리수집합은 완비하지 않음.
- 점묘화는 완비가 아님. - 무한차원 유클리드 공간은 완비공간임. - compact: 퍼져나가지 않는 공간. - \((0,\infty)\) 이런건 퍼져나가는 공간임. - compact에서 정의한 연속함수는 항상 최대값과 최소값을 가짐.

- 함수공간 (=모델공간=분포공간) - 아르첼라-아스콜리정리: 함수공간에서의 compact 판단도구. - 집합의 원소가 도형이라면? –> 도형사이의 거리를 재야함 –> 하우스도로프거리. (한 집합에 다른집합까지 가장 먼 거리, 각 집합의 불만대장 2개를 찾아서 맥스를 취하는 방식임)
