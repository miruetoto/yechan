03wk — 경사하강법, 회귀분석 도입

1. 1차원 경사하강법

함수 \(f(x) = (x - 1)^2 + 0.5\) 의 최소값을 경사하강법으로 찾는다고 하자.

(1) \(f(x)\) 의 최소값을 갖는 \(x_{sol}\) 의 (이론적) 값과 그 때의 \(f(x_{sol})\) 값으로 옳은 것은?

① \(x_{sol} = 0,\ f(x_{sol}) = 1.5\)
② \(x_{sol} = 1,\ f(x_{sol}) = 0.5\)
③ \(x_{sol} = 1,\ f(x_{sol}) = 0\)
④ \(x_{sol} = 0.5,\ f(x_{sol}) = 0.75\)

(2) \(x_{sol} = 3\) 에서 시작하여 학습률 \(\alpha = 0.5\) 로 한 번 업데이트한 후의 값은? (단, \(f'(x) = 2(x-1)\))

① \(0\)
② \(1\)
③ \(2\)
④ \(-1\)

(3) \(x_{sol} = 3\) 에서 학습률 \(\alpha = 0.1\) 로 충분히 많은 epoch 진행하면 \(x_{sol}\) 가 수렴하는 값은?

① \(1\)
② \(0\)
③ \(3\)
④ \(\infty\)

(4) 학습률 \(\alpha\) 를 지나치게 크게 (예: \(\alpha = 5\)) 잡으면 어떤 일이 발생할 가능성이 가장 큰가?

① 항상 더 빨리 수렴
② 진동만 하거나 발산
③ 항상 정확히 수렴
④ \(\alpha\) 와 무관하게 늘 같은 결과

(5) 미분 공식 \(f'(x)\) 를 모를 때 \(f'(x_{sol})\) 을 근사하는 식으로 옳은 것은?

① \(\frac{f(x_{sol} + h) - f(x_{sol})}{h}\) (단, \(h\) 가 매우 작음)
② \(f(x_{sol} + h) - f(x_{sol})\)
③ \(f(x_{sol}) + f(x_{sol} + h)\)
④ \(\frac{f(x_{sol} + h) + f(x_{sol})}{h}\)

2. 2차원 최적화 알고리즘

다음 두 알고리즘을 고려하자.

  • 알고리즘1: 현재 점 주변의 격자점들을 모두 조사하여 가장 작은 함수값을 갖는 점으로 이동
  • 알고리즘2: 각 좌표축 방향으로만 조사하여 이동방향을 결정 (편미분 기반)

(1) 차원 \(d\) 에서 알고리즘1 은 \(3^d\) 개, 알고리즘2 는 \(2d + 1\) 개의 점을 조사한다. \(d = 4\) 일 때 두 알고리즘의 계산량은?

① 알고리즘1: \(9\), 알고리즘2: \(5\)
② 알고리즘1: \(81\), 알고리즘2: \(9\)
③ 알고리즘1: \(12\), 알고리즘2: \(4\)
④ 알고리즘1: \(64\), 알고리즘2: \(16\)

(2) 다음 알고리즘은 진정한 (동시 업데이트) 경사하강법인가?

for dummy in range(5):
    x_grad = (f(x_sol + 0.01, y_sol) - f(x_sol, y_sol)) / 0.01
    x_sol = x_sol - alpha * x_grad
    y_grad = (f(x_sol, y_sol + 0.01) - f(x_sol, y_sol)) / 0.01
    y_sol = y_sol - alpha * y_grad

① 진정한 경사하강법이다 — 그래디언트의 반대방향으로 갔으므로
② 아니다 — \(x\) 를 먼저 업데이트한 후 변경된 \(x\) 값을 이용하여 \(y\) 의 그래디언트를 구하고 있음 (동시 업데이트가 아님)
③ 진정한 경사하강법이다 — for 문으로 반복했기 때문
④ 아니다 — 미분 근사식이 잘못됨

(3) 알고리즘1 보다 알고리즘2 를 더 사용하는 이유로 가장 적절한 것은?

① 알고리즘2 가 정확도가 항상 더 높기 때문
② 알고리즘1 은 차원이 높아질수록 조사할 점의 개수가 기하급수적으로 (\(3^d\)) 증가하기 때문
③ 알고리즘1 은 항상 발산하기 때문
④ 알고리즘2 는 미분이 필요없기 때문

(4) 2차원 함수 \(f(x, y)\) 의 그래디언트 \(\nabla f(x_{sol}, y_{sol})\) 의 의미로 옳은 것은?

① \(f\) 의 최댓값을 갖는 점의 좌표를 나타내는 벡터
② 첫 번째 원소가 \(\frac{\partial f}{\partial x}\), 두 번째 원소가 \(\frac{\partial f}{\partial y}\) 인 벡터
③ \(f(x, y)\) 의 평균값
④ \(x\) 와 \(y\) 의 평균

3. 회귀분석 도입 — 김연구원의 광고비/매출 분석

마케팅 회사의 김연구원씨는 (광고비 \(x\), 매출 \(y\)) 자료 100일치를 모았다. 산점도를 그려보니 양의 상관관계가 보였다. 김연구원씨는 본질적인 추세를 추정하여 미래의 매출을 예측하고 싶다.

(1) 김연구원씨가 “이 자료는 어떤 모형에서 나왔다고 가정하자” 라고 의심한다고 하자. 가장 자연스러운 모형 가정은?

① \(y_i \overset{i.i.d.}{\sim} N(0, 1)\)
② \(y_i = \beta_0 + \beta_1 x_i + \epsilon_i, \quad \epsilon_i \overset{i.i.d.}{\sim} N(0, \sigma^2)\)
③ \(y_i = \beta_0 \cdot \beta_1^{x_i}\) (지수)
④ \(y_i = \beta_0 / x_i\)

(2) 김연구원씨는 두 후보 직선 시도1 \([\beta_0, \beta_1] = [10, 3]\) 와 시도2 \([\beta_0, \beta_1] = [9, 3]\) 중 어느 것이 더 좋은지 직관으로 판단하기 어려웠다. 이 비교를 객관화하는 가장 적절한 도구는?

① 데이터를 더 많이 수집한다
② loss (손실함수) 를 도입하여 “적당함” 을 수치화한다
③ 시도3 을 추가한다
④ \(\beta_1\) 만 본다

(3) 단순회귀모형 \(y_i = \beta_0 + \beta_1 x_i + \epsilon_i\) 에서 사용되는 손실함수 SSE 의 수식으로 옳은 것은?

① \(\sum_{i=1}^{n}|y_i - (\beta_0 + \beta_1 x_i)|\)
② \(\sum_{i=1}^{n}(y_i - (\beta_0 + \beta_1 x_i))^2\)
③ \(\sum_{i=1}^{n}(y_i - \beta_0 - \beta_1)^2\)
④ \(\frac{1}{n}\sum_{i=1}^{n}(y_i - \beta_0)^2\)

(4) 김연구원씨가 원래 후보 시도1 \([\beta_0, \beta_1] = [10, 3]\) 에 대해 SSE 를 계산해 보니 시도2 \([\beta_0, \beta_1] = [9, 3]\) 보다 작았다. 이 결과의 해석으로 옳은 것은?

① 시도1 이 시도2 보다 데이터에 더 잘 맞는 직선이다
② 시도2 가 시도1 보다 데이터에 더 잘 맞는 직선이다
③ 두 직선은 데이터에 똑같이 잘 맞는다
④ SSE 비교로는 둘을 비교할 수 없다

(5) 단순회귀의 손실함수 \(l(\beta_0, \beta_1) = \sum (y_i - (\beta_0 + \beta_1 x_i))^2\) 는 무엇의 함수로 볼 수 있는가?

① \(x_i, y_i\) 의 함수
② \(\beta_0, \beta_1\) 의 함수
③ \(i\) 의 함수
④ \(n\) 의 함수

(6) 회귀분석 문제를 경사하강법으로 풀 수 있는 핵심 이유는?

① 회귀분석 문제는 아래로 볼록한 손실함수 \(l(\beta_0, \beta_1)\) 을 최소화하는 최적화 문제로 바꿀 수 있기 때문
② 회귀분석은 항상 \(\beta_0 = 0, \beta_1 = 1\) 이 답이기 때문
③ 손실함수가 항상 0이기 때문
④ \(y_i\) 가 정규분포를 따르기 때문

04wk — 회귀 (풀이 1~10), 미분, net/optimizer

1. 파이토치 미분의 함정

다음 코드는 \(f(x) = x^2\) 에서 \(f'(3)\) 과 \(f'(5)\) 를 차례로 계산하려는 시도이다.

def f(x):
    return x**2

x = torch.tensor(3.0, requires_grad=True)
y = x**2
y.backward()
print(x.grad)         # 출력 (가)

x.data = torch.tensor(5.0)
y = x**2
y.backward()
print(x.grad)         # 출력 (나)

(1) 출력 (가) 의 값으로 옳은 것은?

① \(0\)
② \(3\)
③ \(6\)
④ \(9\)

(2) 위 코드에서 출력 (나) 가 \(f'(5) = 10\) 으로 깔끔하게 나오지 않는 이유로 가장 적절한 것은?

① requires_grad=True 가 빠졌기 때문
② 두 번째 backward() 전에 x.grad = None 으로 초기화하지 않아서 gradient 가 누적됨
③ f 함수를 정의했지만 사용하지 않았기 때문
④ x.data 를 직접 바꾸면 안 되기 때문

(3) 위 코드의 출력 (나) 의 값은?

① \(10\) (= \(f'(5)\))
② \(16\) (= \(f'(3) + f'(5) = 6 + 10\))
③ \(25\)
④ \(0\)

(4) loss.backward() 의 역할로 가장 적절한 것은?

① loss 값을 출력한다
② 가중치를 업데이트한다
③ 학습 가능한 파라미터에 대한 gradient 를 계산하여 .grad 에 저장한다
④ loss 함수를 정의한다

(5) 다음 두 코드의 효과 비교로 옳은 것은?

optimizer.zero_grad()       # 코드 A
What.grad = None            # 코드 B (단, What 이 학습 파라미터)

① 코드 A 는 가중치를 0으로 만들고 코드 B 는 그렇지 않다
② 코드 A 와 코드 B 모두 gradient 를 0 (또는 None) 으로 초기화하는 동일한 목적이며, optimizer 사용 여부에 따라 적절히 선택
③ 코드 A 는 loss 를 0으로 만들고 코드 B 는 그렇지 않다
④ 두 코드는 정반대의 효과

어느 실험에서 「입력 \(x\) 와 출력 \(y\) 가 사실은 무관 (참모델은 \(f(x) = 0\))」 한 데이터 100개를 만들어 학습/평가로 80/20 분할하였다.

(1) 학습 후 학습 데이터 (X, Y) 의 두 손실값 비교로 옳은 부등호는? (A = loss_fn(net(X), Y), B = loss_fn(net(X)*0, Y))

① \(A < B\) — 학습 데이터에서는 학습된 net 이 0예측보다 더 잘 맞춤 (노이즈까지 외움)
② \(A > B\)
③ \(A = B\)
④ 부등호 결정 불가

(2) 학습 후 평가 데이터 (XX, YY) 의 두 손실값 비교로 옳은 부등호는? (C = loss_fn(net(XX), YY), D = loss_fn(net(XX)*0, YY))

① \(C < D\)
② \(C > D\) — 오버피팅된 net 이 평가 데이터에서는 0으로 예측하는 것보다 못함
③ \(C = D\)
④ 부등호 결정 불가

(3) (1), (2) 의 결과로부터 도출되는 결론으로 옳은 것은?

① net 은 학습 데이터에서는 0예측보다 잘 맞추지만, 평가 데이터에서는 0예측보다 못 맞춘다 (오버피팅의 전형)
② net 은 학습/평가 데이터 모두에서 0예측보다 잘 맞춘다 — 시벤코 정리가 unseen data 까지 보장하기 때문
③ net 의 표현력이 부족해서 평가 데이터에서 못 맞춘다
④ 드랍아웃을 추가하면 net 의 평가 손실이 0예측 손실보다 작아짐을 보장한다

(4) 위 오버피팅의 「근본적 원인」 으로 가장 적절한 것은?

① 노드 수 \(m = 512\) 가 너무 적어서 표현력이 부족했기 때문
② 노드 수 \(m = 512\) 가 너무 많아서 표현력이 과해 노이즈까지 적합했기 때문
③ Optimizer (Adam) 선택이 잘못되었기 때문
④ 학습 epoch 수가 너무 부족했기 때문
