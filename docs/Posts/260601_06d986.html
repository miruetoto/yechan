연구 ▷ HST ▷ Chamber reference measure — 왜 박스 전체가 아니라 방 하나인가?

Author

미소

Published

June 1, 2026

(스튜디오. 화면에는 작은 사각형 하나가 떠 있다. 사각형 안에는 대각선 몇 개가 그어져 있고, H 는 그 선들을 피해 작은 색칠된 영역 하나를 동그라미 친다.)

H. 오늘은 에이 문서의 이 문장 하나를 풀어볼게요. Chamber reference measure. 말은 무섭지만, 하고 싶은 말은 꽤 단순해요.

G. 이름부터 어렵네요. chamber 는 방이고, reference measure 는 기준측도?

H. 맞아요. 정확히는 minorisation, 즉 small set 증명에서 쓰는 공통 목표분포예요. 어떤 초기상태에서 출발하든, 충분히 정해진 길이의 round window 뒤에는 transition kernel 이 같은 기준측도 \(\nu_{\mathrm{skel}}\) 를 일정 비율 이상 포함해야 해요.

\[ P^L(s,\cdot) \;\ge\; \eta\,\nu_{\mathrm{skel}}(\cdot) \qquad (s\in C_0) \]

G. 그러면 그냥 가능한 최종 높이 차이 영역 전체에 균등분포를 잡으면 안 되나요?

H. 그게 바로 이 문단의 핵심이에요. 전체 박스 \(\mathcal O^\dagger\) 에 균등분포를 잡으면 안 됩니다. 이유는 박스 안을 가르는 equality hyperplane 들 때문이에요.

에피소드 1: 왜 전체 박스가 깨지는가

H. skeleton state 는 대략 이렇게 봐요. 전체 높이에서 기준 높이를 하나 빼서 anchored full height 로 만들고,

\[ \widetilde u_1 := 0,\qquad \widetilde u_k := u_{k-1}\quad (k\ge 2) \]

최종 높이 비교가

\[ \widetilde u_i = \widetilde u_j \]

가 되는 곳들이 생깁니다. 이게 equality hyperplane 이에요.

G. 높이가 딱 같은 경계면이라는 뜻이군요.

H. 네. HST flow rule 은 높이 비교로 움직임이 갈립니다. 그러니까 최종 목표가 이런 경계면 위에 있으면 문제가 생겨요. 아주 조금만 흔들려도 “어느 쪽이 낮은가”가 바뀌고, fall trajectory 가 그 경계 위의 목표를 안정적으로 만들기 어렵습니다.

import numpy as np
import matplotlib.pyplot as plt

plt.style.use("seaborn-v0_8-whitegrid")
plt.rcParams.update({
    "font.family": "serif",
    "font.size": 10,
    "axes.titlesize": 12,
    "axes.labelsize": 10,
})

fig, ax = plt.subplots(figsize=(6.8, 4.4))

# Normalized two-dimensional slice of O^\dagger.
x = np.linspace(0, 1, 400)
ax.fill_between(x, 0, 1, color="#f4f7fb", alpha=1.0)

# Equality hyperplanes in the anchored coordinates:
# \tilde u_1 = \tilde u_2 -> u_1 = 0,
# \tilde u_1 = \tilde u_3 -> u_2 = 0,
# \tilde u_2 = \tilde u_3 -> u_1 = u_2.
ax.plot([0, 0], [0, 1], color="#b94a48", lw=2.0, alpha=0.95)
ax.plot([0, 1], [0, 0], color="#b94a48", lw=2.0, alpha=0.95)
ax.plot(x, x, color="#b94a48", lw=2.0, alpha=0.95)

# A chamber away from all equality hyperplanes.
center = np.array([0.25, 0.56])
theta = np.linspace(0, 2*np.pi, 240)
rx, ry = 0.075, 0.055
ux = center[0] + rx*np.cos(theta)
uy = center[1] + ry*np.sin(theta)
ax.fill(ux, uy, color="#3b82f6", alpha=0.28, edgecolor="#1d4ed8", lw=2)
ax.scatter([center[0]], [center[1]], s=28, color="#1d4ed8", zorder=3)

ax.text(0.08, 0.05, r"$\widetilde u_1=\widetilde u_2$", color="#8a2f2e")
ax.text(0.53, 0.50, r"$\widetilde u_2=\widetilde u_3$", color="#8a2f2e", rotation=32)
ax.text(0.29, 0.64, r"chamber $U$", color="#1d4ed8", weight="bold")
ax.text(0.58, 0.10, r"full box $\mathcal{O}^{\dagger}$", color="#334155")

ax.set_xlim(-0.04, 1.02)
ax.set_ylim(-0.04, 1.02)
ax.set_aspect("equal")
ax.set_xlabel(r"$u_1=\widetilde u_2$")
ax.set_ylabel(r"$u_2=\widetilde u_3$")
ax.set_title("Why not use the whole box?")
plt.tight_layout()
plt.show()

G. 그림으로 보니까 박스 전체에는 빨간 선들이 지나가네요. 그러면 uniform on full box 는 그 선 근처도 계속 목표로 삼는 거고요.

H. 맞아요. 그런데 minorisation 은 “한두 점 빼고 대충”이 아니에요. 기준측도에 들어간 target 을 일정 확률 하한으로 만들어야 합니다. 경계면 위나 경계면에 아주 가까운 target 은 branch 가 불안정해져서 uniform lower bound 를 잡기 불편해요.

에피소드 2: 그래서 chamber 하나를 고정한다

H. 그래서 문서에서는 박스 전체가 아니라, equality hyperplane 을 전부 피하는 열린 방 하나를 고정합니다.

\[ U \Subset \mathcal O^\dagger, \qquad \inf_{u\in U}\min_{i\ne j} \left|\widetilde u_i-\widetilde u_j\right| \ge \kappa_U > 0. \]

G. 이 조건은 “\(U\) 안에서는 어떤 두 높이도 너무 가까워지지 않는다”는 뜻이죠?

H. 정확해요. \(\kappa_U\) 는 안전거리예요. \(U\) 안으로 들어간 target 은 모든 최종 높이 비교가 확실합니다. 어느 노드가 더 낮은지, 어느 비교가 equality 에 걸리는지 애매하지 않아요.

G. 그러면 proof 에서는 \(U\) 안의 목표만 만들면 되는 건가요?

H. 네. small set minorisation 은 reference measure 하나만 있으면 됩니다. 전체 reachable set 을 덮을 필요가 없어요. 작지만 양의 부피를 가진 방 하나를 잡고, 모든 시작점에서 그 방으로 갈 수 있음을 균일하게 보이면 충분해요.

에피소드 3: 기준측도는 무엇인가

H. 최종적으로 잡는 기준측도는 이겁니다.

\[ \nu_{\mathrm{skel}} := \mathrm{Unif}(U)\otimes \delta_{v_n} \qquad \text{on }\bar{\mathcal X}=\mathbb R^{n-1}\times V. \]

G. 두 조각으로 나뉘네요. \(\mathrm{Unif}(U)\) 는 높이 차이 좌표의 목표분포이고, \(\delta_{v_n}\) 은 walker 위치를 마지막 노드 \(v_n\) 으로 고정한다는 뜻?

H. 맞습니다. skeleton state 는 “높이 차이 좌표 + 현재 위치”로 되어 있으니까, 기준측도도 두 성분을 가져요. 높이 차이는 chamber \(U\) 안에서 균등하게 뿌리고, 위치는 \(v_n\) 에 붙여 둡니다.

G. 왜 위치까지 고정하나요?

H. minorisation 에서는 reference measure 가 하나로 고정되어야 하니까요. 위치까지 흔들리게 두면 증명해야 할 target 이 더 커집니다. 반대로 마지막 위치를 \(v_n\) 으로 고정하면, “정해진 fall schedule 과 정해진 마지막 위치”를 만들면 되어서 증명 구조가 깔끔해집니다.

에피소드 4: 문단의 한 줄 번역

G. 그러면 원문 문단을 한 문장으로 번역하면요?

H. 이렇게요.

small set 증명에 필요한 것은 전체 박스에 대한 균등분포가 아니라, 모든 초기상태에서 공통으로 도달시킬 수 있는 고정된 양의 기준측도다. 전체 박스는 equality hyperplane 때문에 경계 target 이 불안정하므로, 높이들이 서로 확실히 떨어져 있는 작은 chamber \(U\) 를 잡고 그 위의 균등분포를 기준측도로 쓴다.

G. 즉 chamber 는 “증명을 약하게 만드는 꼼수”가 아니라, minorisation 이 요구하는 공통 target 을 안정적으로 만들기 위한 장치군요.

H. 네. 더 짧게 말하면:

\[ \text{전체 박스는 너무 욕심이고, chamber 하나면 small set 에 충분하다.} \]

이 문단이 하는 일은 딱 그겁니다. 경계면을 피해서, 하나의 고정 reference measure 를 만든다.
