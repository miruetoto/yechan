Setup

\(\mathcal{G} = (V, \mathbf{E}, \mathbf{W})\)을 연결 가중 그래프, \(n = |V|\), \(\mathbf{y} = (y(v_1), \ldots, y(v_n))^\top\)을 초기 신호, \(b > 0, T_{\max} \geq 1\)을 알고리즘 파라미터라 하자. \(\{X_t\}\)를 Algorithm 1(Heavy-Snow Process)로 생성된 walker 위치 과정, \(\boldsymbol{\mu}_0 \propto \deg\)를 재시작 분포, \(\mu_{\min} := \min_i \mu_0(v_i) > 0\)으로 놓는다.

Block 시각. \(M_0 := 0\), \(M_k := \inf\{t > M_{k-1} : Z_t = T_{\max}\}\) (\(k \geq 1\)). Algorithm 1에 의해 \(1 \leq M_{k+1} - M_k \leq T_{\max} + 1\).

재생 시각, 에포크, 에포크 길이.

\[R_k := M_k + 1, \qquad \mathcal{E}_k := [R_k, R_{k+1}), \qquad \xi_k := R_{k+1} - R_k\]

\(\xi_k \in \{1, 2, \ldots, T_{\max}+1\}\).

재생 성질 (알고리즘 정의에 의한).

\[\Pr\big(X_{R_k} = j \,\big|\, \mathcal{F}_{M_k}\big) = \mu_0(j) \qquad \forall\, k \geq 0,\, j \in V. \tag{R}\]

Lemma 1 (Walker 통계의 i.i.d. 재생)

\(f: V \to \mathbb{R}\)를 bounded 함수라 하자. 에포크별 보상

\[R_k^{(f)} \;:=\; \sum_{t \in \mathcal{E}_k} f(X_t)\]

에 대해, 수열 \(\{(\xi_k,\, R_k^{(f)})\}_{k \geq 0}\)은 i.i.d.이다.

증명. \(\mathbf{y} \bmod b\)의 fractional part에 의해 결정되는 유효 상태공간 내에서 \(\boldsymbol{\delta}(t) - \boldsymbol{\delta}(0) \in b\mathbb{Z}^{n-1}\)이므로, 쌍별 비교 \(\mathbb{1}(h(v_i, t) \geq h(v_j, t)) = \mathbb{1}(\delta_i(t) \geq \delta_j(t))\)의 패턴은 \(\boldsymbol{\delta}(t) \bmod b = \boldsymbol{\delta}(0) \bmod b\)에만 의존하고 \(k\)에 독립이다.

시점 \(R_k\)에서의 walker-관점 전이는:

  1. \(X_{R_k} \sim \boldsymbol{\mu}_0\) — \((\mathrm{R})\)에 의해 이전 에포크들과 독립
  2. 이후 \(\mathcal{E}_k\) 내부 (\(\leq T_{\max}+1\) 스텝) walker 궤적은 \((\boldsymbol{\delta}(R_k) \bmod b, X_{R_k}, Z_{R_k} = 0)\)에서 출발하는 유한 길이의 random walk. 전이 결정이 \(\boldsymbol{\delta} \bmod b\)와 walker 위치에만 의존하므로, \(\boldsymbol{\delta}(R_k) \bmod b\)가 \(k\)에 독립이라는 점과 결합하여 walker 궤적 \((X_{R_k}, \ldots, X_{R_{k+1}-1})\)의 joint distribution은 \(k\)에 독립이다.

\(\xi_k\)와 \(R_k^{(f)}\) 둘 다 walker 궤적의 결정론적 함수이므로 \((\xi_k, R_k^{(f)})\)의 분포가 \(k\)에 독립. 또한 \((\mathrm{R})\)이 \(\mathcal{F}_{M_k}\)-조건부 독립성을 주므로 이전 \((\xi_j, R_j^{(f)})\), \(j < k\)에 대해서도 독립. 따라서 i.i.d. \(\square\)

Proposition 1 (Walker Marginal의 지수 Mixing)

\(\boldsymbol{\pi}_X\)를 walker 위치의 정상분포(존재는 Theorem 1 참조)라 하자. 임의의 초기분포 \(\boldsymbol{\nu}\)에 대해:

\[\big\|\mathcal{L}(X_t \mid X_0 \sim \boldsymbol{\nu}) - \boldsymbol{\pi}_X\big\|_{TV} \;\leq\; \big(1 - \mu_{\min}\big)^{\lfloor t / (T_{\max}+1)\rfloor} \qquad (t \geq 0).\]

증명. Coupling 논법. 두 독립 copy \(\{X_t\}, \{X_t'\}\)를 같은 source of randomness 하에 다음과 같이 결합한다:

  • Flow/block 판정과 flow 시 이웃 선택은 두 copy에서 독립적으로 수행.
  • \((\mathrm{R})\)에 해당하는 매 \(\boldsymbol{\mu}_0\) 재시작 시점에서는 동일 난수 \(U \sim \boldsymbol{\mu}_0\)를 공유: \(X_{R_k} = X'_{R'_k} = V^{-1}(U)\) (각 copy의 재시작이 동시가 아닐 수 있음에 주의).

두 copy가 최초의 공통 재시작 시점 이후 동일한 궤적을 따른다 (동일한 \(\boldsymbol{\delta} \bmod b\)에서 동일한 랜덤성 소비). 따라서 coupling time \(T^\ast\)는 “두 copy 모두가 같은 \([t, t + T_{\max}+1)\) 구간 내에서 block을 맞아 공통 재시작을 공유하는 최초 시점”으로 bounded.

한 copy가 길이 \(T_{\max}+1\)의 구간 내에서 적어도 한 번 block을 맞을 확률 \(\geq 1\) (정의상 모든 에포크는 이 길이 이하). 두 copy 동시에 같은 block 이벤트에 정렬될 확률을 각 길이-\((T_{\max}+1)\) 구간마다 \(\mu_{\min}\) 이상으로 하한할 수 있다 (\(\boldsymbol{\mu}_0\)에서의 단일 노드 뽑기 확률 하한). 따라서 각 구간마다 coupling 실패 확률 \(\leq 1 - \mu_{\min}\).

\(\lfloor t/(T_{\max}+1) \rfloor\)개의 disjoint 구간을 연쇄적으로 적용:

\[\Pr(T^\ast > t) \;\leq\; (1 - \mu_{\min})^{\lfloor t/(T_{\max}+1)\rfloor}\]

Coupling inequality에 의해 \(\|\mathcal{L}(X_t) - \boldsymbol{\pi}_X\|_{TV} \leq \Pr(T^\ast > t)\). \(\square\)

Theorem 1 (Renewal SLLN + CLT for Walker Statistics)

\(f: V \to \mathbb{R}\)를 bounded라 하고 \(\mathbb{E}[\xi_1] < \infty\) (Setup의 상한 \(\xi_1 \leq T_{\max}+1\)에 의해 자동 성립)라 하자. 그러면

\[\bar f_\pi \;:=\; \frac{\mathbb{E}[R_1^{(f)}]}{\mathbb{E}[\xi_1]}\]

이 존재하고,

\[\frac{1}{t}\sum_{s=1}^{t} f(X_s) \;\xrightarrow{a.s.}\; \bar f_\pi \qquad (t \to \infty). \tag{SLLN}\]

또한 \(\mathrm{Var}[R_1^{(f)} - \bar f_\pi\, \xi_1] < \infty\)이면

\[\sqrt{t}\left(\frac{1}{t}\sum_{s=1}^{t} f(X_s) - \bar f_\pi\right) \;\xrightarrow{d}\; N\!\left(0,\; \frac{\mathrm{Var}[R_1^{(f)} - \bar f_\pi\, \xi_1]}{\mathbb{E}[\xi_1]}\right). \tag{CLT}\]

증명. Lemma 1에 의해 \(\{(\xi_k, R_k^{(f)})\}_{k \geq 0}\)은 i.i.d. 이고 \(\xi_k \leq T_{\max}+1\), \(|R_k^{(f)}| \leq (T_{\max}+1)\|f\|_\infty\)이므로 1차 및 2차 모멘트 유한.

\(K(t) := \max\{k : R_k \leq t\}\). \(\xi_k \in [1, T_{\max}+1]\)이므로

\[\frac{t}{T_{\max}+1} - 1 \;\leq\; K(t) \;\leq\; t \tag{1}\]

따라서 \(K(t) \to \infty\) a.s. 이고 \(K(t)/t \to 1/\mathbb{E}[\xi_1]\) a.s. (elementary renewal theorem).

(SLLN). 시간 \(t\) 범위의 합을 에포크별로 분해:

\[\sum_{s=1}^{t} f(X_s) \;=\; \sum_{k=0}^{K(t)-1} R_k^{(f)} \;+\; \underbrace{\sum_{s = R_{K(t)}}^{t} f(X_s)}_{=: E(t)}\]

잔차 \(E(t)\)는 길이 \(\leq \xi_{K(t)} \leq T_{\max}+1\)의 합이므로 \(|E(t)| \leq (T_{\max}+1)\|f\|_\infty\) bounded. 따라서

\[\frac{1}{t}\sum_{s=1}^{t} f(X_s) \;=\; \frac{K(t)}{t}\cdot\frac{1}{K(t)}\sum_{k=0}^{K(t)-1} R_k^{(f)} \;+\; \frac{E(t)}{t}\]

i.i.d. SLLN으로 \(\frac{1}{K(t)}\sum_{k=0}^{K(t)-1} R_k^{(f)} \to \mathbb{E}[R_1^{(f)}]\) a.s., \(\frac{K(t)}{t} \to 1/\mathbb{E}[\xi_1]\) a.s., \(E(t)/t \to 0\). 결합하여

\[\frac{1}{t}\sum_{s=1}^t f(X_s) \;\xrightarrow{a.s.}\; \frac{\mathbb{E}[R_1^{(f)}]}{\mathbb{E}[\xi_1]} \;=\; \bar f_\pi. \qquad \square_{\text{SLLN}}\]

(CLT). 중심화하면 (분자 · 분모에 \(\bar f_\pi\)를 각각 조정):

\[\sum_{s=1}^{t} f(X_s) - \bar f_\pi \cdot t \;=\; \underbrace{\sum_{k=0}^{K(t)-1}(R_k^{(f)} - \bar f_\pi \xi_k)}_{=: S_{K(t)}} \;+\; \underbrace{E(t) - \bar f_\pi\,(t - R_{K(t)})}_{\text{bounded}}\]

\(Y_k := R_k^{(f)} - \bar f_\pi \xi_k\)는 i.i.d., \(\mathbb{E}[Y_k] = 0\), \(\sigma^2 := \mathrm{Var}[Y_k] < \infty\). 고전 CLT에 의해 \(S_m/\sqrt{m} \xrightarrow{d} N(0, \sigma^2)\). \(K(t)/t \to 1/\mathbb{E}[\xi_1]\) a.s.와 Anscombe의 정리를 결합하면 \(S_{K(t)}/\sqrt{K(t)} \xrightarrow{d} N(0, \sigma^2)\), 따라서

\[\frac{S_{K(t)}}{\sqrt{t}} \;=\; \sqrt{\frac{K(t)}{t}} \cdot \frac{S_{K(t)}}{\sqrt{K(t)}} \;\xrightarrow{d}\; N\!\left(0,\; \frac{\sigma^2}{\mathbb{E}[\xi_1]}\right)\]

잔차 항은 bounded이므로 \(\sqrt{t}\)로 나누면 확률 수렴으로 \(0\). Slutsky에 의해

\[\frac{1}{\sqrt{t}}\Big(\sum_{s=1}^t f(X_s) - \bar f_\pi t\Big) \;\xrightarrow{d}\; N\!\left(0,\; \frac{\sigma^2}{\mathbb{E}[\xi_1]}\right). \qquad \square_{\text{CLT}}\]
