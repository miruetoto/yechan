정확한 지적입니다. 제가 ②에서 알고리즘을 잘못 그렸어요 — walker 는 downstream 집합 안에서 랜덤(degree 가중)으로 하나 픽하지, 최저값으로만 흐르는 게 아닙니다. 두 질문 다 페이퍼 실제 텍스트를 봐야 정확히 답하겠습니다. minorization 조립부(lem:doeblin)를 읽어보겠습니다.

두 지적 다 정확합니다. 특히 ②에서 제 설명이 틀렸어요 — 실제 텍스트(982번 줄, 974번 줄)를 보고 바로잡겠습니다.

먼저 알고리즘 정정 (대표님 말이 맞습니다)

flow 규칙은 downstream 집합 \[\mathcal D_t=\{u\sim X_t: h(u,t)\leq h(X_t,t)\}\] 안에서 degree 가중으로 랜덤 픽입니다. “최저값으로만 흐른다”가 아니라 “현재보다 낮거나 같은 이웃 아무거나 확률적으로”. 제가 ②를 최저값 흐름처럼 그린 게 잘못입니다.

Q1 — “경로가 R_δ 위에서 고정” 은 어디에 쓰여 있나

두 군데입니다:

branch 정의 — Claim 2-a, 948번 줄: > “A branch \(\mathbf v^{\flat}\) is the sequence of non-fall visited nodes (the discrete choices left free by \(\mathcal A^{\sharp}\)).”

즉 \(\mathbf v^{\flat}\) = walker 가 실제로 밟은 노드 순서(이산 데이터).

고정 — Claim 2-b, 974번 줄의 robust core 정의 + 982번 줄의 transport: \[\mathcal R_\delta(\boldsymbol\zeta,s^{\star}):=[0,b]^{nL}\cap\Lambda^{-1}(\boldsymbol\zeta)\cap\{\delta\leq b^{\sharp}_j\leq b-\delta\}\cap\!\!\bigcap_{a:\,P_K\alpha_a\neq0}\!\!\{|\alpha_a\cdot\mathbf b^{\sharp}+\gamma_a(s^{\star})|\geq\delta\}.\] 그리고 982번 줄에서 이 core 를 branch 별로 쪼갭니다: \(\mathcal R_\delta=\bigsqcup_{\mathbf v^{\flat}}\mathcal R_{\delta,\mathbf v^{\flat}}\) — 이 disjoint 분할이 핵심입니다(아래에서 설명).

Q2 — “downstream picks are forced (no tie-break)” 의 진짜 뜻

제가 “tie 면 1/2 로 쪼개져서 확률이 샌다”고 한 건 증명이 막아버린 상황을 마치 증명의 메커니즘인 양 말한 거라 헷갈리게 했습니다. 982번 줄 실제 논리는 이렇습니다:

“On \(\mathcal R_\delta\) every nondegenerate comparison is \(\geq\delta\) from equality, so the downstream picks are forced (no tie-break) and each round’s strictly-decreasing path is exhausted in \(\leq n-1\) flows … each fibre point thus realises its branch \(\mathbf v^{\flat}\) deterministically, at no probability cost.”

해석:

robust core 에서 모든 비교가 0 에서 \(\delta\) 이상 떨어져 있다 → 각 flow 스텝에서 downstream 집합 \(\mathcal D_t\) 가 정확히 한 원소(singleton) 가 되도록 구성을 골라놨다는 뜻입니다. “현재보다 낮은 이웃이 딱 하나, 나머지는 전부 \(\delta\) 이상 높음.” 그러면:

  • \(|\mathcal D_t|=1\) 이니까 degree 가중 랜덤 픽이라도 고를 게 하나뿐 → 자동으로 강제됨. “최저값으로 흐르는 알고리즘”이 아니라, 이 깎아낸 영역에서는 메뉴 자체가 한 개라서 랜덤이 결정론으로 붕괴하는 겁니다.
  • 그래서 떨어진 눈 \(\mathbf b^{\sharp}\) 가 경로를 완전히 결정합니다(잔여 flow 동전던지기 없음). 이게 974→982 의 분할 \(\mathcal R_\delta=\bigsqcup_{\mathbf v^{\flat}}\mathcal R_{\delta,\mathbf v^{\flat}}\) 이 성립하는 이유 — 각 deposit 값이 정확히 하나의 branch 로 사상되니까 disjoint 분할이 되는 거예요. \(|\mathcal D_t|\geq2\) 면 한 deposit 에서 여러 branch 가 확률적으로 갈려서 깔끔한 분할이 안 됩니다.
  • “at no probability cost” = flow 픽에 확률 인자가 안 붙음. 실제로 Claim 1(940–941번 줄)의 확률 밑바닥을 보면 fall 확률 \(\mu_{\min}^{nL}\) 과 작은 deposit 확률 \((\varepsilon_{\flat}/b)^{nLT_{\max}}\) 뿐, flow 픽 인자가 아예 없습니다. 픽이 강제라서 1 을 곱하는 셈이니까요.

그래서 ② 를 어떻게 고쳐야 하나

  • 틀린 그림(제가 한 것): “tie 면 \(1/2\) 로 쪼개져 확률이 샌다” — 이건 carve 를 안 했을 때의 동기일 뿐, 증명의 작동방식이 아님.
  • 맞는 그림: 증명은 \(\delta\)-robust core 로 깎아서 각 스텝의 downstream 메뉴를 singleton 으로 만들어 버리고, 그 결과 (i) deposit→경로 사상이 한 branch 안의 깨끗한 평행이동이 되어 밀도(Hausdorff 측도)를 얹을 수 있고(972번 줄: “right-inverse shift … carve a robust core with a margin to absorb the shift”), (ii) flow 픽이 강제라 확률 인자가 안 새는 것.

정리하면 — walker 가 랜덤 픽이라는 건 맞고, 증명은 그 랜덤성을 “downstream 후보를 하나만 남기는 deposit 영역”으로 제한해서 결정론으로 만든다가 정확한 그림입니다. tie 회피는 그 singleton-강제와 평행이동 안정성을 위한 것이고요.

제가 앞 답변 ②를 부정확하게 설명한 점 사과드립니다. 이 부분, 원하시면 “왜 cyclic fall 패턴이 실제로 \(|\mathcal D_t|=1\) 을 만들어내는가”(box geometry + 작은 non-fall deposit)까지 더 파고들 수 있습니다.
