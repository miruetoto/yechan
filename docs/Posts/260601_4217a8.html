1. 팟캐스트 버전

(스튜디오. Lemma 7 카드 한 장.)

H. 오늘 Lemma 7 이에요. 핵심 한 줄: fall 들이 cyclic 하게 떨어지는 이벤트 위에서, “각 노드 총 fall 량의 노드 \(v_1\) 대비 차이”를 fall 양들의 선형사상 \(\Sigma\) 로 보면, 이 \(\Sigma\) 가 full rank · 우역원(right inverse) · 깔끔한 Jacobian 을 가진다.

G. 셋업부터요.

H. 이벤트 \(\mathcal{A}_1\) 위에서 시작해요 — \(nL\) 개 fall 의 착지 노드 순서가 \(v_1, \ldots, v_n\) 을 cyclic 하게 \(L\) 사이클 도는 사건이에요. 노드 \(n\) 개를 한 바퀴 도는 걸 \(L\) 번.

G. \(nL\) 개 fall 이 연속으로 \(v_1, v_2, \ldots\) 떨어진다는 건가요?

H. ★ 아니에요, 거기가 핵심 오해예요. fall 은 연속으로 못 일어나요. 알고리즘상 fall 직후 \(Z_t = 0\) 이 되고, 다음 스텝은 \(Z < T_{\max}\) 라 flow 시도(downstream 있으면 flow, 없으면 block) 예요. \(Z\) 가 다시 \(T_{\max}\) 에 도달해야 그 다음 fall 이 와요. 그래서 실제 trajectory 는

\[\underbrace{\text{fall}\to v_1}_{\text{fall 1}} \to \underbrace{\text{flow/block}\cdots}_{\text{사이 스텝}} \to \underbrace{\text{fall}\to v_2}_{\text{fall 2}} \to \underbrace{\text{flow/block}\cdots}_{\text{사이 스텝}} \to \cdots\]

처럼 fall 사이에 flow/block 이 반드시 끼어 있어요. \(\mathcal{A}_1\) 은 그 중 fall 시점들만 추렸을 때 \(\mu_0\) 착지 노드가 \(v_1, v_2, v_3, v_1, \ldots\) cyclic 하게 나오는 사건이에요.

G. 그럼 \(b'_{k,\ell}\) 의 인덱스는 시간 스텝이 아니네요?

H. 맞아요. \(k, \ell\) 은 fall 만 센 인덱스예요 (시간 스텝 \(t\) 아님).

  • \(\mathbf{b}' = (b'_{k,\ell})_{1\leq k\leq n,\,1\leq\ell\leq L} \in [0,b]^N\) : fall 양 벡터 (\(N = nL\) 차원, bold 로 표기)
  • \(b'_{k,\ell} \in [0,b]\) : 그 성분 (스칼라) — 노드 \(v_k\)·사이클 \(\ell\) 의 fall 양 (\(k\)=착지 노드 \(1\sim n\), \(\ell\)=사이클 \(1\sim L\))
  • \(\sum_\ell b'_{k,\ell}\) : 노드 \(v_k\) 에 \(L\) 사이클 동안 쌓인 총 fall 량 (스칼라; flow/block deposit 은 제외 — 다른 보조정리에서 residual 로 처리)

왜 fall 만 모으나: fall 의 목적지는 \(\mu_0\) (full support) 라 임의 노드로 양의 확률로 보낼 수 있어요. flow 는 현재 height 에 의존(downstream 으로만)해서 통제가 안 돼요. 그래서 “모든 노드를 균등하게 \(L\) 번씩 커버”하는 통제는 fall 의 \(\mu_0\) draw 로만 가능하고, \(\Sigma\) 가 fall 양만 모으는 거예요.

H. 핵심 사상 \(\Sigma : \mathbb{R}^N \to \mathbb{R}^{n-1}\) 는 두 단계로 만들어져요.

1단계 — 노드별 총 fall 량. 각 노드 \(v_k\) 에 \(L\) 사이클 동안 쌓인 fall 을 다 더해요:

\[T_{v_k} := \sum_{\ell=1}^{L} b'_{k,\ell} \qquad (k = 1, \ldots, n)\]

2단계 — 노드 \(v_1\) 기준 차이(anchoring). 노드 \(v_1\) 의 총량 \(T_{v_1}\) 을 기준점으로 빼요:

\[\Sigma \mathbf{b}' = (T_{v_2} - T_{v_1},\ T_{v_3} - T_{v_1},\ \ldots,\ T_{v_n} - T_{v_1}) \in \mathbb{R}^{n-1}\]

성분이 \(n-1\) 개인 이유: 노드 \(n\) 개 중 기준 노드 \(v_1\) 자신(\(T_{v_1} - T_{v_1} = 0\))은 빠지니까요. 절대 높이는 눈이 쌓여 계속 커지지만 노드 간 차이만 의미가 있어서 이렇게 anchor 해요 (HST augmented state 의 \(\Delta_1\mathbf{h}\) 와 같은 정신).

이름 “cumulative centred fall shift” 를 풀면:

  • cumulative = \(L\) 사이클 누적 합 (\(\sum_\ell\))
  • centred = 노드 \(v_1\) 기준 centering (anchoring)
  • fall shift = fall 로 생긴 높이 이동

구체 예시로 (\(n=3\), \(L=2\)):

\[T_{v_1} = b'_{1,1}+b'_{1,2}, \quad T_{v_2} = b'_{2,1}+b'_{2,2}, \quad T_{v_3} = b'_{3,1}+b'_{3,2} \;\Rightarrow\; \Sigma \mathbf{b}' = (T_{v_2} - T_{v_1},\ T_{v_3} - T_{v_1}) \in \mathbb{R}^2\]

숫자로 (\(b=1\)): 사이클 1 이 \((0.2, 0.6, 0.9)\), 사이클 2 가 \((0.1, 0.5, 0.8)\) 이면 \((T_{v_1}, T_{v_2}, T_{v_3}) = (0.3, 1.1, 1.7)\), 따라서 \(\Sigma \mathbf{b}' = (0.8,\ 1.4)\).

G. Lemma 4 랑 닮았는데요?

H. 정확해요. Lemma 4 의 \(\Delta_1\boldsymbol{\xi} = (\xi_2-\xi_1, \ldots, \xi_n-\xi_1)\) 랑 같은 구조인데, 한 번이 아니라 \(L\) 사이클 합으로 한 거예요. 그래서 \(\Sigma\) 는 per-block 차이사상 \(\Delta_1\) 의 \(L\)-fold sum 이에요.

# 작은 예: n=3, L=4 → N=12, d=2 인 Sigma 행렬 구성
n, L = 3, 4
N, d = n * L, n - 1

# b'_{k,l} 을 (k,l) 평탄화: index = (k-1)*L + (l-1), k=1..n, l=1..L
Sigma = np.zeros((d, N))
for row, k in enumerate(range(2, n + 1)):   # k = 2..n  → d 행
    for l in range(1, L + 1):
        Sigma[row, (k - 1) * L + (l - 1)] += 1     # +sum_l b'_{k,l}
        Sigma[row, (1 - 1) * L + (l - 1)] -= 1     # -sum_l b'_{1,l}

print(f"n={n}, L={L}: N={N}, d={d}")
print("Sigma (d×N):")
print(Sigma.astype(int))
print(f"\nrank(Sigma) = {np.linalg.matrix_rank(Sigma)}  (= d = {d})")

G. 각 행이 “노드 \(v_k\) 자리에 +1, 노드 \(v_1\) 자리에 −1” 패턴이네요.

H. 맞아요. 행 하나가 한 노드의 (노드 \(v_1\) 대비) 차이를 뽑아요. 이제 네 가지 결론을 봐요.

H. (1) \(\mathrm{rank}\,\Sigma = n-1\). \(\Delta_1\) 이 rank \(n-1\) 라 \(L\)-fold sum 인 \(\Sigma\) 도 rank \(n-1\) — 출력공간 \(\mathbb{R}^{n-1}\) 를 꽉 채워요.

(2) coarea Jacobian \(J(\Sigma) = \sqrt{\det(\Sigma\Sigma^\top)} = \sqrt{L^{n-1}n}\). Gram 행렬을 계산하면

\[\Sigma\Sigma^\top = L\,(I_{n-1} + \mathbf{1}\mathbf{1}^\top)\]

이고, 행렬식 보조정리로

\[\det(I_{n-1} + \mathbf{1}\mathbf{1}^\top) = 1 + \mathbf{1}^\top\mathbf{1} = 1 + (n-1) = n \;\Rightarrow\; \det(\Sigma\Sigma^\top) = L^{n-1}\cdot n = L^{n-1}n\]

Gram = Sigma @ Sigma.T
print("Gram = Sigma Sigma^T:")
print(Gram.astype(int))
print(f"\n예측: L(I_d + 11^T) = {L}(I + 11^T)")
print(f"det(Gram)        = {np.linalg.det(Gram):.1f}")
print(f"L^(n-1)*n        = {L**(n-1) * n}")
print(f"J(Sigma)=sqrt(det) = {np.sqrt(np.linalg.det(Gram)):.4f}  vs  sqrt(L^(n-1)n) = {np.sqrt(L**(n-1)*n):.4f}")
Gram = Sigma Sigma^T:

예측: L(I_d + 11^T) = 4(I + 11^T)
det(Gram)        = 48.0
L^(n-1)*n        = 48

(3) 우역원 \(Q\) 존재, \(\Sigma Q = I_{n-1}\), \(C_Q = \|Q\|_{\infty\to\infty} < \infty\). full row rank 라 오른쪽 역사상이 존재해요. “원하는 차이 벡터 \(z\) 를 만들려면 fall 양을 이렇게 잡아라”가 \(Qz\). \(C_Q < \infty\) 는 그 구성이 유계 — 입력이 크지 않으면 필요한 fall 양도 폭주 안 함.

# 우역원 Q (Moore-Penrose pseudo-inverse 가 한 예)
Q = Sigma.T @ np.linalg.inv(Sigma @ Sigma.T)   # right inverse: Sigma Q = I_d
print("Sigma Q = I_d 확인:")
print(np.round(Sigma @ Q, 10).astype(int))
C_Q = np.max(np.sum(np.abs(Q), axis=1))         # ||Q||_{inf->inf} = max row abs-sum
print(f"\nC_Q = ||Q||_(inf->inf) = {C_Q:.4f}  (< infinity)")

# 임의 target z 를 실제로 만들어보기
z = np.array([0.7, -0.3])
b_constructed = Q @ z
print(f"\ntarget z = {z}")
print(f"Sigma (Q z) = {np.round(Sigma @ b_constructed, 6)}   (= z 복원)")

(4) \(\mathrm{Range}(\Sigma^\top) = \{c : c_{k,\ell} = a_k\) (\(\ell\) 무관), \(\sum_k a_k = 0\}\). \(c = \Sigma^\top\theta\) 를 풀면 사이클 \(\ell\) 에 무관하게 노드별 상수이고 그 상수들의 합이 0 — anchored + centred 구조가 그대로 드러나요.

H. 왜 필요한지 — Doeblin 맥락이에요.

minorization 증명에서 target 분포 밀도를 coarea formula 로 fall 양 벡터 \(\mathbf{b}'\) 을 적분해 구해요. 그때:

  • \(J(\Sigma)\) : 적분 변수변환 Jacobian (필수)
  • \(Q\) : “원하는 target shift 를 만드는 fall 양”을 명시 구성 (fiber 위 점 이동)
  • \(C_Q < \infty\) : 그 구성이 cube \([0,b]^N\) 안에 머물도록 보장 (margin 통제)
  • \(\mathrm{Range}(\Sigma^\top)\) : 어떤 방향이 \(\Sigma\) 로 보이고 어떤 방향이 fiber(kernel)인지 구분

G. Lemma 4·6 과 정리하면요?

H. 한 줄기예요.

  • Lemma 4: 한 라운드 차이의 밀도 하한
  • Lemma 6: \(L\) 겹 합성곱이 넓은 영역에서 양수
  • Lemma 7: 그 \(L\) 겹 구조를 선형대수로 정밀하게 깔아주는 도구 — coarea 적분을 굴리려면 \(\Sigma\) 의 rank·Jacobian·우역원이 명시적으로 필요

비유하면 벡터 \(\mathbf{b}'\) 은 \(nL\) 개 손잡이(각 성분 \(b'_{k,\ell}\) 이 fall 양)이고 \(\Sigma\) 는 그걸 돌려 만들 수 있는 “\(n-1\) 차원 차이 벡터”를 읽어요. Lemma 7 은 “이 손잡이들로 원하는 차이를 다 만들 수 있고(full rank), 만드는 방법이 유계(\(C_Q\))이며, 부피 환산율이 정확히 \(\sqrt{L^{n-1}n}\)”임을 보장해요.

2. 논문직접삽입버전

Lemma. fall-target event \(\mathcal{A}_1\) (\(nL\) 개 fall 의 착지 노드가 \(v_1,\ldots,v_n\) 을 cyclic 순서로 \(L\) 사이클 도는 사건; fall 들은 연속이 아니라 사이사이 flow/block 스텝을 두고 일어난다) 위에서, fall 양 벡터를 \(\mathbf{b}' = (b'_{k,\ell})_{1\leq k\leq n,\, 1\leq\ell\leq L}\in[0,b]^N\), \(N = nL\) (성분 \(b'_{k,\ell}\) 은 스칼라; \(k\)=착지 노드, \(\ell\)=사이클이며 시간 스텝 아님) 이라 쓰자. anchored coordinate 의 cumulative centred fall shift 를 선형사상 \(\Sigma:\mathbb{R}^N\to\mathbb{R}^{n-1}\) (\(S_t\) 와는 별개),

\[\Sigma \mathbf{b}' = \Big(\textstyle\sum_\ell b'_{2,\ell} - \sum_\ell b'_{1,\ell},\ \ldots,\ \sum_\ell b'_{n,\ell} - \sum_\ell b'_{1,\ell}\Big)\in\mathbb{R}^{n-1}\]

이라 하자. 그러면 \(\mathrm{rank}\,\Sigma = n-1\), coarea Jacobian 은 \(J(\Sigma) = \sqrt{\det(\Sigma\Sigma^\top)} = \sqrt{L^{n-1}n}\), 그리고 \(\Sigma\) 는 우역원 \(Q:\mathbb{R}^{n-1}\to\mathbb{R}^N\) (\(\Sigma Q = I_{n-1}\)) 을 가지며 \(C_Q := \|Q\|_{\infty\to\infty} < \infty\). 또한

\[\mathrm{Range}(\Sigma^\top) = \{c\in\mathbb{R}^N : c_{k,\ell} = a_k\ \text{($\ell$ 무관)},\ \textstyle\sum_k a_k = 0\}\]

Proof.

rank 와 우역원. \(\Sigma\) 는 Lemma 4 의 per-block 차이사상 \(\Delta_1\) 의 \(L\)-fold sum 이고, \(\Delta_1\) 은 rank \(n-1\) 이다. 따라서 \(\mathrm{rank}\,\Sigma = n-1\) (full row rank) 이고, full row rank 행렬은 우역원을 가지므로 \(\Sigma Q = I_{n-1}\) 인 \(Q\) 가 존재한다. \(Q\) 를 유한차원 행렬로 잡으면 \(C_Q = \|Q\|_{\infty\to\infty} < \infty\).

Gram 계산과 Jacobian. 각 행이 “노드 \(v_k\) 자리 \(+1\), 노드 \(v_1\) 자리 \(-1\)” 의 \(L\) 사이클 합이므로, 행 \(i\) 와 행 \(j\) 의 내적은

\[\begin{aligned} (\Sigma\Sigma^\top)_{ij} &= \sum_\ell \big[\text{(행 $i$)}_\ell \cdot \text{(행 $j$)}_\ell\big] \\ &= \begin{cases} L\cdot(1^2 + 1^2) = 2L & i = j \\[2pt] L\cdot(1\cdot 1) = L & i \neq j \end{cases} && (\because \text{노드 } v_1 \text{ 자리 공유 + 자기 노드 자리}) \\ \Rightarrow\quad \Sigma\Sigma^\top &= L\,(I_{n-1} + \mathbf{1}\mathbf{1}^\top) \end{aligned}\]

행렬식 보조정리 \(\det(I_{n-1} + uv^\top) = 1 + v^\top u\) 를 \(u = v = \mathbf{1}\) 에 적용하면

\[\begin{aligned} \det(I_{n-1} + \mathbf{1}\mathbf{1}^\top) &= 1 + \mathbf{1}^\top\mathbf{1} = 1 + (n-1) = n \\ \Rightarrow\quad \det(\Sigma\Sigma^\top) &= L^{n-1}\det(I_{n-1} + \mathbf{1}\mathbf{1}^\top) = L^{n-1}\,n = L^{n-1}n \\ \Rightarrow\quad J(\Sigma) &= \sqrt{\det(\Sigma\Sigma^\top)} = \sqrt{L^{n-1}n} \end{aligned}\]

Range 계산. \(c = \Sigma^\top\theta\) (\(\theta\in\mathbb{R}^{n-1}\)) 를 성분으로 풀면, \(\Sigma\) 의 열 구조에서

\[c_{1,\ell} = -\sum_{q=1}^{n-1}\theta_q \quad (\forall\ell), \qquad c_{k,\ell} = \theta_{k-1} \quad (k\geq 2,\ \forall\ell)\]

즉 각 \(c_{k,\ell}\) 은 사이클 \(\ell\) 에 무관한 노드별 상수 \(a_k\) 이고, 그 합은

\[\sum_{k=1}^{n} a_k = -\sum_{q=1}^{n-1}\theta_q + \sum_{k=2}^{n}\theta_{k-1} = -\sum_{q=1}^{n-1}\theta_q + \sum_{q=1}^{n-1}\theta_q = 0\]

역으로 “노드별 상수이고 합이 0” 인 \(c\) 는 위 형태의 \(\theta\) 로 실현되므로 (converse 는 즉각), 등식이 성립한다. \(\square\)
