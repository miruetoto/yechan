연구 ▷ HST ▷ AAA vs BAB

Author

소미

Published

May 28, 2026

HST의 알고리즘 종류는 아래와 같이 세분화된 버전을 생각할 수 있다.

  1. snowfall — 매 step 쌓는 눈 크기 \(b'\) 를 어떻게 뽑을지.
    • A: 매 step 새로 \(b'_{t+1}\sim\mathrm{Unif}(0,b)\) 독립.
    • B: 라운드 시작 1번 \(b'^{(r)}\sim\mathrm{Unif}(0,b)\).
    • C: B + step-내 감쇠 \(b'_{t_r+s}=b'^{(r)}f(s)\).
    • D: \(b'_s=b\) 고정 (legacy).
  2. flow — walker 가 어디로 흐를지.
    • A (채택): downstream에서만 pick. (downstream이 없으면 block)
    • B: 모든 이웃에서 pick → uphill 이면 block 처리.
  3. \(T_{\max}\) — block timer 상한.
    • A (채택): 라운드마다 \(T_{\max}^{(r)}\sim\mathrm{Unif}\{n,\dots,2n\}\).
    • B: 입력 상수 고정.

기존에 생각한 가장 좋은 알고리즘은 BAB 였으나, AAA가 더 좋은 옵션일 수도 있겠다는 생각이 들어서 고민중임.

현상 1 — 누적 적설량이 단순 기대와 어긋난다 (Cov 잔차)

실험 그래프는 노드 10 개의 완전그래프: 모든 노드 쌍이 직접 이웃이고 차수가 9로 균일, vertex-transitive (모든 노드가 구조적으로 동등).

노드 \(i\)의 적설률 \(\tilde\rho_i:=\lim_t h_i(t)/t\) 는 순진한 기대로

\[\tilde\rho_i \;\stackrel{?}{=}\; \bar b\,\rho_i \;=\; 0.025\times 0.1 \;=\; 0.0025\]

이 되어야 할 것 같다. 그런데 시뮬로 두 모델을 돌려보면 기대와 다르다.

Code 
import numpy as np

B = 0.05; bbar = B / 2

def run(W, T, model, seed, fixed_maxflow=None):
    """공통: flow A(downstream) + block-stay. AAA: per-step b + T_max~U[n,2n].
       BAB: per-round b + fixed T_max."""
    n = W.shape[0]; deg = W.sum(1); mu0 = deg / deg.sum()
    nb = [np.where(W[i] > 0)[0] for i in range(n)]
    rng = np.random.default_rng(seed)
    h = np.zeros(n); visit = np.zeros(n, np.int64)
    draw_mf = lambda: int(rng.integers(n, 2*n+1)) if model == "AAA" else (fixed_maxflow or 2*n)
    maxflow = draw_mf(); Z = maxflow; X = 0
    b_round = float(rng.uniform(0, B))
    N_r = np.zeros(n, np.int64); rec_b = []; rec_N = []
    for t in range(T):
        fall = (Z >= maxflow)
        if fall:
            if N_r.sum() > 0:
                rec_b.append(b_round); rec_N.append(N_r.copy())
            maxflow = draw_mf(); b_round = float(rng.uniform(0, B)); Z = 0
            N_r = np.zeros(n, np.int64)
            b_step = float(rng.uniform(0, B)) if model == "AAA" else b_round
            X = int(rng.choice(n, p=mu0))
        else:
            b_step = float(rng.uniform(0, B)) if model == "AAA" else b_round
            nbr = nb[X]; down = nbr[h[nbr] <= h[X]]
            if len(down) > 0:
                w = W[X, down]; X = int(rng.choice(down, p=w/w.sum())); Z += 1
            else:
                Z = maxflow   # block: 제자리
        h[X] += b_step; visit[X] += 1; N_r[X] += 1
    return h, visit, np.array(rec_b), np.stack(rec_N)

n = 10; W = np.ones((n, n)) - np.eye(n); T = 800_000
res = {}
for model in ["BAB", "AAA"]:
    h, visit, rb, RN = run(W, T, model, seed=20, fixed_maxflow=2*n)
    rho = (visit / visit.sum())
    excess = h / T - bbar * (visit / T)              # = Cov_i / m̄
    cov_i = np.array([np.cov(rb, RN[:, i])[0, 1] for i in range(n)])
    mean_hT = (h / T).mean()
    expected = bbar * rho.mean()
    print(f"[{model}] 노드당 h/T 평균 = {mean_hT:.5f}   "
          f"(순진한 기대 b̄ρ_i = {expected:.5f},  잉여 {(mean_hT/expected-1)*100:+5.1f}%)")
    print(f"        Cov_i 평균 = {cov_i.mean():+.2e}   |excess_i| 평균 = {np.abs(excess).mean():.2e}")
    res[model] = excess

AAA는 시뮬값이 순진한 기대 \(0.0025\)와 정확히 일치한다. BAB는 노드당 약 \(0.0029\), 기대보다 16% 더 쌓인다. 매 step의 \(b'\) 평균은 두 모델 모두 \(\bar b\)로 같은데, 왜 BAB만 더 쌓이는가? 라운드 \(r\)의 총 적설은 \(b'^{(r)}m_r\)이므로 한 step당 평균 적설은

\[\frac{\mathbb E_\pi\!\big[b'^{(r)}m_r\big]}{\mathbb E_\pi[m_r]} \;=\;\frac{\bar b\,\mathbb E_\pi[m_r]+\mathrm{Cov}_\pi(b'^{(r)},m_r)}{\bar m} \;=\;\bar b+\frac{\mathrm{Cov}_\pi(b'^{(r)},m_r)}{\bar m}\qquad(\ast)\]

다. 여기에서 Cov가 AAA모델에서는 0인데 BAB에서는 0이 아니다 (큰 \(b'\)의 라운드가 약간 더 길다). 이것이 +16% 잉여로 나타난다.

Cov텀의 존재는 \(\mathrm{SD}^2_{ij}/t^3\) 의 수렴값에 영향을 준다.

  • AAA: \(\displaystyle \frac{\mathrm{SD}^2_{ij}(t)}{t^3} \;\xrightarrow{t\to\infty}\; \frac{\bar b^{\,2}(\rho_i-\rho_j)^2}{3}\)
  • BAB: \(\displaystyle \frac{\mathrm{SD}^2_{ij}(t)}{t^3} \;\xrightarrow{t\to\infty}\; \frac{1}{3}\Big[\bar b(\rho_i-\rho_j) + \tfrac{\mathrm{Cov}_i-\mathrm{Cov}_j}{\bar m}\Big]^2\)

(여기서 \(\mathrm{Cov}_i:=\mathrm{Cov}_\pi(b'^{(r)},N_r^{(i)})\) 는 시뮬에서야 측정되는 graph+dynamics joint 잔차.)

현상 3 — 적설량 분해: AAA는 2항으로 정확히 떨어지고, Model B는 3항이다

한 노드의 적설량 \(h_i(t)\) 자체를 분해해 보면, 매 step 의 눈 \(b'_s\) 를 평균 \(\bar b\) 와 편차로 쪼개

\[h_i(t)-h_i(0) \;=\; \underbrace{\bar b\sum_{s\le t}\mathbf 1\{X_s=v_i\}}_{\text{drift } (\bar b N_i)} \;+\; \underbrace{\sum_{s\le t}(b'_s-\bar b)\mathbf 1\{X_s=v_i\}}_{\text{martingale } M_i(t)}\]

가 된다. AAA 에선 \(b'_s\) 가 매 step 독립이고 walker 이동이 \(b'_s\) 를 안 보므로 \(M_i\) 가 깨끗한 마팅게일(\(\mathbb E[\,\cdot\mid\mathcal F_{s-1}]=0\)) — 분해가 정확히 두 항이고 남는 잔차가 없다. Model B 에선 한 라운드 내내 같은 \(b'^{(r)}\) 를 쓰므로 관측 시점의 마지막 미완료 라운드가 깨끗한 2항에 안 들어가 세 번째 항(incomplete-round residual)으로 남는다.

그 차이는 drift 로부터의 편차 \(S_i(t):=h_i(t)-\bar b\,N_i(t)\) 를 보면 바로 드러난다. AAA 에선 \(S_i=M_i\) (마팅게일)라 \(S_i\sim\sqrt t\), 즉 \(S_i/t\to 0\) (\(o(t)\)). Model B 에선 라운드 결합으로 \(\mathbb E[S_i]=(\text{라운드수})\times\mathrm{Cov}_i = O(t)\) — 즉 \(S_i/t\to \mathrm{Cov}_i/\bar m\neq 0\). K\(_{10}\) 에서 \(\mathrm{rms}(S)/t\) 를 시간에 따라 보자.

Code 
def run_S(W, T, model, seed, fixed_maxflow=None, n_ck=40):
    n=W.shape[0]; deg=W.sum(1); mu0=deg/deg.sum(); nb=[np.where(W[i]>0)[0] for i in range(n)]
    rng=np.random.default_rng(seed); h=np.zeros(n); visit=np.zeros(n,np.int64)
    draw=lambda: int(rng.integers(n,2*n+1)) if model[2]=="A" else (fixed_maxflow or 2*n)
    sfA=(model[0]=="A"); mf=draw(); Z=mf; X=0; b_round=float(rng.uniform(0,B))
    ck=np.unique(np.geomspace(1000,T,n_ck).astype(int)); ci=0; cks=[]; rms=[]
    for t in range(1,T+1):
        b_step=float(rng.uniform(0,B)) if sfA else b_round
        if Z>=mf:
            mf=draw(); b_round=float(rng.uniform(0,B))
            if not sfA: b_step=b_round
            X=int(rng.choice(n,p=mu0)); h[X]+=b_step; Z=0
        else:
            nbr=nb[X]; down=nbr[h[nbr]<=h[X]]
            if len(down)>0:
                w=W[X,down]; X=int(rng.choice(down,p=w/w.sum())); h[X]+=b_step; Z+=1
            else:
                h[X]+=b_step; Z=mf
        visit[X]+=1
        if ci<len(ck) and t==ck[ci]:
            S=h-bbar*visit; cks.append(t); rms.append(np.sqrt((S**2).mean())); ci+=1
    return np.array(cks), np.array(rms)

n=10; W=np.ones((n,n))-np.eye(n); T=500_000
cA,rA=run_S(W,T,"AAA",0); cB,rB=run_S(W,T,"BAB",0,fixed_maxflow=2*n)
print(f"[AAA] rms(S)/t : t=10^4 {rA[np.searchsorted(cA,10**4)]/cA[np.searchsorted(cA,10**4)]:.2e} → t={T:,} {rA[-1]/cA[-1]:.2e}  (→0, o(t))")
print(f"[BAB] rms(S)/t : t=10^4 {rB[np.searchsorted(cB,10**4)]/cB[np.searchsorted(cB,10**4)]:.2e} → t={T:,} {rB[-1]/cB[-1]:.2e}  (→const, O(t))")

[BAB] rms(S)/t : t=10^4 4.58e-04 → t=500,000 3.90e-04  (→const, O(t))

AAA 의 \(S_i/t\) 는 \(0\) 으로 가고(적설량이 drift \(\bar bN_i\) 에서 \(\sqrt t\) 만큼만 벗어나는 마팅게일), BAB 는 양의 상수로 떠 있다(적설량이 drift 에서 \(O(t)\) 로 체계적으로 벗어남). 이 \(O(t)\) 잔차가 §현상1 에서 본 \(\mathrm{Cov}_i/\bar m\) 이고, 적설량 분해로 보면 Model B 에만 있는 세 번째 항(incomplete-round residual) 이다. AAA 는 per-step 독립 덕분에 분해가 깨끗한 2항 이라 이 잔차가 아예 없다.
